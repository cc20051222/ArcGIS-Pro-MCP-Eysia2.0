# M1 比较规则 v1 — PASS CANDIDATE

所有适用规则、样本身份和阈值在查看最终结果前冻结。失败、超时、断线、取消和正确拒绝均按其适用类别保留，不事后缩小分母。

## 机器判定

| ID | 检查 | v1 判定 |
|---|---|---|
| GEO-001 | 地理/几何 | CRS、轴序、单位、范围、要素身份及拓扑与冻结参考一致；坐标比较采用输入数据声明的 XYTolerance。栅格 CRS、行列数、像元尺寸、原点、范围和共同格网完全匹配。缺 CRS/XYTolerance/转换来源即 UNKNOWN/BLOCKED。 |
| NUM-001 | 数值/事实 | 整数计数、类别、断点、单位与冻结的规范十进制答案精确相等；绝对/相对容差为 0，比较精度来自冻结参考。不能事后舍入。 |
| SCI-001 | 科学保护 | 类别、NoData、方法、误差/不确定性和来源事实不得被视觉修饰改写或隐藏；语义色 token 与图例绑定，ICC 前 ΔE00 最大值 0。 |
| LAY-001 | 构图 | 适用的地图框、图例、比例尺、指北针、单位和来源全部在页面内；关键元素无重叠；图框与整饰绑定同一修订；叠加位移上限 0 px。初始印刷档 A4/A3、300 DPI。 |
| TXT-001 | 文本/字体 | 标题、类别、单位、来源等语义字符串精确匹配；无缺字、截断、裁剪或未记录 fallback；候选最小字号 8 pt。 |
| OUT-001 | 交付文件 | 每件必需产物可打开/解码，类型、大小、hash 和来源清单一致；拒绝覆盖。 |

| TS08-INPUT-QUAL-001 | TS08 输入资格 | 至少 3 个频谱独立波段；每波段有身份和光谱角色，且来源 lineage 指向不同原始波段；同一单波段重复合成不合格。CRS、宽高、像元大小、原点、范围和波段对齐须共同格网一致；NoData 值/掩膜、有效区语义和边界处理须显式；来源/产品身份、采集信息、处理 lineage 与源 hash 可追溯。黄金路径 `NOT-AVAILABLE-PENDING-USER`。 |

## 预算与全局门

- 单页每作业最多 12 个结构候选、3 次初始预览、5 次总预览、2 轮自动修正、2 次最终渲染（路线图 §6）。
- 全量 108 标准图目标为 108/108 自动完成、PS 人工设计 0；首次无需修正率目标 ≥90%，即至少 98/108。
- 压力全量至少 40 项；适用项完成率 ≥95%，按 `ceil(0.95 × applicable_count)` 计算；任何严重科学错误阻断。
- 隐藏集至少 12 项；首次自动完成 ≥90%，12 项至少 11 项；最多 2 轮修正，严重科学错误 0。
- 至少 2 名独立视觉评阅者，五分制均分至少 4、任一单项不低于 3（FINAL §5 的初始建议，本候选固定为 v1）。

## 校准选择与限制

FINAL 要求数值容差、最小字号、色差/配准阈值在见结果前固定，但没有给出这些具体数值。本候选把数字答案设为精确相等、语义色 token ICC 前 ΔE00=0、叠加位移 0 px、最小字号 8 pt。这些是 D-085 的校准选择，供指挥席零采信验收；不声称来自 FINAL 原文，也不构成运行结果。

TS08 黄金输入的资格判据已按 G-205 写入，实际数据仍待用户解决。无真实黄金件时，比较规则只允许登记资格状态和命名约定；禁止把 `multi.tif` 当有效输入。全量 40 项压力清单的个别行没有在 FINAL 文件中编号；本批以 FINAL 具名维度建立 M1 子集本地 ID，并在映射表披露此点。
