## 10. 成果模板目录目标（20）

模板与配方维度不同：配方描述处理方法，模板描述成果的信息结构与视觉规范。不能通过简单换颜色/纸张大小制造新模板。

| 规划汇报10 | 科研专题10 |
|---|---|
| 区位与研究范围 | 研究区域与采样点 |
| 现状用地结构 | 分级设色与分布 |
| 公共服务直线覆盖 | 变化量与差异分布 |
| 真实路网可达性 | 分类转移与对照 |
| 生态约束叠加 | 空间自相关结果 |
| 规划冲突诊断 | 热点显著性分布 |
| 方案A/B对比 | 地形水文多面板 |
| 指标统计与空间分布 | 遥感多波段对照 |
| 分区管控图册 | 时间序列小多图 |
| 项目综合汇报展板 | 不确定性与误差表达 |

模板有真实数据要求，缺对应分析时不可仅填外观。科研结果中的显著性/不确定性必须来自相应方法，不由AI或PS美化生成。每个模板有中英文字体政策、颜色/单位/图例约束、母版、样例、验证记录；纸张和输出分辨率作为参数。
