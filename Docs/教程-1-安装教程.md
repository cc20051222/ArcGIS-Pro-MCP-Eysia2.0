## 第 1 步 · 确认前置条件（3 项）

| 项 | 要求 | 怎么确认 |
|---|---|---|
| ArcGIS Pro | **3.0–3.5（x64）**已正确安装（3.5 已实测；3.0–3.4 编译期兼容·未验证） | 打开 Pro，关于界面看版本号 |

## 第 2 步 · 核对完整性，然后完整解压

1. 把 ZIP 和 `.sha256` 放在同一个文件夹（例如 `D:\MCP-Install`）。
2. 打开命令提示符（Win+R 输入 `cmd` 回车），进入该目录后执行：

   ```bat
   certutil -hashfile ArcGIS-Pro-MCP-OneClick-1.0.2-r6-Windows-x64.zip SHA256
   ```

3. 把输出的一长串与 `.sha256` 文件里的值**逐字符比对**（大小写不敏感）。
   **不一致就不要安装**，让发送方重新发一份。
4. 右键 ZIP → **全部解压缩**（建议解到 `D:\MCP-Install\`）。
   ⚠️ **不要**在压缩包内直接双击运行（会缺文件）。

解压后你会看到：

```
ONE-CLICK-SETUP.cmd      ← 就点这个
RECOVERY-MENU.cmd        ← 出问题/要卸载时用
ROLLBACK-PLUGIN.cmd  UNINSTALL-PLUGIN.cmd  RESTORE-CLIENT.cmd
README-START-HERE.md    bundle-manifest.json
Docs\  Config\  scripts\  Source\  payload\
```

## 第 3 步 · 双击 `ONE-CLICK-SETUP.cmd`，选一次，确认一次

窗口里需要你做的选择：

| 选择项 | 怎么选 |
|---|---|
| 客户端 | 默认 **Codex**；用 **Cursor** 就选 Cursor；用 **DeepSeek Harness** 就选它；只想装插件不配客户端 → 勾选「**仅安装插件**」 |
| 项目目录（Codex / Cursor） | 选一个**真实存在**的项目文件夹，配置会写到该项目下 `.codex\config.toml` / `.cursor\mcp.json` |
| DeepSeek Harness | 写到你的用户目录 `.dsh\profiles\web\cordis.patch.yml`（不用选目录） |

点「开始一键部署」后**只确认一次**，随后自动执行 5 步：

1. 只读环境预检（不改动系统）
2. 包完整性校验（逐文件哈希 + 插件载荷身份）
3. **插件安装事务**（写前自动快照，失败可回滚）
4. **每个客户端的独立配置事务**（互不影响，没有"全部应用"）
5. HTTP 连接诊断（`tools/list` + 只读 `ping`）

> 安装器**不会**替你启动或关闭 ArcGIS Pro，也不会替你点插件里的 Start。

## 第 4 步 · 打开 Pro，点一次 Start

1. 打开 **ArcGIS Pro**，新建或打开一个工程。
2. 顶部找到 **MCP 选项卡** → 点击 **Start**。
3. 回到安装窗口（或重新运行 `ONE-CLICK-SETUP.cmd` 做诊断），看到：

   | 检查项 | 成功的样子 |
   |---|---|
   | 端口 | 6520 已监听 |
   | 工具发现 | `tools/list = 239` |
   | 只读调用 | `ping = pong` |

   只有这三项都对，才算"装好并能用"。**端口开着 ≠ 连上了。**

## 第 5 步 · 在你选的 AI 客户端里验证一次

1. **重启该 AI 客户端**（新会话才会加载到工具列表）。
2. 让它列出可用工具 → 应该能看到 **239** 个。
3. 试一句最简单的：**"调用 ping，并告诉我返回结果"** → 应返回 `pong`。

到这一步就算安装成功。接下来看 **`使用教程.md`**。

## 出错了怎么办（对照表）

| 提示 | 含义 | 你该做什么 |
|---|---|---|
| `COMPATIBILITY_NOT_PASS` | 环境缺东西（Pro 版本 / .NET 运行时 ≥ 6 / arcpy） | 按窗口提示补齐后重试 |
| `ARCGIS_PRO_RUNNING` | ArcGIS Pro 还开着 | **你先关闭 Pro**，安装器不会强杀 |
| `PROJECT_ROOT_NOT_FOUND` | 项目目录不存在 | 重新选一个真实存在的目录 |
| `CLIENT_RUNNING` | 目标客户端还开着 | 先关闭 Cursor 等，再重试 |
| `WAITING_USER_START` | 插件还没被 Start | 到 Pro 的 MCP 选项卡点 Start |
| `PORT_OPEN_NOT_MCP` | 6520 被别的程序占用 | 关掉占用它的程序再重试 |
| `STALE_BACKUP_REFUSED` | 目标文件在上次之后被手工改过 | 先备份你改的内容，再人工确认 |
| `BUNDLE_*` | 包缺件/被改动/哈希不符 | 重新获取完整 ZIP 并核对哈希 |

> 不要用「改端点、删备份、删 `.lock`、手删安装目录」来绕错误——那会破坏可回滚性。

## 卸载 / 回滚（随时可退）

| 想做的事 | 双击 |
|---|---|
| 回滚到装之前 | `ROLLBACK-PLUGIN.cmd` |
| 彻底卸载插件 | `UNINSTALL-PLUGIN.cmd` |
| 只恢复客户端配置 | `RESTORE-CLIENT.cmd` |
| 图形化操作面板 | `RECOVERY-MENU.cmd` |

事务账本在 `%LOCALAPPDATA%\ArcGISProMCP\installer`（**不要手工删**里面的索引与备份）。
