# GeoAIChat对标：公开优势、项目实情与补强决定

日期：2026-10-01。状态：**调研与规划交付候选，待指挥侧审阅；没有竞品运行验收。** 配套[最终方案](GIS_AUTOMATION_FINAL_PLAN_20261001.md)。

## 1. 对象与证据

对标对象为用户指定的 [GeoAIChat官网](https://www.geoaichat.cn/)，即ArcGIS Pro内AI助手。不是MBZUAI GeoChat遥感模型，也不是Xentity同名页面。

本轮读取官方HTML、页面展示内容及公开版本/技能接口；未登录、下载或安装竞品，未上传项目数据。web读取主页失败，HTTPS只读请求成功。公开能力是厂商声明；版本号和目录条数可直接核对；稳定性、效果和安全行为仍未经实测。

本地证据：[公开接口元数据、摘要hash与原规划hash](Research/GeoAIChat-20261001-evidence.json)。这里只保存公共元数据与目录ID，不复制竞品产品实现或技能脚本。

- D-106安装推进在飞，交付为PASS CANDIDATE，尚未闭环；D-107已CLOSED。
- 正式已验安装基线208工具/4B01E2AF…；磁盘新件A2D6A0D0…属于在飞事务，不能冒称已获独立验收。
- P-05真机与发布代裁授权已G-237到位，不能再次写“缺用户许可”；实际验收与依赖仍需完成。
- 现行是四线治理和写权时窗，不沿用历史全项目单ACTIVE或机械每批≤8。

20个PS接口已经注册，但主要业务仍按NOT_IMPLEMENTED/NOT_VERIFIED拒绝，`psRequestSent=false`。`ps_get_capabilities`只读本机通道路由状态，没有证明Adobe对端能力；源码的单写队列也仍标未实现。注册验收、通道健康和实际自动设计必须分开。

产品入口仍是Config.daml中的Start/Stop/Status/Run Tests/Diagnostics；本轮未发现完整聊天DockPane或Conversation/ModelProfile/Knowledge应用层。现有Invoker、Jobs、GIS素材包和质量工具应复用，不再从头写一套后端。

## 4. 行业深度怎么学

官方目录已有村庄规划、图则/界址、分类与占用检查、建库质检、CAD/坐标文本、底图/历史影像、专题图、海报和HTML展示等方向。[公开技能目录](https://www.geoaichat.cn/api/skills)

我们的BP01–BP10按原60场景的子例落地，不照目录再造同名工具：村庄/用地专题、规范建库、地块图则、区位多图框、调查分类、约束占用、CAD/坐标文本、底图与历史对比、交互展示、综合汇报。每包有真实合法输入、方法/规范版本、输出、失败条件和更新链；详细映射见[开发与验收](GIS_AUTOMATION_DEVELOPMENT_AND_ACCEPTANCE_20261001.md)。

国内规范和分类不得凭模型常识猜值。采用明确版本、适用地区、来源页码的规则包；用户未提供依据或存在冲突时集中确认。不能将官方技能目录的宣传当其数值、合规或准确性已通过验证。

## 5. 可形成优势的组合方向

| 方向 | 要完成的更高要求 | 证明方法 |
|---|---|---|
| 资料到可执行规则 | 引用规范之外，形成可测试Schema、约束和设计规则，记录采用/冲突/未知 | 带答案的规范文档与冲突负例 |
| 操作到可移植技能 | 将路径和图层泛化，绑定工具/方法/模板版本，换工程先做预检 | 多工程副本回放和失败恢复 |
| 分析到PS成稿 | 用户0次PS手工设计，真实排版、检查/有限修正、保存重开 | 108标准图与真实UXP操作证据 |
| 成果到持续更新 | 数据或规则变更触发依赖失效，所有已绑定数字/图例/文档同步 | 换期、改方法、改规范三类更新 |
| 美观到可证正确 | 科学硬门先于审美分，最终文件复验 | 已知数值/空间答案＋独立视觉评阅 |
| 单任务到多成果 | GIS/PDF/PSD/Word/Excel/PPT/长图与数据包同源且可追溯 | 跨文件事实一致、真实打开、可编辑性 |

这些是本项目要建立的组合能力，不宣称全球独创或现已领先。未发现对方PS链路公开证据，写作“公开证据未见”，不能断言对方绝无此能力。

## 6. 不应直接照搬的做法

任意脚本、未经验证的自生成工具、无范围的免确认、把知识文档当执行指令、自动公网上传或任意依赖安装，都不能因竞品采用或宣传就成为本项目授权。录制和技能默认只组合已审查的工具与类型化参数，公众技能市场后续按来源/许可/权限和质量审查。

“数据留在工程内”不证明调用远端模型时零数据外发。我们显示本次模型请求允许发送的类别，默认本地或无模型路径可用；发送元数据、摘录、统计和图像分别可控。

## 7. 公平比较与结论边界

共同任务比较用户操作、成功率、总时间、错误、成果质量和费用；对方支持但未实测的行先标DECLARED。PS/持续更新等公开证据不足的扩展任务单列本项目能力证据，不把它们当竞品失败制造优势。

数量也是本版硬目标：以285净名册完成稳定业务入口，并新增全量GP自动适配和≥max(2100, ceil(1.10×确证N))的准入/运行验证操作目标。GP包含分析、转换、建库、管理；独立语义能力另表。metadata发现、可调用、运行验证、接口数和技能数分账，不靠别名或参数变体加数。

同完整Esri宿主全集可能相同；要超出需真实额外操作来源，无法扩大时该维度报告持平。数量、科学质量和共同任务成功率分别过门，再判效率和视觉优势。10×3输入×3轮共同测试固定为每方90尝试，4扩展任务单列；真正的竞争结论在同任务、同资源、同人工介入规则测试后发布。
