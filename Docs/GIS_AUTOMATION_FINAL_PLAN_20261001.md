## 3. 产品由三层组成

1. **用户层：** 内嵌对话、数据/地图引用标签、用途卡、计划预览、成稿修改、成果中心和通知。普通用户不必切外部AI客户端或学习PS。
2. **智能与执行层：** 模型适配、上下文、方法/规范证据、配方、全量GP目录/类型编译/准入、统一计划/批准、现Invoker/作业、真实Pro/PS动作。
3. **成果与积累层：** FactTable、DesignSpec、版本/依赖、报告/工作簿/PPTX、技能/规则包、质量和比较证据。

外部MCP客户端保留为专业入口，与内嵌对话共用执行内核。没有模型时标准场景可用表单；本地模型需已有或按授权部署，不能暗含随包附送可用大模型。模型负责理解、提案和表达，实际工具与检查决定任务是否完成。

## 5. 八项进一步创新

### 5.1 用途驱动的成果合同

用户选择论文、汇报、图则、海报、数据交接后，系统生成可检查规格：输入条件、方法、最小字号、必需整饰、打印/屏幕、可编辑性、格式、来源与完成门。完成标准从任务开始就明确，不能到交付时临时降为“给了一张图”。

### 5.2 可见且带版本的地图指代

对话上方显示“地图：设施规划；范围：选中12个社区；数据：2026年”。模型引用的是身份/数量/版本明确的对象；地图切换、同名图层或截断选择都不能悄悄改变目标。截图辅助理解，不能代替精确空间身份。

### 5.3 从规范问答走到可测试规则

每条可执行规则保留条款位置、版本、适用地区、单位、例外和验证状态。规范说明、模型推论、业务批准分别存储。新文档不能直接获得执行权；预置已验证规则包让普通用户少做判断，未解条款不被自动忽略。

### 5.4 从流程录制走到可迁移技能

记录有类型操作，固定方法条件，泛化路径/字段/输入，去除一次性OID/token和原批准。在至少两个新数据集回放后，才成为可复用技能。成功聊天或一段脚本不足以成为已验证行业能力。

### 5.5 事实驱动的跨媒介制作

图件、统计、报告、Excel和PPTX同读FactTable；标题/图例/段落通过factRef引用。PS是默认视觉制作引擎；Office文件由独立文档适配器生成，不要求PS写办公文件。Word/PPT文字和Excel表格的承诺可编辑性实际检查。

### 5.6 地理保护与自动设计一起执行

DesignSpec编译布局，真实PS测量中文/混排、渲染检查、有限修正；保护图框、比例尺、图例、定量颜色和数字。装饰只改允许区域，不能通过父组效果或全局调整污染科学内容。

### 5.7 数据和规则变化都能驱动更新

新一期数据、采用新的规则版本、改变分析方法或设计意图，分别触发依赖影响分析。原成果保留，并声明使用的版本与有效范围；更新结果另存。规则变化不自动判旧成果在其历史时间点无效，也不暗中覆盖旧母版。

### 5.8 同一证据链支撑执行、解释与交付

用户点击图表数字或报告结论，可定位factId、计算步骤、输入和方法；计算有未知限制时成果同步表达。任务通知由真实状态变化触发，不能由模型一句“完成了”生成成功卡。

上述组合是本项目的创新重点，不使用未经证实的全球首创或独有表述。它们要靠真实任务、换项目复用和无PS经验用户验证形成优势。

GP规模工程把自动发现→元数据参数合同→副作用/许可/环境策略→批量准入→通用执行→逐项结果证据贯通。标准支持工具无需逐个手写包装；用户描述任务后，系统检索适用的小集合，不让模型和用户浏览整张2100工具表。

## 6. 最终范围与数量承诺的口径

| 对象 | 发行规划基准 | 完成条件 |
|---|---|---|
| 工具/语义底册 | 285净名册，224当前注册 | 未注册61项和所有受限/占位业务逐项处置；注册不代表实现或当前许可可用 |
| 受控GP操作 | 当前53，22项已批准扩容候选；新增全量自动适配工程 | 可信全集100%发现；完整合同编译率目标≥95%；准入并真实运行验证目标≥max(2100, ceil(1.10×N))，对照集合覆盖100% |
| MCP规模模式 | 稳定业务入口与可选生成gp__入口 | Composition唯一注册，算法/effects manifest一致；compact和granular同覆盖、不同入口数，语义重复不加数 |
| 完整场景 | 60条既有底册 | 正例、负例、更新、质量和交付，不以换行业名增数 |
| 模板 | 36套、规划18/科研18 | 规格转为可执行资产；108标准输入真实自动成图 |
| 压力与规则 | 现行60压力行、73规则等冻结资产 | 按原索引验证；新产品负例另列，不冲刷原失败或混用162侧档案与108标准图 |
| 产品能力 | U01–U12 | 原则变真实界面、契约、流程和测试 |
| 行业深度 | BP01–BP10 | 60场景的子例，完整数据/规则/模板/交换验收 |
| 多种交付 | GIS工程/数据、矢量PDF/SVG、PS视觉图/PSD、报告、XLSX、PPTX、长图 | 逐格式与宿主冻结支持矩阵，任何必需项未完不能整体报完成 |

现代数据格式、时间/三维/点云/遥感/科研/网络等8领域保持既有范围，逐项验证。CAD符号、报批TXT、XLSX等目前没有足够实现基础，要补独立适配服务和具体合同；不能因现工具有字符串format参数就声称可用。

这里N是冻结竞品版本在声明前提下、去重后的可执行GP操作数；GP包含分析、转换、建库和管理，独立语义能力另列。1900+不是精确1900，N确证后数量目标随之提高。完整编译率以全部发现操作为分母，不能先排除难项。计入已验证数的每项至少有合法真实正例、结果断言和关键负例。

数量领先按接口、独立业务操作、受控GP、技能、模板和完整任务分别比较。GeoAIChat命名工具口径尚不一致，因此当前不能用224对15、或285对1900宣布全面超越；也不能简单宣传285＋2100种独立能力。先冻结比较集合、同口径能力和真实支持条件。

同Pro版本、工具箱和许可的完整Esri全集可能相同，更多封装不能使全集变大。若要超出该上限，必须真实纳入对照未覆盖的系统操作或经审核的独立扩展；否则该维度如实持平，其他维度分别证明优势。数量目标进入发行功能门与资源计划，不退回永久53白名单，也不靠别名补数。

## 7. 不会PS用户的最终操作流程

**首次：** 安装已验插件→检测Pro/PS与许可→选择模型或无模型模式→选择D盘项目目录→样例出图。提供者Key、官方权限与配对必要动作采用向导，不让用户改配置文件。

**日常：**

1. 在Pro选择资料，点选/框选范围，或用@引用图层。
2. 说明用途，例如“用这些社区分析公共服务，做汇报图和PPT”。
3. 看一张任务卡，集中确认方法、必要歧义、输出目录与交付范围。
4. 系统分析、制图、PS排版、检查修正，展示已经合格的推荐稿。
5. 说“更简洁、改横版、沿用上月风格”，或点击快捷修改；可撤销比较。
6. 在成果中心打开、加地图、领取文件；换新资料时选择更新，得到新版。

正常路径无需打开外部聊天程序、人工导入PS、建蒙版、改图层或逐文件抄数字。无模型表单可完成已验标准场景；模型不可用不影响已批准作业和已完成成果。

## 9. 两条旗舰示范链

**规划链：** 输入调查GDB、人口设施、规程和拥有的模板→识别/规范建库→约束占用/路网覆盖/方案比较→图则与区位多图框→PS自动汇报版式→Excel指标/Word说明/PPTX→更新新一期或新方案。缺真实路网或扩展许可时明确方法边界，不以直线缓冲冒充时间可达。

**科研链：** 输入多期影像/样点/参考数据/方法要求→质量与格网检查→受控分类/趋势/误差→固定分类与科学图件→PS论文多面板→表格/方法引用/补充材料→换数据重算与可复现新版。缺独立参考时不编造分类精度和可信区间。

国内规则、模型和数据的适用条件由冻结来源决定；本稿不提供未经核对的政策数值或新的专业结论。

## 11. 如何确认最终领先

先通过自身功能门：GP数量/覆盖与逐项证据达标、108标准图全部自动完成、0次PS手工设计、严重科学错误为0、60场景和产品/行业包有完整证据。再用10项共同任务（10×3输入×3轮＝每方90尝试）和4项扩展任务比较，分别记录安装/模板准备、主动操作、总时间、费用、成功和质量。

领先目标：数量、科学质量与共同任务成功率分别过门，成功率不低于最优对照；人工操作时间降低≥50%、总耗时降低≥30%、盲评胜率≥70%三项至少两项达到预先固定的实质改善，同时披露区间和样本量。盲评胜率为胜出数/全部有效配对评价，平局进入分母；失败保留。只有一方支持的任务报告能力证据，不算速度倍数。

本次最终稿的“保证”落实为严格完成门和持续证据：达不到就整改，不把注册、界面演示、占位模型或手工代操作写成完成。任何全面领先结论限定产品版本、范围、条件和测试日期。
