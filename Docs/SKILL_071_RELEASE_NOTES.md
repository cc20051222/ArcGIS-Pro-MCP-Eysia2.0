## 0.7.1 本轮改进

新增三维与原生界面方法参考，要求验证真实Z与相对高度、区别地下阴影体与地面阴影、检查日期/时区/DST、保留旧失败及重新核验。解释轮廓转面产生更多分面的合理情形，避免错误计数断言或直接改预期凑通过。

完善双地图框范围/朝向读回、比例尺真实单位检查、多面体符号限制与原生窗口前台核验。更正旧水文说明：目录已有Fill/FlowDirection/Watershed等候选，不再笼统说没有入口；仍需现场许可与真实DEM链验证。

更新配套安装器识别0.7.1并校验kind/version一致，Plan读回实际Skill版本；旧0.7.0兼容保留。安装、使用、功能原理与两份Word随包同步。

启动器补齐D盘临时产物根、地图回图暂存与栅格TempFolders，并对每个运行目录做实际可写探针。这些设置只对新启动进程生效；实际水文并行环境仍需在对应任务核验。
