# 功能覆盖、格式动作与支持账本

日期：2026-10-01。全部新增项为规划合同，不能因出现在本表就视为已实现。配套[总纲](README_FINAL.md)、[实现计划](IMPLEMENTATION_AND_RELEASE_PLAN.md)。

## 1. 功能支持的统一口径

建立拟议`CapabilitySupportManifest`，同时驱动工作台能力显示、工具检索、安装预检、帮助和发布支持表。至少包含：capabilityId/canonicalOperationId、需求来源、M/U/X/BP/S/模板映射、接口或内部职责、输入/输出/动作、契约和实现版本、effects/批准范围、许可/依赖、规模/资源限额、已验证证据、限制和替代方案。

两轴分别记录：

- 开发证据：DECLARED→CONTRACT_DEFINED→IMPLEMENTED→RUNTIME_VERIFIED→E2E_VERIFIED→INDEPENDENTLY_ACCEPTED。每级必须有可回读证据；不能由上一级名称推定下一级。
- 当前环境：AVAILABLE / CONDITIONAL / UNAVAILABLE / UNKNOWN，附具体缺口。可用性不是源码成熟度，目录发现也不是运行正例。

注册、工具发现、GP正例、PS动作、完整任务独立存证。当前224注册/装机发现不统一标为224 E2E通过。本稿不自动给285项或格式填写已验证状态。

同一操作的专用入口、GP入口、别名、旧新名字和技能引用共用canonicalOperationId；有依据的语义差别才另计。内部智能服务、格式adapter、主题皮肤和行业名不计独立GP数量。

## 3. 格式×动作目标矩阵

以下是**目标动作合同**，每格在正式支持账本再绑定版本、规模、adapter和证据；空白证据即未验证。读取/转换为另一格式不能冒称编辑或回写原格式。所有写入都限批准范围及拥有产物。

| 格式/来源 | 发现、读与查询目标 | 写入/交换目标 | 关键验收 |
|---|---|---|---|
| FileGDB | 数据集/字段/域/关系/空间查询 | 拥有库创建/编辑/产出与交接 | 锁、域/子类型/关系、Z/M、精度、恢复 |
| SHP | 编码/几何/属性/CRS | 写新件，侧车整体交接 | 字段截断/空值/编码限制与丢失清单 |
| CSV | 编码/分隔/日期/数值/坐标 | 带字段/单位元数据新表 | 小数与日期、引号/换行、注入式公式、往返 |
| XLSX | 多sheet/表头/合并格/类型/公式缓存 | 真工作簿，拥有副本更新/交接 | 公式与值分开、日期/精度/空值、可编辑性 |
| GeoJSON | 几何/属性/规范CRS语义 | 新标准文件 | 坐标/轴顺序、Z、精度、语义损失 |
| GeoPackage | 图层/几何/属性查询 | 受控转换/写新容器 | 规范版本、几何列、索引/完整性、往返 |
| GeoParquet | schema/几何/分区查询 | 经审查adapter写新件 | metadata/CRS/轴顺序、多几何、分区过滤 |
| FlatGeobuf | 发现/空间范围读 | 经审查adapter写新件 | 空间索引、字段/精度、往返 |
| GeoTIFF | 波段/格网/NoData/像元查询 | 分块/整体写新栅格 | 像元类型、变换、掩膜、位深、边界 |
| COG | tiled/overview识别、本地或受控range读取 | 合规COG输出 | 结构与像元语义，普通TIFF不能自动标COG |
| NetCDF | 变量/维度/时间/单位与范围 | 明确科学立方输出合同 | 历法/维序/单位/NoData，往返维度一致 |
| Zarr | 维度/chunk/schema读 | 经审查固定adapter写新立方 | chunk/元数据一致、部分失败、实际格式版本 |
| LAS | 点/类别/密度/Z基准 | 过滤/分类副本与派生地表 | 点数/类别守恒、Z基准、边界 |
| LAZ | 经审查解码、范围/类别读取 | 编码路径及许可确认后按合同输出 | 压缩与LAS语义一致；没有编码证据不称可写 |
| COPC | 层级/范围随机读取 | 已验写入adapter成立后才对外承诺 | 层级/范围完整、压缩/点属性、规模 |
| CAD | 图层/几何/文字/符号读入 | 有限DWG/DXF等版本的符号映射导出 | 单位/CRS/字体/曲线/丢失项/回导误差 |
| 坐标TXT | 冻结CoordinateTextProfile解析 | 同profile规范输出 | 编码/精度/环向/闭合/分组与来源版本 |
| STAC | 目录/Item/资产/时间空间搜索 | 合同确定后输出拥有目录/交接引用 | 分页/来源/许可、资产可用性/范围 |
| OGC服务 | 经验证的协议/能力/分页/范围读取 | 写服务/发布单独明确scope及授权 | 凭据、请求上限、轴顺序、失败/离线 |
| ArcGIS服务 | Feature/Image等能力分开读 | 有权限的编辑/发布按具体合同 | 服务限制、分页完整、计费/登录/来源 |
| PDF/Word/扫描资料 | 文本/表格/页定位/OCR候选 | 生成规则/Schema草稿，不覆写原件 | 黄金字段/数值、低可信关键单元格和引用 |

科学数据不会因扩展名识别成功就具备所有读写动作。目标format/action在实际宿主不成立时进入固定adapter/变更/支持限制裁定，不用开关掩盖；最终不得发布仍标UNKNOWN的承诺格。

COG利用组织结构和服务范围读取；STAC用于资产目录/搜索，两者不是可互换的数据读写引擎。相应adapter仍需本产品实测。[OGC COG](https://www.ogc.org/standards/ogc-cloud-optimized-geotiff/)、[STAC](https://stacspec.org/en)

## 4. 原始资料到可用数据

U06/U07增加`SourceDocumentProfile`/`ExtractedCell`/`SchemaCandidate`/`MappingDecision`：sheet/单元格/页/原字符串、抽取方法与证据、候选值/单位、类型/别名映射、歧义和采用记录。处理多行表头、合并格、编码、小数/日期、度分秒、分组字段和缺失值。

缺CRS不可仅看坐标大小自动定义；OCR字符不能直接成为数值事实或写入规则。已验映射可自动采用，关键未知集中呈现；来源表、推断和采用值都保留。不能用原表抽取成功推定新规范所有条款都已识别。

## 8. 团队交接、离线与可访问性

ProjectPackageSpec保留拥有副本或有效数据引用、FactTable、方法/模型/规则/模板锁、DesignSpec/Patch、回执/限制、字体/素材来源和兼容条件；凭据仅引用，不带出。另一个D盘目录打开、预检、重放和更新，缺依赖定位到具体项。授权范围与环境凭据不随包迁移。

离线标准表单、已配本地模型、帮助和已下载合法资源分别验证；断网不伪称远端功能可用。缺PS时可用GIS功能明确展示，但不能作为全链设计验收通过。键盘、焦点顺序、高DPI、中文混排、字体替代、色觉/灰度/字号和可理解错误均为产品门，不仅是宣传标签。
