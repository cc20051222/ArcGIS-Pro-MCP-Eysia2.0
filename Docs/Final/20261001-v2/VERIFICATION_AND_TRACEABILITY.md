## 4. GP2100逐项证据与oracle

计入可验证数量的每项在声明参考环境有至少一个真实合法运行正例，并核验结果/产物/状态及关键负例。缺许可/正确拒绝/schema采集/mock/同族代表成功只提供对应证据，不替代正例。允许条件和未测参数范围公开，不能由一次运行宣称所有参数组合均已验证。

| 操作族 | 必要结果判据示例 |
|---|---|
| 几何/缓冲/叠加 | 已知位置/距离、面积/覆盖/分组守恒、拓扑与容差 |
| 变换/转换 | 冻结CRS/单位/变换、往返误差、字段/编码/精度损失 |
| 字段/域/关系/管理 | schema/属性实际变化、依赖完整、只在批准输入/输出范围发生 |
| 栅格/多维 | 格网/像元/NoData、波段/维度/时间/单位、整体与分块一致 |
| 网络/科研/时序 | 真实约束/已知答案、方法假设/参考独立、不虚构误差或因果 |
| 点云/三维 | 点数/类别/高程基准/模型误差、边界和归并 |

每项保存catalog/codec/policy/宿主/许可版本、输入digest、typedArgs、环境/作用范围、request/job/intent、原始结果/断言/receipt、失败与复核。输出存在但内容错误的注入必须被检查发现。

许可/参考环境不足的项如实列缺口，不计本机AVAILABLE；在具备前提的参考环境通过可列CONDITIONAL。两产品比较环境同口径；本机不能执行的操作不能宣传当前无需任何条件可用。

## 6. 故障、资源与输入一致性

每类副作用在调用前、调用中、宿主完成后/receipt前、交付激活前注入中断；可复现状态为未执行/完成/部分/未知。未知对账停止不能算幂等成功；恢复不凭文件存在推定内容完整。

重点矩阵：旧owner/fence、尾日志损坏、写前intent磁盘满（零执行）、写后receipt失败（不重发）、存在性Unknown、取消不可立即生效、Pro/PS busy/退出/token/端口冲突、输入中途修改/删除、地图完成PPT失败、候选目录残留、同项目并发写。

GP/PS/模型同时负载测预约/峰值/队列公平；硬件未知时保守处理，不默认资源无限。规模继承原百万要素、大栅格和100页测试；每算法可拆分traits验证边界/halo/全局统计/归并，整算等价且无漏页/重复。

GP环境显式绑定/隔离/恢复；原位输入、派生/侧车/中间产物全进作用范围。D盘写探针/空间/日志/回执实际检查；宿主伴随物如实披露，不能删除C盘物或改变系统TEMP掩盖问题。

输入一致性来源有明确机制或拥有副本；变化后作业失效/重编译，不发布混期结果。交付manifest只激活全通过revision；这不是跨宿主全局事务。更新/回滚保留原件、旧事实/设计/规则及当时有效依据。
