# 三条业务链：步骤合同、检查点和黄金规格

日期：2026-10-01。以下为未来合成 fixture 与实现配方，**没有创建实际 GIS 数据、运行 GP/PS 或产生真机证据**。所有演示数值明确属于合成规格；真实任务采用自身资料和合法方法。配套[共同合同](DOMAIN_CONTRACTS_AND_STATE_MACHINES.md)。

## 1. 规划汇报：设施覆盖与方案比较

| 步骤 | 类型化输入 → 输出 | 检查点 / 失败与更新 |
|---|---|---|
| P01 绑定资料 | 社区/人口/设施/网络/时段 → DatasetContract、InputSnapshot、实体映射 | 重复 ID、时相/CRS/单位、选择全集；映射不明集中确认 |
| P02 判断充分性 | 问题目的+资料+方法条件 → DataAdequacyReport | 沿路时间需网络/成本模式/许可；人口覆盖需分配/分母依据 |
| P03 决定方法 | 合格方法+已采用口径 → DecisionRecord、AnalysisPlan | 网络和直线距离不是等价替代；越界变化另立计划 revision |
| P04 算可达性 | 设施/网络/成本/时段 → CoverageSet、ReachabilityStatus | 明确已知可达/不可达/未知；断路与网络外对象不能都记不可达 |
| P05 归属人口 | CoverageSet+人口分配合同 → CoverageFacts | 设施重叠去重；分配估计不冒充精确人口；未知不变零 |
| P06 比较方案 | 同输入/时段/方法/分母+批准变量 → ComparableScenarioSet、FactTable | 方案不能偷换人口、删约束或放宽质量门；试验与正式采用分开 |
| P07 制图设计 | 已验事实+规划模板 → GIS 素材、DesignSpec、PS CommandPlan | 指北/比例/图例同源；正文数字有 ClaimBinding；真实文字尺寸 |
| P08 办公交付 | 同版事实/视觉图 → XLSX/PPTX、按合同 DOCX、DeliveryRevision | 真打开、可编辑部分、逐指标一致；必需文件缺失不能全交付 |
| P09 更新 | 人口/设施/网络/风格差异 → UpdateImpactPlan | 人口变重算指标，网络变重算可达性，字体变重排；旧版保留 |

CoverageSet 用稳定实体/空间归属键表示集合，必须声明边界归属规则。人口栅格/面汇总/需求点是不同分配模型，不能为了方便自动互换。距离/时间与人口事实分别验证；没有网络许可或资料，系统先列缺口，不调用未准入方法。

### PL-GOLD-01：重叠覆盖手算规格

四需求点 A/B/C/D 的人口权重为 50/30/20/40；两个设施的覆盖集分别 AB、BC。已冻结实体和人口归属，没有未知值。

- 总人口 140；设施一覆盖 80，设施二覆盖 50；共同覆盖 B=30。
- 联合覆盖 A∪B∪C=100；未覆盖 D=40；覆盖率 100/140=71.428571…%。
- 逐设施相加的 130 不得用于联合覆盖率；图/表/PPT 的显示值来自同一个原值与精度规则。
- 这是 CoverageFacts/集合与算术 oracle，**不证明网络 service-area 真执行**；未来网络 fixture 必须另验路网、成本模式和真实结果。

PL-NEG-01 把 D 人口设 null：总体人口和总体覆盖率未知，不得仍用 140。若用户明确采用“已知人口记录口径”，另立 denominatorRef，已知总量 100/已知覆盖 100，并说明 D 人口缺失；不能称总体覆盖 100%。PL-NEG-02 改成“沿路 15 分钟”而只有平面坐标，应在方法充分性门停止。

## 2. 科研专题：多期分类变化

| 步骤 | 类型化输入 → 输出 | 检查点 / 失败与更新 |
|---|---|---|
| S01 分类语义 | 分类栅格/来源/类别字典/QA → ClassMappingDecision | 相同类别码不保证同含义；合并类别需采用记录 |
| S02 格网计划 | CRS/变换/范围/分辨率/锚点/重采样 → AlignmentPlan | 分类与连续值方法分开；地理坐标不能用角度格面积当 m² |
| S03 可比范围 | 两期掩膜/范围规则 → ComparisonMask、缺测区事实 | 交集/并集/缺测区分开；NoData 不归成普通类别 |
| S04 计算 | 同格网分类+可比掩膜+面积模型 → TransitionFacts、边际面积 | 行列边际和各期面积一致；有效面积守恒；输出数量/单位都核验 |
| S05 科学解释 | 事实+来源/参考条件 → ScientificClaims、limitations | 净变化≠总变化；无参考不编精度；分类变化不自动变真实地物/因果变化 |
| S06 论文图 | 同版类别/事实+多面板模板 → DesignSpec、GIS 精确图和 PS 视觉图 | 跨期颜色/类别固定；图例完整；PS 不能改量化色带/科学区域 |
| S07 交付 | 已验事实/方法/图 → 原始统计表、矢量 PDF/SVG/EPS（按支持合同）、PNG/TIFF/PSD | 实际文件/字体/ICC/印刷与编辑性分账；矢量图不来自 PS 栅格层冒充 |
| S08 新期次 | 新资料/类别/格网/模板 → UpdateImpactPlan | 类别/格网变使计算与科学图失效；仅风格变化保留分析事实 |

若输入只有原始影像而非分类结果，应另登记分类方法、训练、模型与验证流程，不能把本链的统计验收扩张成影像分类模型成功。分块执行需全图同口径、边界与归并等价，不能默认所有工具可切块。

### SCI-GOLD-01：净变化为零但存在真实分类转移

T0=`[[1,1,2],[2,0,1]]`，T1=`[[1,2,2],[1,0,1]]`；0 为 NoData，固定同格网投影，每格 100 m²。

| T0 \ T1 | 1 | 2 | T0 边际 |
|---|---:|---:|---:|
| 1 | 2 | 1 | 3 |
| 2 | 1 | 1 | 2 |
| T1 边际 | 3 | 2 | 5 |

有效格数 5、有效面积 500 m²；变化格数 2、变化面积 200 m²、变化比例 40%；两类别净面积变化均为 0 m²。系统必须同时报告净变化与双向转移，不能用“净变化为零”写“没有变化”。

SCI-NEG-01 将 NoData 算普通类别，错误有效面积 600 m²，oracle 必须拒绝。SCI-NEG-02 无参考样本却生成“精度 95%”，必须拒绝该声明。SCI-NEG-03 修改一个格网锚点但沿用旧检查点，应使复用门失效。

这是离散分类/面积算术规格，不是 ArcGIS 真机栅格验证；真实 fixture 另测 CRS/变换/重采样/NoData 与实际工具结果。

## 3. 规范建库：资料到已查条款覆盖

| 步骤 | 类型化输入 → 输出 | 检查点 / 失败与更新 |
|---|---|---|
| N01 定位资料 | 页/表/单元格/原字符串 → ExtractedCell、ClauseCandidate | 原字符和定位保留；OCR 分数不等于条款正确 |
| N02 解析候选 | 文本/脚注/单位 → ApplicabilityPredicate、ConstraintCandidate | 应/宜/可/不得、上下界、例外、地区/日期逐项结构化 |
| N03 采用规则 | 候选+专业已知答案/正负例 → immutable RulePack | 每适用分支有已验依据；普通用户使用已验包，不自动批准模型规则 |
| N04 计划 schema | 规则/原 schema/Host 能力 → SchemaPlan、MigrationPlan | alias/default/required 分别确认；QC 规则不冒充数据库内建约束 |
| N05 建库副本 | 拥有输出计划/已批准映射 → candidate 数据库、ID/字段映射、拒绝记录 | 原件不变；无损/有损转换与被拒项可追溯；不以删坏数据“修好” |
| N06 检查内容 | 候选库/RulePack → QCReport | PASS/FAIL/UNKNOWN/NOT_APPLICABLE 分开；缺关键字段不绿灯 |
| N07 合规说明 | QCReport+条款覆盖 → ComplianceCoverageReport | 已查/未查/不适用分母明示；不笼统写“完全合规” |
| N08 更新 | 规范/日期/字段/数据变更 → ImpactPlan、新库 revision | 旧版保留当时依据；新版规则不接管旧任务或偷偷扩大作用域 |

### NORM-GOLD-01：合成练习规则，非真实法规

规则 R1：记录位于合成区域 IN、非 exempt 且时点适用时，高度必须 ≤10 m。本规格七条记录均固定在已采用规则有效期内，没有未知日期；真实任务仍逐项核查时间。exempt 是已采用例外；区域 OUT 不适用；适用性字段未知则 UNKNOWN。固定长度单位表 100 cm=1 m。

| 记录 | 区域 / 例外 | 原高度 | 预期 |
|---|---|---|---|
| A | IN / false | 9 m | PASS |
| B | IN / false | 11 m | FAIL |
| C | IN / false | null | UNKNOWN（missing-height） |
| D | OUT / false | 20 m | NOT_APPLICABLE（outside-area） |
| E | IN / true | 11 m | NOT_APPLICABLE（adopted-exception） |
| F | IN / false | 1000 cm | PASS（恰等于 10 m） |
| G | unknown / false | 9 m | UNKNOWN（unknown-applicability） |

预期计数 PASS=2、FAIL=1、UNKNOWN=2、NOT_APPLICABLE=2，总计 7。已确定适用者为 A/B/C/F 共 4 条；其中已评估结果 A/B/F 三条、C 缺值。不能用“通过 2/7”代替适用合规比例，也不能把 C/G 或不适用项当通过。

此规则练习只用于检验逻辑，不是合规结论。真实 RulePack 必须绑定真实规范版本/适用范围/专业采用记录。重复实体键、未知单位、否定和脚注改变适用范围的变体另作关键反例。

## 4. 三链共用的恢复与改稿语义

- 中断前已验事实只在版本/输出/oracle/归属复验后复用；部分或未知 effects 先对账。
- 改标题字号是 StylePatch；改类别、单位、分母、方法或适用规范是 Analysis/RulePatch，不能仅重新画图。
- 每张图和每个办公数字引用同一事实版本；所有必需文件通过才激活交付。某链只完成数据处理不能冒称 GIS→PS→Office 全链完成。
- 专业资料不足是明确缺口。目标是通过优质资源包和检查降低普通用户介入，不让模型替用户猜专业前提。
