# 格式动作、转换损失与声明式资源包

日期：2026-10-01。内部拟议规格。继承V2的21个格式/来源族，新增独立动作和采用约束；**不是21个格式已全支持，更不是105项已验能力**。

## 1. SP05 FormatActionSupportRow

主键为 `formatId + formatVersion + action + adapterId/version + supportedDomainDigest`。action分别为 READ、WRITE_NEW、QUERY、EDIT_OWNED、ROUND_TRIP；发现扩展名仅是DISCOVERY，不进入五类业务成功计数。

每条至少包含：输入/输出真实格式与版本、几何/栅格/字段/编码/NoData/CRS域、容器成员、规模范围、Host/许可/依赖、参数与effects、损失策略、完整性/内容oracle、成熟度/环境可用性、实证、已知限制和替代路径。

| 动作 | 独立成功合同 | 常见错误推定 |
|---|---|---|
| READ | 实际解析完整目标范围，内容/类型/单位正确 | 扩展名识别=读取成功 |
| WRITE_NEW | 新拥有文件/容器及成员、内容/结构有效 | 任意文件存在=标准格式输出 |
| QUERY | 查询语义、范围/分页/截断/空值和完整集合 | 返回第一页=全集 |
| EDIT_OWNED | 已批准对象/内容修改、版本与效果对账 | 读Excel再写GDB=编辑Excel |
| ROUND_TRIP | 固定A→B→A链，结构/属性/几何/CRS和声明损失对照 | 两次转换均exit0=无损往返 |

已验READ不能推出WRITE_NEW/EDIT_OWNED。某动作不在目标范围，要基于实际任务和格式语义明确标NOT_IN_SCOPE，不得为删掉失败分母临时改变范围。格式版本未知保持未知；一个无限制string参数不是全部版本支持。

## 2. SP05配套 ConversionPlan / LossReport

LossReport按字段/对象/波段/时间维度列原语义、转换后语义、丢失/截断/精度/编码/CRS/NoData变化、是否可逆、所用oracle和采用依据；未知损失单列，不显示“无损”。

科学分析输入默认不能接受会改变事实口径的隐式损失。任务确实要求简化或某受限格式时，先冻结可接受损失及其比较方法，形成显式ConversionPlan；不能把用户选择一个格式解释成同意所有字段/精度/几何损失。

名称截断、精度转换、日期/时区、空字符串/null、Z/M、曲线/环向、轴顺序、格网/位深、类别/NoData、点属性、历法/维度均按具体支持域检查。oracle可以比较语义而非二进制一致，但须记录容差/不支持项，不能选宽容差掩盖错误。

输出带 ConversionReceipt、原ID→新ID/字段映射、损失清单、被拒记录和内容证据；用户原件保留。SHP多成员、GDB成员、分区数据和科学立方不能只用File.Exists证明完成。

## 3. 二十一个格式/来源族的实现约束

| 族 | 逐动作实现时的最低重点 |
|---|---|
| FileGDB | schema/域/子类型/关系、锁/版本、拥有库编辑与恢复 |
| SHP | 全侧车成员、字段/编码/null限制、几何/CRS与损失清单 |
| CSV | 分隔/引号/换行/编码、日期/小数/空值，生成表格时公式式内容语义明确 |
| XLSX | sheet/合并格/公式与缓存值分开、日期/精度；编辑拥有副本且保留声明部分 |
| GeoJSON | 实际标准语义、坐标/CRS与轴顺序、属性/几何限制 |
| GeoPackage | 容器完整性、几何列/schema/索引、拥有库修改与往返 |
| GeoParquet | 实际metadata/CRS/几何列/版本和分区过滤，不以普通Parquet代替 |
| FlatGeobuf | schema、空间索引/范围查询、完整性与实际编码能力 |
| GeoTIFF | 像元/格网/掩膜/NoData/位深、成员与内容oracle |
| COG | 独立结构合规与像元检查；普通GeoTIFF不自动标COG |
| NetCDF | 变量/维序/历法/单位/缺测，读写与切片合同分别验 |
| Zarr | 明确实际版本、chunk/元数据、部分失败和科学语义 |
| LAS | 点数/类别/属性、Z基准、过滤范围与边界 |
| LAZ | 已验解码/编码adapter与来源/许可，压缩不改变点语义 |
| COPC | 层级/范围完整、点属性与实际可写路径，不由LAZ支持推定 |
| CAD | 明确DWG/DXF等版本、图层/文字/曲线/单位/CRS与回导误差 |
| 坐标TXT | 固定CoordinateTextProfile、精度/闭合/环向/分组及往返 |
| STAC | 目录/Item/资产、分页/时间空间查询、资产可用性与来源 |
| OGC服务 | 具体协议/服务能力/轴顺序/分页/网络权限；写服务不由读推出 |
| ArcGIS服务 | Feature/Image等分别验范围/分页/版本/权限/计费与编辑效果 |
| PDF/Word/扫描来源 | 原页/单元格/字符定位、OCR关键字段采用；源资料编辑与生成报告分开 |

这21族先生成格式×五动作工作池，逐项确定有意义的目标范围和adapter/版本；**105候选格只是需裁定的记录数**。每个正式承诺格需要真实正例、关键负例与内容oracle，往返另外验整条链。来源族内部的子格式/版本不能用合并一行取消测试。

实现优先级随三条标准链的具体需求推进：核心数据/表格→明确CAD/TXT互通→现代大数据/服务/科学数据，全部目标最终按V2范围完成，优先顺序不删最终目标。新adapter/依赖/公开合同按现SC裁定，不自动安装GDAL/编码器或下载库。

## 4. SP06 ResourcePackManifest

包的最小字段：packId/version/digest、内容schema、作者/来源/许可与有效期、逐成员摘要、闭合内容类型、依赖锁、Host/模型/格式/字体/ICC兼容条件、适用数据/方法、准入操作引用、表单/模板/规则引用、正负例/新数据回放、离线条件、采用/停用记录。

内容白名单是声明式配方、受限规则AST、Design/Office模板规格、静态素材/符号、方法卡/引用、合成样例与证据元数据。固定解释器只执行既有已准入操作；表达式没有文件/网络/任意代码权限，资源文本中的指令没有执行权。

包不能带凭据、历史批准、本机token、用户工程绝对路径、任意Python/JS、DLL、安装命令或动态依赖下载。产品adapter二进制是独立受评审发行组件，不伪装成可随导入执行的资源内容。合法字体/ICC/素材可作为声明资源，但需逐件来源/许可、固定解析与真实兼容验证。

hash证明与给定摘要一致，不证明来源可信或科学正确；作者自填trusted字段不授信。来源身份按外部已配置的信任/采用政策核验，必要签名按实际分发方案检验；签名/版权声明不代替规则/方法oracle。

## 5. 导入、采用、停用与交接

1. 导入前读取有上限的manifest与成员列表；路径、大小/数量、重复成员、链接/别名、压缩展开范围和schema校验。
2. 核对内容类型/摘要/来源、依赖版本和循环/冲突；逐格式固定解析，不加载任意脚本。
3. 对照当前环境/支持条目，检查字体/ICC/方法/准入/许可/模型/离线条件。
4. 导入仅检查现有已知答案、反例和新资料资格证据，证据必须与包/依赖版本对应且来源可回读。缺少合成已知答案、反例或至少两份不同合格新资料回放时，保持等待资格的候选；实际回放由另一个有当前批准、拥有 fixture 和共同执行闸门的资格作业完成，导入本身不触发 GIS/PS 动作。
5. 按授权范围和独立验收采用不可变版本；新任务可选择，旧任务继续锁旧版。
6. 停用影响未来选择；保留历史/在途/回滚依赖，不删除用户成果或旧任务依据。

上述为成功路径，另有 WAITING_REQUIRED_CAPABILITY、WAITING_QUALIFICATION、WAITING_ADOPTION 和 REJECTED，均记录具体原因。包内作者自填 QUALIFIED/ADOPTED 不推进本机状态；独立证据核验、资格作业和采用记录来自本机受控流程。导入作业与资格作业分别留 ID、状态和回执，不能以一次导入替用户启动回放。

声明式包schema和文件名不能证明内容安全。静态素材中若含可执行/外部链接/宏等不属于允许内容，拒绝或经正式独立支持合同处理；不能借模板绕过任意代码红线。

ProjectPackage交接只带拥有副本/合法引用、逻辑连接角色和锁定资源，不带机器权限。第二个D盘目录重新绑定数据、模型endpoint/凭据和当前批准，再预检/重放；“另存成功”不是他人机器可复算证明。

## 6. 离线、更新与冲突

每包标OFFLINE_READY、CONDITIONALLY_OFFLINE或NETWORK_REQUIRED及条件；本地有模板但缺字体/图层/许可/远程数据，仍不能完整离线。更新生成新版本和影响预览；规范或方法改变不自动采用到旧任务。

多个包同语义ID/schema或条件冲突明确拒绝或采用有依据的合并决定。个人视觉偏好不覆盖专业规则/科学保护；新模板不得偷换分类颜色/分母。格式adapter或资源版本变化使相关支持条目与检查点失效，重新验证后才恢复资格。

## 7. 关键验收

损坏/路径逃逸/重复成员/未知类型/过大展开、依赖循环/冲突、缺字体/ICC/许可、陈旧操作、资源注入文本、凭据/token/批准残留、断网/第二目录和版本停用均有反例。固定负例包只验证解释器/导入策略；真实包的专业质量、格式业务和全链仍分别验。

每格式承诺格保留失败分母和支持域；READ通过但WRITE失败应显示两个状态。LossReport未知不得显示无损；明确损失得到采用后仍核验实际损失，不能靠提示一句“可能丢失”省掉质量验收。
