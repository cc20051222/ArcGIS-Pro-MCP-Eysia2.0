## 一、输入档案

- **分析输入策略**：`domain-known-answer-required / NOT-AVAILABLE-PENDING-USER`。
- **所需数据**：计算边界、施工前/后两高程面（须共网格）、NoData 掩膜、像元面积、垂直基准/单位。
- **合格输入现状**：无共网格前后高程面、3D Analyst 许可未探测 ⇒ `NOT-AVAILABLE-PENDING-USER`。
- **负向档案（invalid）**：两面像元尺寸/网格不一致、垂直基准不匹配、NoData 未声明 → 输出前拒绝，不静默重采样强行对齐。

## 二、比较规则引用（逐字 ID，零自定义）

- `GBC-001`、`KDA-001`
- `NUM-001`（计数/求和自洽）
- `SCN-003`（剖面与体积是数值答案，NoData/基准须声明）

## 三、压力维度

- **ST-M4-08**：两高程网格像元尺寸不同的土方；预期 **REJECT**——输出前以网格不一致拒绝，不静默重采样迫使一致（SCN-003/ALN-001）。
- 通用延伸：大区域、大量 NoData、临界平衡（挖≈填）；FINAL §4 未枚举 ID 待后续批。

## 四、判据引用（规则要点，不新增阈值）

- 挖填体积由 Σ(像元面积×Δz) 在公布掩膜上重算；平衡、NoData 掩膜、垂直基准须声明（SCN-003）。
- 前后两面须在共网格、基准一致；无法由公布像元重算的体积判失败（SCN-003/NUM-001）。
- 表与栅格来自同一次运行（same-source，design demands）。
- D-097 候选：体积重算一致相对误差 0.01（d097CalibrationChoice，**待指挥席复核，非定论**）。
