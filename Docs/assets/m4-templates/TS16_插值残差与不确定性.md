## 一、输入档案

- **分析输入策略**：`domain-known-answer-required / NOT-AVAILABLE-PENDING-USER`。
- **所需数据**：观测点、插值方法及参数、折面几何、训练/留出点、（可选）误差面方法。
- **合格输入现状**：无带公布设计/方法/折面的观测集、Geostatistical 许可未探测 ⇒ `NOT-AVAILABLE-PENDING-USER`。
- **负向档案（invalid）**：折面泄漏、训练点与验证点重叠、方法不支持误差面却被要求出带 → 安全拒绝/降级（不发误差面）。

## 二、比较规则引用（逐字 ID，零自定义）

- `GBC-001`、`KDA-001`、`OSV-001`
- `SDU-002`（折面/训练点与残差一起表达，折面泄漏须拒绝）
- `SDU-003`（不确定性/方法/假设分账）

## 三、压力维度

- **ST-M4-15**：方法不支持不确定性带的插值；预期 **COMPLETE**——仅发布预测、不发误差面，并说明为何不可支持（SDU-002/OSV-001）。
- 通用延伸：稀疏/密集观测、强空间异质、折面数多；FINAL §4 未枚举 ID 待后续批。

## 四、判据引用（规则要点，不新增阈值）

- 折面几何、训练点与残差一起表达；折面泄漏或训练/验证重叠须拒绝（SDU-002）。
- 方法不支持误差面时不发误差面并说明，不以"误差"名出非误差（SDU-002/OSV-001）。
- 方法参数与不确定性、假设分账表达（SDU-003）。
