## 三、计数核对

- 主模板归属：TP **28** ＋ TS **32** ＝ **60**（与 60 场景一致）。
- **次模板关系（5 处，不重复计场景）**：
  - S31 次 TS12、S49 次 TS12；
  - S36 次 TS13；
  - S48 次 TS15；
  - S56 次 TP17。
- 模板覆盖：36 个模板**每个至少承载 1 个场景**，无"空模板"。

## 四、使用方法
- L1 实现某模板时，按本表取其主承载场景逐一做自动成果，并核对次模板关系。
- 跨许可族（TP04/TP14/TS07/TS08/TS16 等）须先确认对应宿主许可与合格输入，否则 fail-closed。

## 五、纪律与免责
- 本件为**索引/台账**：无工具调用、无运行证据；为正向映射的转置视图，不新增任何规格承诺。
- 未改动 L3_INBOX 的 WAITING 状态、未伪造 D 编号/验收、四锚与 M1–M4 冻结资产字节未改、未写入 Source/Tests/Config/Benchmarks、全在 D 盘；判据不自定义，阈值以 L2 冻结面为准。
