# TP01 · 区位与研究范围 — 资产规格书

> 模板族：规划类（Planning）｜M1 六模板之一｜版本：v0.1（D-090 初版）
> 对应场景：S19 规划区位现状图｜对应标准图：SF-TP01-A/B/C

---

## 1. 版面结构

```
┌─────────────────────────────────────────────────┐
│  标题区（主标题＋副标题＋制图日期）                │
├──────────────┬──────────────────────────────────┤
│              │                                  │
│  区位索引图   │      研究范围主图                 │
│  (小比例       │   (大比例，含边界/注记/整饰)      │
│   上下文)     │                                  │
│              │                                  │
├──────────────┴──────────────────────────────────┤
│  图例区 ｜ 比例尺 ｜ 指北针 ｜ 来源脚注            │
└─────────────────────────────────────────────────┘
```

- **主图区**占版面 ≥60%，右置或居中；区位索引图固定左上角（占版面 ≤15%）。
- **整饰件**：比例尺（图形＋文字）、指北针、图例（底部或右侧）、来源脚注（底部）。
- **横竖版**：默认横版 A3；竖版 A4 时索引图移至顶部、图例移至底部。

## 2. 语义槽位

| 槽位 ID | 语义 | 数据类型 | 必填 | 来源 |
|---|---|---|---|---|
| `title.main` | 主标题（如「XX 片区区位与研究范围」） | string | 是 | TaskBrief.用途＋输入地名 |
| `title.sub` | 副标题（行政层级/编制单位） | string | 否 | TaskBrief |
| `study_area.geom` | 研究范围面要素 | polygon | 是 | 输入档案 boundary |
| `study_area.name` | 研究范围名称 | string | 是 | boundary.NAME 字段 |
| `study_area.area` | 研究范围面积（km²/hm²） | number＋unit | 是 | FactTable（M02 计算） |
| `admin_context.geom` | 上位行政区面（省/市/区） | polygon | 是 | 输入 admin boundary |
| `admin_context.name` | 上位行政区名 | string | 是 | admin.NAME |
| `location_marker.geom` | 区位指示点/箭头 | point/line | 否 | 自动生成（索引图→主图关联） |
| `base_map.type` | 底图类型（影像/地形/简易） | enum | 是 | 模板默认＋用户选择 |
| `coord.ref` | 坐标系标注（EPSG/名称） | string | 是 | DatasetContract.CRS |
| `scale.denominator` | 主图比例尺分母 | integer | 是 | 自动计算（图框范围/纸张尺寸） |
| `source.note` | 数据来源与年份 | string | 是 | DatasetContract.来源 |

## 3. 字号与约束

| 元素 | 字号（pt，A3 300DPI） | 字重 | 约束 |
|---|---|---|---|
| 主标题 | 28–36 | Bold | 单行优先；超长自动缩至 ≥20pt 或换行（最多 2 行） |
| 副标题 | 14–18 | Regular | 主标题下方，间距 6pt |
| 图内注记（地名） | 9–12 | Regular | 不压盖核心要素；碰撞时自动避让或移至引线 |
| 图例标题 | 11–12 | Bold | — |
| 图例条目 | 9–10 | Regular | — |
| 比例尺/指北针标签 | 8–9 | Regular | — |
| 来源脚注 | 8 | Regular | 底部左对齐，不超过版面宽 80% |

**硬约束**：
- 最小字号 ≥8pt（印刷可读底线；待 D-089 冻结精确阈值）。
- 主标题不得缩至 <20pt；若仍溢出则触发附页或精简标题（Z02 约束求解判定无解）。
- 指北针与比例尺不得重叠；图框变换后整饰件重新绑定（M10 布局求解）。

## 4. 输入档案

| 档案 | 格式 | 必需字段 | 说明 |
|---|---|---|---|
| 研究范围边界 | FileGDB/SHP/GeoJSON | NAME（或等效名称字段） | 面要素；坐标系须可读 |
| 上位行政区边界 | FileGDB/SHP | NAME | 面要素；用于区位索引图上下文 |
| 底图 | 影像服务/本地栅格/Pro 底图 | — | [VERIFY] 在线底图可用性受网络与许可限制 |
| （可选）重要地标 | point feature class | NAME | 用于主图标注 |

**预检**（M02 数据理解）：CRS 一致性、面要素有效性、名称字段非空、面积可计算。

## 5. 改稿意图清单（对齐能力目录 §8 二十类）

| 意图 ID | 改稿类型 | 动作 | 语义检查 |
|---|---|---|---|
| R01 | 标题 | 修改主/副标题文字 | 纯样式，不触发重算 |
| R04 | 字体方案 | 切换中英文字体族 | [VERIFY] 字体可用性；fallback 链 |
| R05 | 字号层级 | 整体缩放字号档位 | 不低于最小字号约束 |
| R07 | 图例位置 | 图例移至右侧/底部/隐藏 | 纯布局 |
| R09 | 版面留白 | 调整边距/元素间距 | 不压盖整饰 |
| R10 | 横竖版 | 横版↔竖版切换 | 触发 Z02 重排；索引图位置自适应 |
| R11 | 输出尺寸 | A3↔A4↔自定义 | 字号按比例重算；DPI  separately 设置 |
| R12 | 地图框位置 | 主图框平移/缩放 | 比例尺分母联动更新 |
| R15 | 单位显示 | 面积单位 km²↔hm²↔亩 | **触发 FactTable 单位换算**（非纯样式） |
| R17 | 来源脚注 | 修改/补充来源文字 | 纯样式 |
| R20 | 恢复上版 | 回退到上一 DesignSpec revision | M15 版本管理 |

> 涉及分类/筛选/分析方法的改稿（如换底图类型、换研究范围）须重新做语义检查，不按纯样式处理。
