# TS01 · 研究区域与采样点 — 资产规格书

> 模板族：科研类（Science）｜M1 六模板之一｜版本：v0.1（D-090 初版）
> 对应场景：S50 空间采样设计（输出含研究区＋采样点）｜对应标准图：SF-TS01-A/B/C

---

## 1. 版面结构

```
┌─────────────────────────────────────────────────┐
│  标题区（主标题＋研究区名称＋采样方案名）            │
├──────────────────────────────┬──────────────────┤
│                              │  采样统计表       │
│                              │ (样本数/分层/方法) │
│   研究区域主图                ├──────────────────┤
│  (边界＋底图＋采样点符号)      │  采样设计说明      │
│                              │ (种子/分层/距离)   │
│                              │                  │
├──────────────────────────────┴──────────────────┤
│  图例（采样点类型/分层）｜比例尺｜指北针｜来源脚注   │
└─────────────────────────────────────────────────┘
```

- **主图区**≥55%；采样点按分层/类型用不同符号或颜色区分。
- 右侧统计区含样本计数表＋采样方法摘要（非长文，≤5 行关键参数）。
- 默认横版 A3 或双栏论文宽度（[VERIFY] 期刊双栏尺寸待冻结）。

## 2. 语义槽位

| 槽位 ID | 语义 | 数据类型 | 必填 | 来源 |
|---|---|---|---|---|
| `title.main` | 主标题 | string | 是 | TaskBrief |
| `study_area.geom` | 研究区域面 | polygon | 是 | 输入 boundary |
| `study_area.name` | 研究区名称 | string | 是 | boundary.NAME |
| `sample_points.geom` | 采样点 | point | 是 | 输入 sample 或 M07 设计输出 |
| `sample_points.id_field` | 样本编号字段 | string | 是 | 字段名（如 SAMPLE_ID） |
| `sample_points.stratum_field` | 分层字段 | string | 否 | 分层采样时必填 |
| `sample_points.strata` | 分层值列表 | enum[] | 否 | 字段唯一值 |
| `sample_count.total` | 总样本数 | integer | 是 | FactTable |
| `sample_count.per_stratum` | 各层样本数 | dict | 否 | FactTable |
| `sampling.method` | 采样方法（随机/分层/系统/网格） | enum | 是 | AnalysisPlan/M07 |
| `sampling.seed` | 随机种子 | integer | 否 | 可复现性要求 |
| `sampling.min_distance` | 最小间距（m） | number | 否 | 若有空间约束 |
| `base_map.type` | 底图类型 | enum | 是 | 模板默认 |
| `coord.ref` | 坐标系 | string | 是 | DatasetContract |
| `source.note` | 数据来源 | string | 是 | DatasetContract |

## 3. 字号与约束

| 元素 | 字号（pt） | 字重 | 约束 |
|---|---|---|---|
| 主标题 | 24–32 | Bold | 论文双栏时 ≤24pt |
| 副标题 | 12–16 | Regular | — |
| 采样点标注（ID） | 7–9 | Regular | 密度高时自动抽稀标注；不压盖 |
| 统计表 | 8–10 | Regular/Bold 表头 | — |
| 方法说明 | 8–9 | Regular | ≤5 行 |
| 图例 | 8–10 | Regular | — |
| 脚注 | 7–8 | Regular | 含采样方法与种子 |

**硬约束**：
- 最小字号 ≥7pt（科研图可略小于规划图；待 D-089 冻结）。
- 采样点符号大小不随缩放变化（屏幕/印刷恒定），避免密集区视觉过载。
- 样本编号标注与点符号不重叠；密集区引线标注或抽稀。
- 采样方法、种子、分层参数必须在图面或脚注可查（可复现性硬要求）。

## 4. 输入档案

| 档案 | 格式 | 必需字段 | 说明 |
|---|---|---|---|
| 研究区域边界 | FileGDB/SHP | NAME | polygon |
| 采样点 | FileGDB/SHP/CSV | 样本编号字段 | point；若为设计输出则来自 M07 |
| （可选）分层底图 | raster/polygon | 分层字段 | 分层采样的分层依据 |
| （可选）底图 | 影像/地形 | — | [VERIFY] |

**预检**：采样点在研究区内（越界点标记）、编号唯一、CRS 一致、方法参数完整。
