# TS02 · 分级设色与分布 — 资产规格书

> 模板族：科研类（Science）｜M1 六模板之一｜版本：v0.1（D-090 初版）
> 对应场景：S22 科研分级设色图｜对应标准图：SF-TS02-A/B/C

---

## 1. 版面结构

```
┌─────────────────────────────────────────────────┐
│  标题区（主标题＋变量名＋单位＋分类方法）            │
├──────────────────────────────┬──────────────────┤
│                              │  分类统计表       │
│                              │ (断点/频数/占比)   │
│   分级设色主图                ├──────────────────┤
│  (choropleth＋连续色带)       │  分布直方图       │
│                              │ (值分布可视化)     │
│                              │                  │
├──────────────────────────────┴──────────────────┤
│  色带图例（连续/离散）｜比例尺｜指北针｜来源脚注     │
└─────────────────────────────────────────────────┘
```

- **主图区**≥55%；色带图例水平置于底部或垂直置于右侧。
- 右侧统计区含分类断点表＋分布直方图（展示数据分布与分类的关系）。
- 默认横版 A3 或论文双栏。

## 2. 语义槽位

| 槽位 ID | 语义 | 数据类型 | 必填 | 来源 |
|---|---|---|---|---|
| `title.main` | 主标题（含变量名） | string | 是 | TaskBrief |
| `variable.name` | 变量名称 | string | 是 | 字段名/用户指定 |
| `variable.unit` | 变量单位 | string | 是 | DatasetContract/用户指定 |
| `features.geom` | 制图要素（面/点） | polygon/point | 是 | 输入数据 |
| `features.value_field` | 值字段名 | string | 是 | M02 识别或用户指定 |
| `classification.method` | 分类方法（等距/分位数/自然断点/手动） | enum | 是 | AnalysisPlan/M09 |
| `classification.breaks` | 分类断点 | number[] | 是 | M09 计算 |
| `classification.num_classes` | 分类数 | integer | 是 | 默认 5；模板范围 3–8 |
| `color.ramp` | 色带名称/定义 | string | 是 | 模板默认（科研惯用连续色带） |
| `stats.summary` | 描述统计（min/max/mean/median/std） | dict | 是 | FactTable（M02） |
| `stats.histogram` | 直方图 bins＋counts | array | 是 | FactTable |
| `coord.ref` | 坐标系 | string | 是 | DatasetContract |
| `source.note` | 来源 | string | 是 | DatasetContract |

## 3. 字号与约束

| 元素 | 字号（pt） | 字重 | 约束 |
|---|---|---|---|
| 主标题 | 24–32 | Bold | 含变量名与单位 |
| 副标题 | 12–16 | Regular | 含分类方法与分类数 |
| 分类断点表 | 8–10 | Regular | 断点值保留与数据一致的小数位 |
| 直方图标签 | 7–9 | Regular | — |
| 色带图例标签 | 8–10 | Regular | 断点值标注 |
| 图内注记 | 7–9 | Regular | 可选，密度高时关闭 |
| 脚注 | 7–8 | Regular | 含分类方法与数据年份 |

**硬约束**：
- 最小字号 ≥7pt（待 D-089 冻结）。
- 色带须为**色盲友好**（[VERIFY] 具体色带值待设计冻结；不得使用红绿无差别色带）。
- 分类方法与断点必须在图面可查（副标题或脚注）；不得隐藏分类参数。
- 直方图与地图使用同一分类断点（视觉一致性硬规则）。
- 负值/零值须有明确颜色区分（不得与正值混色）。

## 4. 输入档案

| 档案 | 格式 | 必需字段 | 说明 |
|---|---|---|---|
| 制图要素 | FileGDB/SHP | 数值字段 | 面（choropleth）或点（graduated symbol） |
| （可选）研究范围 | FileGDB/SHP | NAME | 裁剪/掩膜 |

**预检**：值字段数值型、非空率、异常值（M02 标记）、CRS、分类方法参数。
