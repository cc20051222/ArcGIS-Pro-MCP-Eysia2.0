# TS08 · 遥感多波段对照 — 资产规格书

> 模板族：科研类（Science）｜M1 六模板之一｜版本：v0.1（D-090 初版）
> 对应场景：S18 多波段专题合成（＋S44 影像质量子例）｜对应标准图：SF-TS08-A/B/C
>
> ⚠️ **数据缺口挂账（G-205 ④）**：本模板依赖**已有合格多波段栅格数据**。M1 阶段不新增遥感算法（X4 域在 M4），不声称分类/变化检测等已完成。波段合成、拉伸、配准等操作使用现有已验工具或 Pro 原生能力；[VERIFY] 项如实标注。

---

## 1. 版面结构

```
┌─────────────────────────────────────────────────┐
│  标题区（主标题＋传感器＋获取日期＋波段组合）        │
├──────────────────┬──────────────────────────────┤
│                  │                              │
│  波段组合面板 A   │      波段组合面板 B            │
│  (如真彩色 RGB)   │      (如假彩色 CIR)           │
│                  │                              │
├──────────────────┼──────────────────────────────┤
│                  │                              │
│  波段组合面板 C   │      波段信息表                │
│  (如波段比值/指数) │  (波段号/名称/波长/分辨率)     │
│                  │                              │
├──────────────────┴──────────────────────────────┤
│  图例/色带 ｜ 比例尺 ｜ 指北针 ｜ 来源脚注           │
└─────────────────────────────────────────────────┘
```

- **多面板对照**布局：2×2 或 1×3 面板，每面板一个波段组合。
- 波段信息表固定在右下角或底部，列出各波段的编号/名称/中心波长/空间分辨率。
- 默认横版 A3；面板数由 Brief 决定（最少 2，最多 4）。

## 3. 字号与约束

| 元素 | 字号（pt） | 字重 | 约束 |
|---|---|---|---|
| 主标题 | 24–32 | Bold | 含传感器与日期 |
| 面板标题 | 12–16 | Bold | 每面板上方，含组合名（如「真彩色 B4B3B2」） |
| 波段信息表 | 7–9 | Regular | 波长单位 nm；分辨率单位 m |
| 图例/色带 | 8–10 | Regular | 若有指数面板则需色带 |
| 脚注 | 7–8 | Regular | 含传感器、日期、拉伸方法 |

**硬约束**：
- 最小字号 ≥7pt（待 D-089 冻结）。
- 各面板**使用相同的空间范围与分辨率**（配准一致）；若源数据分辨率不同，须重采样到共同格网并在脚注说明（M08 共同格网预检）。
- 波段组合定义必须在面板标题中可见（如「B5B4B3 假彩色」），不得只标「图 A/图 B」。
- 拉伸方法与参数在脚注可查；不同面板可使用不同拉伸，但须分别标注。
- **不做**：影像分类、变化检测、云影掩膜（这些属 X4 域，M4 才实现）；若 Brief 要求，须明确标注「超出 M1 范围，待 M4」。

## 4. 输入档案

| 档案 | 格式 | 必需字段 | 说明 |
|---|---|---|---|
| 多波段遥感影像 | GeoTIFF/IMG/FileGDB raster | ≥3 波段 | 已有合格数据；[VERIFY] 大文件分块处理能力 |
| （可选）波段元数据 | XML/JSON/MTL.txt | 传感器/日期/波长 | 若影像自带元数据则自动读取 |

**预检**（M02/M08）：
- 波段数 ≥3；各波段尺寸一致（行列数相同）。
- CRS 一致；若多景拼接须先配准。
- NoData 值可识别；云覆盖区域标记（不自动去除，仅标注）。
- [VERIFY] 当前已验工具对多波段栅格的读取与合成能力范围。

**数据缺口挂账**：
- 若无合格多波段数据，本模板的标准图渲染**挂起**，在标准图清单中标注「数据待补」。
- 不下载、不生成模拟数据替代真实影像。
