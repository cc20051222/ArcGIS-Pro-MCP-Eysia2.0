# TP02 · 现状用地结构 — 资产规格书

> 模板族：规划类（Planning）｜M1 六模板之一｜版本：v0.1（D-090 初版）
> 对应场景：S20 用地/约束专题图｜对应标准图：SF-TP02-A/B/C

---

## 1. 版面结构

```
┌─────────────────────────────────────────────────┐
│  标题区（主标题＋副标题＋统计年份）                 │
├──────────────────────────────┬──────────────────┤
│                              │  用地结构统计表    │
│                              │  (面积/占比/环比)  │
│     现状用地分类主图          ├──────────────────┤
│   (分级设色＋图例)            │  占比环形图/条形图 │
│                              │  (可视化摘要)      │
│                              │                  │
├──────────────────────────────┴──────────────────┤
│  图例 ｜ 比例尺 ｜ 指北针 ｜ 来源脚注              │
└─────────────────────────────────────────────────┘
```

- **主图区**占版面 ≥55%；右侧统计区 ≤35%（表＋图上下排布）。
- 分类色板采用规划行业惯用用地色（如城乡用地分类 GB 50137 色系）；[VERIFY] 色板具体值待设计冻结。
- 横竖版：默认横版 A3；竖版时统计区移至底部。

## 2. 语义槽位

| 槽位 ID | 语义 | 数据类型 | 必填 | 来源 |
|---|---|---|---|---|
| `title.main` | 主标题 | string | 是 | TaskBrief |
| `title.sub` | 副标题＋统计年份 | string | 是 | 输入数据年份 |
| `landuse.geom` | 用地图斑面要素 | polygon | 是 | 输入 landuse |
| `landuse.class_field` | 用地分类字段名 | string | 是 | M02 自动识别或用户指定 |
| `landuse.class_values` | 分类值列表 | enum[] | 是 | 字段域/唯一值 |
| `landuse.area_per_class` | 每类面积 | number＋unit | 是 | FactTable（M07/M02 计算） |
| `landuse.pct_per_class` | 每类占比（%） | number | 是 | FactTable 派生 |
| `landuse.color_map` | 分类→颜色映射 | dict | 是 | 模板默认色板＋分类标准 |
| `study_area.boundary` | 研究范围边界（叠加） | polygon | 否 | 若与 landuse 不同范围 |
| `classification.standard` | 分类标准（如 GB50137/自定义） | string | 是 | 输入元数据/用户指定 |
| `data.year` | 数据年份 | integer | 是 | DatasetContract |
| `source.note` | 来源 | string | 是 | DatasetContract |

## 3. 字号与约束

| 元素 | 字号（pt，A3 300DPI） | 字重 | 约束 |
|---|---|---|---|
| 主标题 | 28–36 | Bold | 同 TP01 规则 |
| 副标题/年份 | 14–18 | Regular | — |
| 统计表表头 | 10–11 | Bold | — |
| 统计表内容 | 9–10 | Regular | 数字右对齐；面积保留 2 位小数 |
| 图表标签 | 9–10 | Regular | 占比保留 1 位小数 |
| 图例 | 9–11 | Regular | 分类条目多时自动分列（≤4 列） |
| 图内注记 | 8–10 | Regular | 仅标注大类；小图斑不强制标注 |
| 脚注 | 8 | Regular | — |

**硬约束**：
- 最小字号 ≥8pt（待 D-089 冻结）。
- 分类数 >12 时图例自动分列或折叠次要类为「其他」；折叠须在脚注说明。
- 环形图/条形图为 FactTable 的可视化，**不得与地图数值不一致**（M16 检查同源）。
- 用地色板中相邻类颜色色差须满足可访问性（待 D-089 冻结色差阈值）。

## 4. 输入档案

| 档案 | 格式 | 必需字段 | 说明 |
|---|---|---|---|
| 现状用地数据 | FileGDB/SHP | 分类字段（如 DLBM/地类码） | 面要素；须有分类标准说明 |
| 研究范围边界 | FileGDB/SHP | NAME | 可选，用于裁剪/叠加 |
| （可选）上一期用地 | 同上 | 分类字段 | 用于环比统计（若 Brief 要求） |

**预检**：分类字段非空率、面要素重叠/缝隙、面积可计算、分类标准可识别。
