# TP03 · 公共服务直线覆盖 — 资产规格书

> 模板族：规划类（Planning）｜M1 六模板之一｜版本：v0.1（D-090 初版）
> 对应场景：S07 设施直线覆盖｜对应标准图：SF-TP03-A/B/C
> ⚠️ 本模板为**直线（欧氏）覆盖**，不等同路网服务区（S08/TP04）；Brief 中须明确区分。

---

## 1. 版面结构

```
┌─────────────────────────────────────────────────┐
│  标题区（主标题＋设施类型＋覆盖半径）               │
├──────────────────────────────┬──────────────────┤
│                              │  覆盖统计表       │
│                              │ (半径/覆盖面积/    │
│   设施点＋多环缓冲区主图      │  覆盖人口/未覆盖)  │
│   (分级设色缓冲环＋设施点)    ├──────────────────┤
│                              │  覆盖率条形图      │
│                              │                  │
├──────────────────────────────┴──────────────────┤
│  图例（缓冲环＋设施类型）｜比例尺｜指北针｜来源脚注  │
└─────────────────────────────────────────────────┘
```

- **主图区**≥55%；缓冲环采用半透明分级设色（由近及远透明度递增或色阶递减）。
- 设施点用符号区分类型（若多类型）；未覆盖区可用斜线或对比色标识。
- 默认横版 A3。

## 2. 语义槽位

| 槽位 ID | 语义 | 数据类型 | 必填 | 来源 |
|---|---|---|---|---|
| `title.main` | 主标题（含设施类型） | string | 是 | TaskBrief |
| `facility.geom` | 公共设施点 | point | 是 | 输入 facility |
| `facility.type_field` | 设施类型字段 | string | 否 | 多类型时必填 |
| `facility.type_values` | 设施类型列表 | enum[] | 否 | 字段唯一值 |
| `buffer.distances` | 缓冲半径列表（m） | number[] | 是 | TaskBrief/模板默认（如 300/500/1000m） |
| `buffer.geom_per_ring` | 各环缓冲区面 | polygon[] | 是 | M07 Buffer 工具计算 |
| `coverage.area_per_ring` | 各环覆盖面积 | number＋unit | 是 | FactTable |
| `coverage.pop_per_ring` | 各环覆盖人口 | number | 否 | 若有人口栅格/面数据 |
| `coverage.pct` | 覆盖率（%） | number | 是 | FactTable 派生 |
| `unserved.area` | 未覆盖面积 | number＋unit | 是 | 研究范围－最大环 |
| `study_area.boundary` | 研究范围 | polygon | 是 | 输入 boundary |
| `population.data` | 人口数据 | raster/polygon | 否 | [VERIFY] 人口数据可得性 |
| `source.note` | 来源 | string | 是 | DatasetContract |

## 3. 字号与约束

| 元素 | 字号（pt，A3 300DPI） | 字重 | 约束 |
|---|---|---|---|
| 主标题 | 28–36 | Bold | 含设施类型与半径 |
| 副标题 | 14–18 | Regular | — |
| 缓冲环标注 | 9–11 | Bold | 环边缘引线标注；不压盖设施点 |
| 设施点标注 | 8–10 | Regular | 密度高时自动抽稀或仅标注类型 |
| 统计表 | 9–11 | Regular/Bold 表头 | 覆盖率保留 1 位小数 |
| 图例 | 9–11 | Regular | 缓冲环＋设施类型分组 |
| 脚注 | 8 | Regular | 须注明「直线覆盖，非路网可达」 |

**硬约束**：
- 最小字号 ≥8pt（待 D-089 冻结）。
- 缓冲环透明度叠加后须可区分相邻环；[VERIFY] 色阶/透明度具体值待设计冻结。
- 脚注**必须**包含「直线（欧氏）覆盖」声明，避免与路网服务区混淆（科学保护硬规则）。
- 覆盖率分母＝研究范围面积，不得用全域面积替代。

## 4. 输入档案

| 档案 | 格式 | 必需字段 | 说明 |
|---|---|---|---|
| 公共设施点 | FileGDB/SHP/CSV | （可选）类型字段 | point；坐标须有效 |
| 研究范围边界 | FileGDB/SHP | NAME | polygon |
| （可选）人口数据 | raster/FileGDB | 人口字段 | 覆盖人口统计用 |
| （可选）障碍要素 | polygon | — | 若需扣除水体/山体等不可覆盖区 |

**预检**：设施点坐标有效、缓冲区半径 >0、研究范围非空、CRS 为投影坐标系（地理坐标系须先投影，否则距离单位为度——M02 须拦截并提示）。
