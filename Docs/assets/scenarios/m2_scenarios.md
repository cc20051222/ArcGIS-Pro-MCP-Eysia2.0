## 场景 1：S01 文件夹资料体检入库（→ TP08）

### Brief（Z01）
- **用户输入**：拖入整个项目文件夹（含 shp/gdb/tif/csv 混排，约数十件）；用途「资料归档」；输出体检报告＋入库台账。
- **数据画像**：格式混杂、部分缺 PRJ、个别空图层/重复文件；CRS 多样。
- **TaskBrief**：模板=TP08，动作=逐件识别格式/CRS/要素数/缺陷，输出体检报告（不修改原始数据）。

### 成稿（Z02→Z05）
1. **Z02**：TP08 槽位；逐件提取元数据（格式/CRS/行列/要素数/字段）。
2. **Z03**：在途工具 check_topology_rules/get_dataset_lineage/validate_geometries（PENDING-D088）；现役工具完成可读件体检。
3. **Z04**：QLT-001 缺陷集核对；缺 CRS/容差件标 UNKNOWN 不 PASS；汇总台账。
4. **Z05**：导出体检报告（RPT-001：reportPath 缺失零落物，指定则写 D 盘）。

### 改稿（Z06）
- 指令：「把缺 PRJ 的文件单独列一节，按 CRS 分组重排」。
- 分类：R18 分组排序（纯视觉）；执行后报告重排，原始判定不变。

### 更新（Z07）
- 触发：文件夹新增一批数据。
- 执行：增量体检新件，台账追加，旧件结果保留，报告同修订。

### 交付
- 体检报告＋入库台账（含每件来源/缺陷/建议）；原始数据零修改；0 次手工设计。
