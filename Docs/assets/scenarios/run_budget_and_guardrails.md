## 二、安全护栏（按类别）

### A. 科学 / 表达保护
- 字号不得低于最小字号、不无下限缩字；
- **定量色阶受保护**，量化颜色不可当美化改；定性配色才可换；
- 地图框**不得非等比变形**；范围/旋转变更须重生成比例尺/指北针/图例；
- 事实文字以 factRef 绑定，改风格不改数据；
- **单位换算、分类/筛选、分析方法必须重新做语义检查**（非一律当纯样式）；
- CRS/变换/单位走硬规则；误差表达须先消费**已验证**误差输入。

### B. 文件 / 原件安全
- 外部原件**只读**；预览/渲染前**不覆盖**外部原件；
- 预览图、渲染文件**不进入交付目录**，交付只从不可变发布目录取；
- 交付前做路径长度/非法字符检查；
- **G-197：一切在 D 盘，%TEMP% 零写入零落物**；
- 不删除源数据；自动包不得静默覆盖既有包。

### C. 流程 / 授权门
- 许可/合格输入缺失 → **fail-closed**，不降级产出；
- baseRevision 不匹配的**过期 Patch 拒绝**；
- 在线发布、邮件/平台发送属**单独授权**动作；
- 方法变更 → 重新生成 TaskBrief/AnalysisPlan 并**重新走批准范围**；
- 预算超限 → 停止并升级用户，不自行扩张。

### D. 缓存 / 可复现
- 强缓存键含数据/方法/CRS/单位/样式；仅路径或 mtime 相同**不得复用**；
- 版本/revision 不可变；保留回滚锚点；恢复上版回到不可变 revision。
