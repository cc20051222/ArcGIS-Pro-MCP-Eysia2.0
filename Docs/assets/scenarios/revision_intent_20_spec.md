## 一、核心判定规则（FINAL 原文口径）

- 能力目录行 246："**涉及单位换算、分类/筛选、分析方法的请求必须重新做语义检查；不是一律当纯样式修改。**"
- ROADMAP §7 更新三类：**样式改动 → 只重渲染；新数据 → 沿依赖图重算受影响分析与全部事实；方法变更 → 重新生成计划与批准范围。**
- 类型标签：**V**＝视觉（重渲染即可）｜**S**＝语义（须重算/语义检查/重新批准）｜**M**＝混合（按实际内容判定）。
- 所有改稿生成 baseRevision 匹配的 `DesignPatch`；**过期 Patch 拒绝**（Z06）；事实文字以 factRef 绑定，改风格不改数据。

## 三、语义改稿（S）的强制流程

1. 命中"单位换算/分类筛选/分析方法"（或 M 类判定后涉语义）→ **不得只重渲染**。
2. 沿依赖 DAG 重算受影响分析与全部相关事实（ROADMAP §7）；方法变更须重新生成 TaskBrief/AnalysisPlan 并**重新走批准范围**。
3. 重算后默认完整重渲染新版；强缓存键含数据/方法/CRS/单位/样式，仅路径或 mtime 相同不得复用。
4. 留证：语义检查结果、重算事实 diff、重新批准记录。
