## 场景 1：S19 规划区位现状图（→ TP01）

### Brief（Z01）
- **用户输入**：拖入 `XX片区边界.shp`＋`XX市行政区.shp`；选用途「规划汇报」；输出 A3 横版 PNG＋PDF。
- **数据画像**：边界面要素有效，CRS＝CGCS2000 / 3-degree GK；行政区含省/市/区三级；名称字段非空。
- **歧义**：无（数据完整）。
- **TaskBrief**：用途=规划汇报，输入=边界＋行政区，输出=A3 横版 PNG/PDF，模板=TP01，预算=标准。

### 成稿（Z02→Z05）
1. **Z02 约束求解**：TP01 槽位填充（title.main=「XX片区区位与研究范围」，study_area=边界，admin_context=行政区）；候选布局 3 个，硬约束全过。
2. **Z03 预览推荐**：GIS 素材包导出（边界/行政区/底图三层，透明 PNG，配准锚点）；PS 导入应用 TP01 配方；渲染主稿 1＋备选 1。[VERIFY] PS 通道可用性。
3. **Z04 检查修正**：检查项=图框/图例/比例尺/指北针/最小字号/来源脚注；初检全过，无需修正。
4. **Z05 成果输出**：导出 A3 横版 PNG（300DPI）＋PDF；DeliveryManifest 含两件 hash/大小/来源。

### 改稿（Z06）
- **用户指令**：「图例移到右边，标题改成『XX片区区位分析图』」。
- **意图分类**：R07 图例位置（纯视觉）＋ R01 标题（纯视觉）。
- **执行**：生成 DesignPatch（baseRevision=当前），重排图例至右侧，更新标题；重渲染；Z04 重检全过。

### 更新（Z07）
- **触发**：新一期边界数据 `XX片区边界_v2.shp`（范围微调）。
- **执行**：依赖 DAG 重算=面积 FactTable 更新；视觉 Patch 继承；完整重渲染新版；旧 revision 保留。
- **验证**：新版面积与 v2 一致；标题/图例位置沿用改稿意图。

### 交付（Z05/Z08）
- 最终成果：PNG＋PDF（v2 新版）＋ DeliveryManifest；工作台展示成果列表；0 次 PS 手工设计。
