# TP09 · 分区管控图册 — 资产规格书

> 模板族：规划类（Planning）｜M2 十六模板之一｜版本：v0.1（D-095 初版）
> 对应场景：S15 分区土地类别统计、S28 屏幕/打印双版本交付｜M2 支柱：批量页与项目风格（batch-and-style）
> 输入政策：current-tool-surface
> 判据引用（rules-v2，阈值不自定义）：BAT-001、LAY-001、NUM-001、OUT-001、PRM-001、RFL-001、SCI-001、STY-001、TXT-001、WF-001

---

## 1. 版面结构

```
┌─────────────────────────────────────────────────┐
│  图册封面（标题＋编制单位＋日期）                  │
├─────────────────────────────────────────────────┤
│  目录页（分区名＋页码）                            │
├─────────────────────────────────────────────────┤
│  逐管控分区页（每页）：                            │
│  ┌───────────────────────────────────────────┐  │
│  │ 页标题（分区名＋管控类型）                 │  │
│  │ 分区主图（管控界线/地类/指标）＋管控条文表  │  │
│  │ 图例｜比例尺｜指北针｜统一页脚/页码         │  │
│  └───────────────────────────────────────────┘  │
└─────────────────────────────────────────────────┘
```

- **图册为多页批量件**：封面＋目录＋逐分区页，每页同模板、统一风格。
- **分区页**：管控界线/地类主图＋管控条文/指标表。
- **整饰件**：每页统一标题栏、图例、比例尺、指北针、页脚、连续页码。

## 2. 语义槽位

| 槽位 ID | 语义 | 数据类型 | 必填 | 来源 |
|---|---|---|---|---|
| `cover.title` | 图册标题 | string | 是 | TaskBrief |
| `toc.entries` | 目录（分区名＋页码） | table | 是 | 自动生成 |
| `page.zone` | 每页对应分区 | polygon | 是 | 分区字段 |
| `page.title` | 页标题（分区名＋管控类型） | string | 是 | 分区属性 |
| `zoning.boundary` | 管控界线 | line/polygon | 是 | 管控数据 |
| `zoning.regulation` | 管控条文/指标（用途/强度/高度） | text/table | 是 | 管控标准 |
| `landclass.field` | 土地类别字段 | string | 条件 | S15 统计 |
| `fact.per_zone` | 各分区地类/指标统计 FactTable | FactTable | 是 | FactTable（M07） |
| `style.token` | 项目风格令牌（字体/色板/页边距） | style（hash） | 是 | STY-001 风格件 |
| `page.number` | 连续页码 | integer | 是 | 自动生成 |
| `coord.ref` | 坐标系标注 | string | 是 | DatasetContract.CRS |
| `source.note` | 管控/地类来源 | string | 是 | DatasetContract.来源 |

## 3. 字号与约束

| 元素 | 字号（pt，A4/A3 300DPI） | 字重 | 约束 |
|---|---|---|---|
| 封面标题 | 30–40 | Bold | — |
| 页标题 | 16–20 | Bold | 各页同级 |
| 管控条文 | 9–11 | Regular | 条文完整不截断（TXT-001） |
| 图内注记 | 8–10 | Regular | 密集抽稀 |
| 统计表 | 8–10 | Regular | 与图同源 |
| 页脚/页码 | 8 | Regular | 各页位置一致 |

**硬约束**：
- 最小字号 ≥8pt（待 rules-v2 冻结）。
- **批量页一致性**（BAT-001）：页数/页序/类别集/图例序/单位/来源在要求一致范围内跨页相同；每页绑定同一数据指纹，指纹变更在同一作业内重验全部页。
- **风格令牌**（STY-001）：字体/色板/页边距等来自显式保存且带 hash 的项目风格件；静默回退默认即失败。
- 管控条文须完整呈现（TXT-001），不得丢字；双媒介（屏幕/打印）重排只改版面不改事实（RFL-001/LAY-001）。

## 4. 输入档案

| 档案 | 格式 | 必需字段 | 说明 |
|---|---|---|---|
| 管控分区面 | polygon | 分区名、管控类型 | CRS 可读 |
| 管控条文/指标表 | table | 分区键、条文/指标 | 逐分区对应 |
| 土地类别数据 | polygon/raster | 地类字段 | S15 统计用 |
| 项目风格件 | style artifact | 字体/色板/页边距 | 带 hash |

**预检**（M02）：分区字段非空、条文逐分区可匹配、CRS 一致、风格件可读、页码可连续。

## 5. 改稿意图清单（对齐能力目录 §8 二十类）

| 意图 ID | 改稿类型 | 动作 | 语义检查 |
|---|---|---|---|
| R01 | 标题 | 封面/页标题 | 纯样式 |
| R04/R05 | 字体/字号 | 切换风格件 | STY-001，全册统一 |
| R06 | 配色风格 | 管控色板 | 全册同步 |
| R10/R11 | 横竖版/尺寸 | A4/A3、屏幕/打印 | RFL-001/LAY-001 |
| R19 | 系列页统一 | 全册风格/页脚统一 | BAT-001 |
| — | **页序/分区增减** | 换页序、新增分区页 | **混合：页序纯视觉，新增页语义重算** |
| — | **管控条文/指标更新** | 新版管控要求 | **语义改稿：重算 FactTable、更新条文** |

> 凡增减分区、变更管控条文/指标的请求必须重新做语义检查；工作流（WF-001）与许可副作用（PRM-001）如实记录。
