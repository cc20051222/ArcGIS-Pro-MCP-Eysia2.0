# TP04 · 真实路网可达性 — 资产规格书

> 模板族：规划类（Planning）｜M2 十六模板之一｜版本：v0.1（D-095 初版）
> 对应场景：S08 真实路网服务区｜M2 支柱：质量与溯源（quality-provenance）
> 输入政策：**qualified-frozen-input**——分析侧能力 `calculate_service_areas`（P5）、`solve_routes`（P5）属后续领域批，**当前未实现**；本规格只定设计面，不声称路网分析算法已完成。
> 判据引用（rules-v2，阈值不自定义）：BAT-001、GEO-001、LNG-001、NUM-001、OUT-001、PRM-001

## 1. 版面结构

```
┌─────────────────────────────────────────────────┐
│  标题区（主标题＋副标题：阻抗类型/中断值＋日期）    │
├──────────────────────────────────────┬──────────┤
│                                      │          │
│        路网可达性主图                 │ 覆盖率    │
│  (道路网络＋多级服务区面半透明         │ 统计表    │
│   ＋设施点＋研究区边界)               │ ＋条形图  │
│                                      │          │
├──────────────────────────────────────┴──────────┤
│  图例区 ｜ 比例尺 ｜ 指北针 ｜ 脚注（真实路网声明）│
└─────────────────────────────────────────────────┘
```

- **主图区**占版面 ≥60%；服务区面按时间/距离中断值分级半透明叠置于道路网络之上。
- **整饰件**：比例尺、指北针、图例（服务区分级＋道路＋设施）、脚注（底部，含真实路网声明与数据年份）。
- **横竖版**：默认横版 A3；多设施/多中断值时右侧统计表可下移。

## 2. 语义槽位

| 槽位 ID | 语义 | 数据类型 | 必填 | 来源 |
|---|---|---|---|---|
| `title.main` | 主标题（如「XX 设施真实路网可达性」） | string | 是 | TaskBrief.用途＋设施类型 |
| `title.sub` | 副标题（阻抗类型＋中断值，如「行驶时间 5/10/15min」） | string | 是 | AnalysisPlan |
| `study_area.geom` | 研究区面要素 | polygon | 是 | 输入 boundary |
| `network.dataset` | 道路网络数据集（含连通性/层级/转向） | network dataset | 是 | 输入路网；**P5 能力未实现，挂账** |
| `network.impedance` | 阻抗属性（行驶时间 min / 距离 m） | enum＋unit | 是 | TaskBrief＋网络属性 |
| `facilities.geom` | 设施点（起点/终点） | point | 是 | 输入 facilities |
| `service_areas.geom` | 多级服务区面（按中断值） | polygon（分级） | 是 | AnalysisPlan 计算（P5 挂账） |
| `cutoffs.value` | 中断值序列（5/10/15 min 或对应距离） | number[]＋unit | 是 | TaskBrief |
| `fact.coverage` | 各中断值覆盖面积/人口/覆盖率 | FactTable | 是 | FactTable（M07 计算） |
| `coord.ref` | 坐标系标注（须投影，单位 m） | string | 是 | DatasetContract.CRS |
| `scale.denominator` | 主图比例尺分母 | integer | 是 | 自动计算 |
| `source.note` | 路网/设施/人口数据来源与年份 | string | 是 | DatasetContract.来源 |

## 3. 字号与约束

| 元素 | 字号（pt，A3 300DPI） | 字重 | 约束 |
|---|---|---|---|
| 主标题 | 26–34 | Bold | 单行优先；超长缩至 ≥20pt 或换行（≤2 行） |
| 副标题 | 13–17 | Regular | 须含阻抗与中断值 |
| 图内注记（路名/设施名） | 8–11 | Regular | 密集路网区抽稀标注，不压盖 |
| 统计表/图表文字 | 8–10 | Regular | 数值与 FactTable 同源 |
| 图例条目 | 9–10 | Regular | 服务区分级按中断值升序 |
| 来源脚注 | 8 | Regular | 底部左对齐 |

**硬约束**：
- 最小字号 ≥8pt（精确阈值待 D-089 rules-v2 冻结，本规格不自定义）。
- **脚注强制声明**：「基于真实道路网络行驶时间（或距离），非直线（欧氏）距离」——与 TP03 直线覆盖严格区分，不得互换。
- 路网分析必须在投影坐标系（距离/时间单位明确）；网络数据集缺失或不可定位时 BLOCKED，不得用直线缓冲冒充。
- 服务区中断值单位与阻抗属性一致；多级服务区嵌套关系正确。

## 4. 输入档案

| 档案 | 格式 | 必需字段 | 说明 |
|---|---|---|---|
| 道路网络数据集 | network dataset（FileGDB） | 连通性、阻抗属性、（可选）层级/转向 | **P5 能力未实现，当前仅定标** |
| 设施点 | point feature class | NAME、类型 | 须能在网络上定位 |
| 研究区边界 | polygon | NAME | CRS 与路网一致 |
| （可选）人口栅格/面 | raster/polygon | 人口字段 | 用于覆盖率统计 |

**预检**（M02）：网络数据集可读、设施点可定位率、CRS 一致性（投影）、阻抗属性存在、研究区非空。**[VERIFY]** 网络数据集构建与定位能力随 P5 领域批，M2 不验证。
