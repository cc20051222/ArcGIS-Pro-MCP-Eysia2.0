## 1. 版面结构

```
┌─────────────────────────────────────────────────┐
│  标题区（主标题＋副标题：指标名/分区＋日期）        │
├──────────────────────────────────────┬──────────┤
│                                      │          │
│      指标空间分布主图                 │ 指标统计  │
│  (分区面按指标分级设色＋研究区边界)    │ 表＋图表  │
│                                      │ (分布/   │
│                                      │  排序)    │
├──────────────────────────────────────┴──────────┤
│  图例区 ｜ 比例尺 ｜ 指北针 ｜ 指标口径/来源脚注   │
└─────────────────────────────────────────────────┘
```

- **主图区**占版面 ≥60%；分区面按指标值分级设色。
- **指标统计表**：分区指标值＋汇总（合计/均值/极值），与地图同源。
- **整饰件**：比例尺、指北金、图例（指标分级）、脚注（指标口径/计算方法/来源）。

## 2. 语义槽位

| 槽位 ID | 语义 | 数据类型 | 必填 | 来源 |
|---|---|---|---|---|
| `title.main` | 主标题（如「XX 指标分区统计与分布图」） | string | 是 | TaskBrief＋指标名 |
| `title.sub` | 副标题（分区口径/年份） | string | 是 | TaskBrief |
| `study_area.geom` | 研究区面要素 | polygon | 是 | 输入 boundary |
| `zones.geom` | 分区面要素 | polygon | 是 | 输入分区 |
| `indicator.field` | 指标字段/名称 | string | 是 | TaskBrief |
| `indicator.values` | 各分区指标值 | number[] | 是 | 字段/计算 |
| `indicator.definition` | 指标口径/计算方法 | string | 是 | 标准/AnalysisPlan |
| `fact.indicator` | 分区值＋汇总统计 FactTable | FactTable | 是 | FactTable（M07） |
| `quality.defects` | 数据体检缺陷集 | defect[] | 条件 | QLT-001 |
| `coord.ref` | 坐标系标注 | string | 是 | DatasetContract.CRS |
| `source.note` | 分区/指标来源与年份 | string | 是 | DatasetContract.来源 |

## 3. 字号与约束

| 元素 | 字号（pt，A3 300DPI） | 字重 | 约束 |
|---|---|---|---|
| 主标题 | 26–34 | Bold | 超长缩至 ≥20pt |
| 副标题 | 13–17 | Regular | — |
| 分区注记 | 8–11 | Regular | 密集分区抽稀 |
| 统计表/图表 | 8–10 | Regular | 与地图同源 |
| 图例条目 | 9–10 | Regular | 指标分级 |
| 脚注 | 8 | Regular | 含指标口径 |

**硬约束**：
- 最小字号 ≥8pt（待 rules-v2 冻结）。
- **指标口径固定**：指标定义/单位/计算方法须显式标注（脚注），不得由地图视觉推断。
- 数据体检缺陷集（QLT-001）与预期一致；未声明 CRS/容差时 UNKNOWN/BLOCKED，不得 PASS。
- 统计表汇总值由分区值现算（NUM-001）；溯源链完整（LNG-001）。

## 4. 输入档案

| 档案 | 格式 | 必需字段 | 说明 |
|---|---|---|---|
| 分区面 | polygon | 分区名、指标字段 | CRS 可读 |
| 研究区边界 | polygon | NAME | 裁剪范围 |
| （可选）指标底表 | csv/table | 分区键、指标值 | 指标计算来源 |

**预检**（M02）：分区字段非空、指标值数值型、CRS 一致、几何有效（QLT-001）、指标口径可识别。
