# TP05 · 生态约束叠加 — 资产规格书

> 模板族：规划类（Planning）｜M2 十六模板之一｜版本：v0.1（D-095 初版）
> 对应场景：S02 多源坐标统一｜M2 支柱：质量与溯源（quality-provenance）
> 输入政策：current-tool-surface（使用现役工具面）
> 判据引用（rules-v2，阈值不自定义）：ALN-001、GEO-001、LNG-001、OUT-001、PRM-001、TRF-001

## 1. 版面结构

```
┌─────────────────────────────────────────────────┐
│  标题区（主标题＋副标题：约束类别数＋日期）         │
├──────────────────────────────────────┬──────────┤
│                                      │          │
│       生态约束叠加主图                │ 各约束    │
│  (多约束层半透明叠加：红线/基本农田/   │ 面积统计  │
│   林地/水体＋研究区边界)              │ ＋重叠区  │
│                                      │  说明     │
├──────────────────────────────────────┴──────────┤
│  图例区 ｜ 比例尺 ｜ 指北针 ｜ 来源/坐标变换脚注   │
└─────────────────────────────────────────────────┘
```

- **主图区**占版面 ≥60%；多个约束层按半透明叠加，重叠（多重约束）区域以可区分方式表达。
- **整饰件**：比例尺、指北针、图例（各约束层＋重叠区）、脚注（来源＋坐标变换说明）。
- **横竖版**：默认横版 A3；约束层 ≥6 时统计表可整页下移。

## 2. 语义槽位

| 槽位 ID | 语义 | 数据类型 | 必填 | 来源 |
|---|---|---|---|---|
| `title.main` | 主标题（如「XX 区域生态保护约束叠加图」） | string | 是 | TaskBrief |
| `title.sub` | 副标题（约束类别数/编制依据） | string | 否 | TaskBrief |
| `study_area.geom` | 研究区面要素 | polygon | 是 | 输入 boundary |
| `constraint.layers[]` | 约束图层列表（生态红线/基本农田/林地/水体等） | layer[] | 是 | 各约束输入 |
| `constraint.type` | 约束等级（禁建/限建/保护） | enum | 是 | 图层属性/标准 |
| `overlay.result` | 叠加结果（含多重约束重叠区） | polygon（分级） | 是 | AnalysisPlan 叠加计算 |
| `fact.constraint_area` | 各约束面积/占比/重叠区面积 | FactTable | 是 | FactTable（M07） |
| `transform.method` | 坐标变换方法（多源坐标统一时） | string | 条件 | TRF-001 列表 |
| `coord.ref` | 统一后坐标系标注 | string | 是 | DatasetContract.CRS |
| `scale.denominator` | 主图比例尺分母 | integer | 是 | 自动计算 |
| `source.note` | 各约束层来源与年份 | string | 是 | DatasetContract.来源 |

## 3. 字号与约束

| 元素 | 字号（pt，A3 300DPI） | 字重 | 约束 |
|---|---|---|---|
| 主标题 | 26–34 | Bold | 超长缩至 ≥20pt 或换行 |
| 副标题 | 13–17 | Regular | — |
| 图内注记 | 8–11 | Regular | 不压盖约束边界 |
| 统计表文字 | 8–10 | Regular | 各约束面积与 FactTable 同源 |
| 图例条目 | 9–10 | Regular | 约束层逐项可区分 |
| 来源/变换脚注 | 8 | Regular | 含坐标变换名称与依据 |

**硬约束**：
- 最小字号 ≥8pt（待 rules-v2 冻结精确值）。
- **多源图层必须先坐标统一**：CRS/格网对齐（ALN-001）；坐标变换须取自主机发布的候选集（TRF-001），不得使用未发布变换；无候选变换时下游叠加 BLOCKED。
- 多重约束重叠区须正确表达，不得简单覆盖丢失下层；约束分类标准可识别。
- 各约束层面积之和与重叠区面积的算术关系自洽。

## 4. 输入档案

| 档案 | 格式 | 必需字段 | 说明 |
|---|---|---|---|
| 生态保护红线 | polygon | 类型/等级 | CRS 可读 |
| 基本农田 | polygon | 类型 | CRS 可读 |
| 林地/水体等约束 | polygon/raster | 类型 | 多源 CRS 可能不一致 |
| 研究区边界 | polygon | NAME | 统一目标 CRS 基准 |

**预检**（M02）：各层 CRS 识别、格网/几何对齐（ALN-001）、约束字段非空、面积可计算、坐标变换候选可用（TRF-001）。
