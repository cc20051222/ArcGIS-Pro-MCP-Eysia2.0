# TP10 · 项目综合汇报展板 — 资产规格书

> 模板族：规划类（Planning）｜M2 十六模板之一｜版本：v0.1（D-095 初版）
> 对应场景：S06 带依赖检查的数据交接包、S26 规划汇报自动成稿、S30 外部修改保护与交付验收、S60 同源报告/PPTX自动交付
> M2 支柱：同源报告（same-source-report）
> 输入政策：current-tool-surface
> 判据引用（rules-v2，阈值不自定义）：DEP-001、LNG-001、NUM-001、OUT-001、PRM-001、PRT-001、RFL-001、SCI-001、SRC-001、STY-001、TXT-001、WF-001

## 1. 版面结构

```
┌─────────────────────────────────────────────────┐
│  展板标题区（项目名＋副标题＋汇报日期）            │
├───────────┬───────────┬─────────────────────────┤
│           │           │                         │
│ 区位/范围  │ 现状/指标  │   方案/规划主图          │
│  小图      │  小图      │                         │
│           │           │                         │
├───────────┴───────────┴─────────────────────────┤
│ 关键指标条（KPI 数字）｜ 结论要点文字             │
├─────────────────────────────────────────────────┤
│ 图例｜比例尺｜指北针｜数据来源/依赖说明脚注        │
└─────────────────────────────────────────────────┘
```

- **综合展板为多图拼版**：区位/现状/方案等多幅小图＋关键指标条＋结论要点，信息聚合于一版。
- **KPI 数字**与各图/分析 FactTable 同源同修订。
- **整饰件**：统一图例、比例尺、指北针、脚注（来源＋数据依赖说明）。
- 同源派生：报告/PPTX 由展板数字同源生成（S60）。

| 槽位 ID | 语义 | 数据类型 | 必填 | 来源 |

## 3. 字号与约束

| 元素 | 字号（pt，A0/A1 展板或 A3） | 字重 | 约束 |
|---|---|---|---|
| 展板标题 | 36–60（按幅面） | Bold | 超长缩至不低于档下限 |
| 面板标题 | 18–28 | Bold | 各面板同级 |
| KPI 数字 | 24–40 | Bold | 数字与 FactTable 精确一致 |
| 结论要点 | 12–16 | Regular | 完整不截断（TXT-001） |
| 图内注记 | 8–11 | Regular | 密集抽稀 |
| 脚注 | 8–9 | Regular | 来源/依赖可查 |

**硬约束**：
- 最小字号 ≥8pt（待 rules-v2 冻结）。
- **同源一致**（SRC-001，critical）：展板每个数字/单位/类别标签/来源注记与对应地图或分析 FactTable 同修订、规范小数精度精确一致；无 FactTable 来源的数字即失败；展板与报告/PPTX 共享一个 revision id。
- **数据依赖可溯**（DEP-001/LNG-001）：依赖节点/边与冻结清单一致，断链计数如实；外部母版/用户原件哈希前后相同、只生新版不覆盖（PRT-001，critical）。
- 媒介重排（展板↔报告↔PPTX↔长图）只改版面不改事实（RFL-001）；风格令牌来自带 hash 风格件（STY-001）。

## 4. 输入档案

| 档案 | 格式 | 必需字段 | 说明 |
|---|---|---|---|
| 项目多源数据（区位/现状/方案） | layer 集合 | 各自字段 | 同 CRS |
| 关键指标底表 | table | 指标/单位 | KPI 来源 |
| （可选）外部母版/用户原件 | 模板文件 | — | 受 PRT-001 保护 |
| 项目风格件 | style（hash） | 字体/色板 | STY-001 |

**预检**（M02）：多源 CRS 一致、指标字段非空、依赖图可解析（DEP-001）、外部母版哈希登记、风格件可读。
