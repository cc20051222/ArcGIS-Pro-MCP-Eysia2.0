> 模板族：规划类（Planning）｜M2 十六模板之一｜版本：v0.1（D-095 初版）
> 对应场景：S04 值域与子类型治理｜M2 支柱：质量与溯源（quality-provenance）
> 输入政策：current-tool-surface
> 判据引用（rules-v2，阈值不自定义）：CMP-002、FLD-001、NUM-001、PRM-001、RPT-001、SCI-001

## 1. 版面结构

```
┌─────────────────────────────────────────────────┐
│  标题区（主标题＋副标题：分组口径/指标＋日期）      │
├──────────────────────────────────────┬──────────┤
│                                      │          │
│     分组公平性主图                    │ 分组指标  │
│  (分组单元按公平性指标设色＋公共服务   │ 表＋图表  │
│   设施点＋研究区边界)                 │ (组间对比)│
│                                      │          │
├──────────────────────────────────────┴──────────┤
│  图例区 ｜ 比例尺 ｜ 指北针 ｜ 分组/分母口径脚注   │
└─────────────────────────────────────────────────┘
```

- **主图区**占版面 ≥60%；分组单元（人口分组/片区）按公平性指标设色，叠加公共服务设施。
- **分组指标表**：逐组列出分母（人口/需求）、服务供给、公平性指标，组间可比。
- **整饰件**：比例尺、指北针、图例、脚注（分组口径与分母定义）。

## 2. 语义槽位

| 槽位 ID | 语义 | 数据类型 | 必填 | 来源 |
|---|---|---|---|---|
| `title.main` | 主标题（如「XX 公共服务分组公平性分析」） | string | 是 | TaskBrief |
| `title.sub` | 副标题（分组口径/指标） | string | 是 | TaskBrief |
| `study_area.geom` | 研究区面 | polygon | 是 | boundary |

## 3. 字号与约束

| 元素 | 字号（pt，A3 300DPI） | 字重 | 约束 |
|---|---|---|---|
| 主标题 | 26–34 | Bold | 超长缩至 ≥20pt |
| 副标题 | 13–17 | Regular | 含分组口径 |
| 分组注记 | 8–11 | Regular | 不压盖 |
| 指标表 | 8–10 | Regular | 分母/供给/指标同源 |
| 图例条目 | 9–10 | Regular | — |
| 脚注 | 8 | Regular | 含分母定义 |

**硬约束**：
- 最小字号 ≥8pt（待 rules-v2 冻结）。
- **须有合法人口分组与分母**：分组口径合规、分母定义明确且非零；公平性指标定义固定，**不能由地图视觉推断社会结论**（能力目录 §7 明示）。
- 字段约束/值域校验（FLD-001）：不可解析约束标 UNKNOWN，不计为满足；模式对比（CMP-002）正确，值域差异单独分类。
- 公平性指标由分母与供给现算（NUM-001）；结论有科学依据（SCI-001）。
