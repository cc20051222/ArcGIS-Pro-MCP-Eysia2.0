## 1. 版面结构

```
┌─────────────────────────────────────────────────┐
│  标题区（主标题＋副标题：两期/两版＋日期）          │
├──────────────────────────┬──────────────────────┤
│                          │                      │
│   差异分布主图            │ 差异统计              │
│ (增/减/变化区域分级设色   │ 表＋差异分布直方图     │
│  ＋研究区边界)           │ (变化量均值/极值/     │
│                          │  标准差)              │
├──────────────────────────┴──────────────────────┤
│ 图例区｜比例尺｜指北针｜两期版本/来源/方法脚注      │
└─────────────────────────────────────────────────┘
```

- **主图区**占版面 ≥60%；差异（变化量）按大小/方向分级设色。
- **差异统计**：变化量描述统计＋分布直方图，与主图同源。
- **整饰件**：比例尺、指北针、图例（增/减/变化分级）、脚注（两期版本号/来源/差分方法）。

## 2. 语义槽位

| 槽位 ID | 语义 | 数据类型 | 必填 | 来源 |
|---|---|---|---|---|
| `title.main` | 主标题（如「XX 两期变化量与差异分布图」） | string | 是 | TaskBrief |
| `title.sub` | 副标题（两期/两版本标识） | string | 是 | TaskBrief |

| `baseline.data` | 基期/基线数据 | raster/layer | 是 | 输入 |

| `difference.direction` | 变化方向（增/减） | enum | 是 | 差分定义 |
| `fact.diff` | 变化量描述统计/分布 FactTable | FactTable | 是 | FactTable（M07） |

| `source.note` | 两期来源/日期 | string | 是 | DatasetContract.来源 |

## 3. 字号与约束

| 元素 | 字号（pt，论文版/A3） | 字重 | 约束 |
|---|---|---|---|
| 主标题 | 20–30（论文）/26–34 | Bold | 超长缩至档下限 |
| 副标题 | 11–17 | Regular | 含两期标识 |
| 图内注记 | 7–10 | Regular | 论文最小 ≥7pt |
| 差异统计/直方图 | 7–10 | Regular | 与图同差分 |
| 图例条目 | 7–10 | Regular | 增/减可区分 |
| 脚注 | 7–8 | Regular | 版本/方法可查 |

**硬约束**：
- 论文版最小字号 ≥7pt（待 rules-v2 冻结精确值）。
- **两期须可比**：数据对比分区（CMP-001）、模式对比（CMP-002）正确；差分须在共同 CRS/格网下进行。
- 差异统计由差分值现算（NUM-001）；变化方向定义明确。
- **换数据保留设计意图**（S29）：视觉 Patch 继承，依赖重算（DEP-001）；外部母版哈希前后相同、只生新版（PRT-001，critical）。
