## 1. 版面结构

```
┌─────────────────────────────────────────────────┐
│  标题区（主标题＋副标题：变量/显著性水平＋日期）    │
├─────────────────────────────────────────────────┤
│                                                 │
│        热点显著性分布主图                         │
│  (热点/冷点按置信度分级：99%/95%/90%＋不显著)     │
│                                                 │
├─────────────────────────────────────────────────┤
│ 热点/冷点计数表｜Gi z-score 说明                  │
├─────────────────────────────────────────────────┤
│ 图例｜比例尺｜指北针｜权重/FDR/显著性脚注           │
└─────────────────────────────────────────────────┘
```

- **主图区**：每个单元按 Gi* 显著性分级（热点 99/95/90%、冷点 99/95/90%、不显著）。
- **计数表**：各显著性级热点/冷点单元数。
- **整饰件**：比例尺、指北针、图例（7 级显著性）、脚注（空间权重/FDR 校正/显著性水平）。

## 2. 语义槽位

| 槽位 ID | 语义 | 数据类型 | 必填 | 来源 |
|---|---|---|---|---|
| `title.main` | 主标题（如「XX 热点（Getis-Ord Gi*）显著性分布」） | string | 是 | TaskBrief |

## 3. 字号与约束

| 元素 | 字号（pt，论文/A3） | 字重 | 约束 |
|---|---|---|---|
| 主标题 | 20–34 | Bold | 超长缩至档下限 |
| 图内注记 | 7–10 | Regular | ≥7pt |
| 计数表 | 7–10 | Regular | 各级计数与图一致 |
| 图例条目 | 7–10 | Regular | 7 级可区分（含色盲友好） |
| 脚注 | 7–8 | Regular | 权重/FDR/显著性可查 |

**硬约束**：
- 论文版最小字号 ≥7pt（待 rules-v2 冻结）。
- **热点/冷点分级须与 Gi* z-score 和显著性水平严格对应**；FDR 校正须显式标注（用/不用）；不得由视觉高值直接判热点（SCI-001）。
- 空间权重显式定义；各级计数由分级结果现算（NUM-001）；数字同源（SRC-001）、溯源（LNG-001）。
- **P5 能力未实现期间不声称热点结果**；副作用计数（PRM-001）。
