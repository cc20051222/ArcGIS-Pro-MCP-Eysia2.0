## 1. 版面结构

```
┌─────────────────────────────────────────────────┐
│  标题区（主标题＋副标题：冲突类型/数量＋日期）      │
├──────────────────────────────────────┬──────────┤
│                                      │          │
│       规划冲突诊断主图                │ 冲突清单  │
│  (冲突地块/图斑高亮＋规划层 vs 对照层  │  表       │
│   ＋研究区边界，非冲突区灰化)          │ 编号/类型/ │
│                                      │ 位置/面积 │
├──────────────────────────────────────┴──────────┤
│  图例区 ｜ 比例尺 ｜ 指北针 ｜ 判定规则/来源脚注   │
└─────────────────────────────────────────────────┘
```

- **主图区**占版面 ≥55%；冲突要素高亮，非冲突底图灰化以突出冲突。
- **冲突清单表**：逐行列出冲突编号/类型/位置/面积，与地图高亮一一对应。
- **整饰件**：比例尺、指北针、图例（冲突类型分类）、脚注（判定规则与数据来源）。

## 2. 语义槽位

| 槽位 ID | 语义 | 数据类型 | 必填 | 来源 |
|---|---|---|---|---|
| `title.main` | 主标题（如「XX 规划方案冲突诊断图」） | string | 是 | TaskBrief |
| `title.sub` | 副标题（冲突类型/总数） | string | 是 | AnalysisPlan |
| `study_area.geom` | 研究区面要素 | polygon | 是 | 输入 boundary |
| `plan.layer` | 待诊断规划方案层 | layer | 是 | 输入规划 |
| `compare.layers[]` | 对照层（现状/保护红线/上位规划） | layer[] | 是 | 对照输入 |
| `conflict.features[]` | 冲突要素（点/面） | feature[] | 是 | 规则判定结果 |
| `conflict.type` | 冲突类型（用地性质/指标/边界/重复） | enum | 是 | 判定规则 |
| `conflict.id` | 冲突唯一编号 | string | 是 | 自动生成，唯一 |
| `fact.conflict` | 冲突数量/类型计数/面积 | FactTable | 是 | FactTable（M07） |
| `duplicate.groups` | 重复要素分组（属性/几何） | group[] | 条件 | DUP-001 |
| `coord.ref` | 坐标系标注 | string | 是 | DatasetContract.CRS |
| `source.note` | 规划/对照数据来源与年份 | string | 是 | DatasetContract.来源 |

## 3. 字号与约束

| 元素 | 字号（pt，A3 300DPI） | 字重 | 约束 |
|---|---|---|---|
| 主标题 | 26–34 | Bold | 超长缩至 ≥20pt |
| 副标题 | 13–17 | Regular | 含冲突总数 |
| 冲突编号/注记 | 8–11 | Bold/Regular | 编号不压盖、可定位 |
| 冲突清单表 | 8–10 | Regular | 行与地图高亮一一对应 |
| 图例条目 | 9–10 | Regular | 冲突类型逐项 |
| 脚注 | 8 | Regular | 含判定规则依据 |

**硬约束**：
- 最小字号 ≥8pt（待 rules-v2 冻结）。
- **冲突判定基于显式规则**：数据对比分区（新增/删除/修改）互斥且并集等于预期差异（CMP-001）；几何质量缺陷集与预期一致（QLT-001）。
- **冲突编号唯一**，清单表行数＝地图冲突要素数；重复要素按 DUP-001 分组（几何模式须声明容差），不得在两组重复出现。
- 冲突判定须有科学依据（SCI-001）；不得把无冲突要素误报或漏报。

## 4. 输入档案

| 档案 | 格式 | 必需字段 | 说明 |
|---|---|---|---|
| 规划方案层 | polygon | 用地性质/指标字段 | 待诊断对象 |
| 现状/保护/上位对照层 | polygon | 对照字段 | 一层或多层 |
| 研究区边界 | polygon | NAME | 裁剪范围 |

**预检**（M02）：关键字段非空、CRS 一致、几何有效性（QLT-001）、关键字段声明、对照层可对比（CMP-001）。
