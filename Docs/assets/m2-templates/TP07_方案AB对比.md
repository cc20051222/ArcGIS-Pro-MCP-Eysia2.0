# TP07 · 方案A/B对比 — 资产规格书

> 模板族：规划类（Planning）｜M2 十六模板之一｜版本：v0.1（D-095 初版）
> 对应场景：S21 方案A/B对照｜M2 支柱：质量与溯源（quality-provenance）
> 输入政策：current-tool-surface
> 判据引用（rules-v2，阈值不自定义）：CMP-001、CMP-002、NUM-001、RFL-001、RPT-001、SRC-001

---

## 1. 版面结构

```
┌─────────────────────────────────────────────────┐
│  标题区（主标题＋副标题：对比维度＋日期）           │
├────────────────────────┬────────────────────────┤
│                        │                        │
│   方案 A 主图           │   方案 B 主图           │
│  (同范围/同比例尺/      │  (同范围/同比例尺/      │
│   同符号体系)           │   同符号体系)           │
│                        │                        │
├────────────────────────┴────────────────────────┤
│        对比指标表（指标 ｜ A 值 ｜ B 值 ｜ 差值）   │
├─────────────────────────────────────────────────┤
│  图例（共用）｜ 比例尺 ｜ 指北针 ｜ 来源脚注        │
└─────────────────────────────────────────────────┘
```

- **双图等大并列**，必须同范围、同比例尺、同符号体系，仅方案内容不同。
- **对比指标表**：同指标逐行列出 A 值/B 值/差值，与双图数据同源。
- **整饰件**：共用图例、（双）比例尺、指北针、脚注。

## 2. 语义槽位

| 槽位 ID | 语义 | 数据类型 | 必填 | 来源 |
|---|---|---|---|---|
| `title.main` | 主标题（如「XX 方案 A/B 对比」） | string | 是 | TaskBrief |
| `title.sub` | 副标题（对比维度） | string | 否 | TaskBrief |
| `study_area.geom` | 研究区面要素（两图共用） | polygon | 是 | 输入 boundary |
| `option_a.data` | 方案 A 数据 | layer | 是 | 方案 A 输入 |
| `option_b.data` | 方案 B 数据 | layer | 是 | 方案 B 输入 |
| `compare.metrics[]` | 对比指标列表 | metric[] | 是 | TaskBrief/AnalysisPlan |
| `fact.compare` | 指标 A 值/B 值/差值对比表 | FactTable | 是 | FactTable（M07） |
| `symbology.common` | 共用符号体系 | style | 是 | 模板/项目风格 |
| `coord.ref` | 坐标系（两图一致） | string | 是 | DatasetContract.CRS |
| `scale.denominator` | 比例尺（两图相同） | integer | 是 | 自动计算 |
| `source.note` | 两方案数据来源 | string | 是 | DatasetContract.来源 |

## 3. 字号与约束

| 元素 | 字号（pt，A3 300DPI） | 字重 | 约束 |
|---|---|---|---|
| 主标题 | 26–34 | Bold | 超长缩至 ≥20pt |
| 子图标题（方案A/B） | 14–18 | Bold | 两标题同级 |
| 图内注记 | 8–11 | Regular | 两图标注规则一致 |
| 对比指标表 | 9–11 | Regular | 数值精度一致、同源 |
| 图例条目 | 9–10 | Regular | 共用一套 |
| 脚注 | 8 | Regular | — |

**硬约束**：
- 最小字号 ≥8pt（待 rules-v2 冻结）。
- **双图三同**：同范围、同比例尺分母、同符号体系；数据对比分区正确（CMP-001）、模式字段级对比正确（CMP-002）。
- **指标同源**（SRC-001）：对比表每个数字可回溯至方案 FactTable，同修订；差值＝B−A（或约定方向）算术正确。
- 媒介重排（如改上下排列、转 PPT）只改版面不改事实（RFL-001）。

## 4. 输入档案

| 档案 | 格式 | 必需字段 | 说明 |
|---|---|---|---|
| 方案 A 数据 | layer | 方案指标字段 | 与 B 同 CRS |
| 方案 B 数据 | layer | 同 A 字段结构 | 可对比 |
| 研究区边界 | polygon | NAME | 两图共用范围 |

**预检**（M02）：两方案 CRS 一致、字段结构可比（CMP-002）、范围一致、指标字段非空、几何有效。

| 意图 ID | 改稿类型 | 动作 | 语义检查 |
|---|---|---|---|
