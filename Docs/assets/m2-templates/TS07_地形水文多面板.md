# TS07 · 地形水文多面板 — 资产规格书

> 模板族：科研类（Scientific）｜M2 十六模板之一｜版本：v0.1（D-095 初版）
> 对应场景：S13 DEM坡度坡向地形专题｜M2 支柱：多媒介重排（multi-media-reflow）
> 输入政策：**qualified-frozen-input**——分析侧能力 `raster_reproject`（P6）、`zonal_histogram`（P6）属后续领域批，**当前未实现**；本规格只定设计面。
> 判据引用（rules-v2，阈值不自定义）：ALN-001、GEO-001、OUT-001、RFL-001、TXT-001

---

## 1. 版面结构

```
┌─────────────────────────────────────────────────┐
│  标题区（主标题＋副标题：DEM/流域＋日期）          │
├──────────────┬──────────────┬───────────────────┤
│              │              │                   │
│ 高程面板      │ 坡度面板      │ 坡向面板           │
│ (DEM 连续色) │ (坡度分级)   │ (坡向罗盘色)       │
│              │              │                   │
├──────────────┴──────────────┴───────────────────┤
│ （可选）流域/水系面板 ｜ 地形剖面/直方图           │
├─────────────────────────────────────────────────┤
│ 各面板图例｜比例尺（共用）｜指北针｜方法/格网脚注   │
└─────────────────────────────────────────────────┘
```

- **多面板拼版**：高程/坡度/坡向（可加流域水系、剖面），各面板同范围。
- **面板色板**：高程连续色、坡度分级、坡向罗盘方向色。
- **整饰件**：各面板图例、共用比例尺、指北针、脚注（垂直/水平单位、格网、算法）。

## 2. 语义槽位

| 槽位 ID | 语义 | 数据类型 | 必填 | 来源 |
|---|---|---|---|---|
| `title.main` | 主标题（如「XX 地形水文多面板分析」） | string | 是 | TaskBrief |
| `study_area.geom` | 研究区面 | polygon | 是 | boundary |
| `dem.raster` | 数字高程模型 | raster | 是 | 输入 DEM |
| `panel.elevation` | 高程面板（连续色） | panel | 是 | DEM 渲染 |
| `panel.slope` | 坡度面板（分级，单位 °/%） | panel | 是 | P6 计算（挂账） |
| `panel.aspect` | 坡向面板（罗盘方向） | panel | 是 | P6 计算（挂账） |
| `panel.hydrology` | 流域/水系面板（可选） | panel | 否 | P6 计算（挂账） |
| `zonal.histogram` | 分区直方图/剖面（可选） | chart | 否 | P6 zonal_histogram（挂账） |
| `units.vh` | 垂直/水平单位 | unit | 是 | DEM 元数据 |
| `coord.ref` | 坐标系（含垂直基准） | string | 是 | DatasetContract.CRS |
| `source.note` | DEM 来源/分辨率/日期 | string | 是 | DatasetContract.来源 |

## 3. 字号与约束

| 元素 | 字号（pt，论文/A3） | 字重 | 约束 |
|---|---|---|---|
| 主标题 | 20–34 | Bold | 超长缩至档下限 |
| 面板标题 | 10–16 | Bold | 各面板同级 |
| 图内注记 | 7–10 | Regular | ≥7pt |
| 图例/色标 | 7–10 | Regular | 各面板单位标注 |
| 脚注 | 7–8 | Regular | 算法/格网/单位可查 |

**硬约束**：
- 论文版最小字号 ≥7pt（待 rules-v2 冻结）。
- **各面板空间范围一致、格网对齐**（ALN-001/GEO-001）；坡度/坡向算法与单位（°/%、罗盘方向）在脚注可查（TXT-001）。
- **多媒介重排只改版面不改事实**（RFL-001）：转竖排/横排、论文/打印时各面板数值与高程/坡度统计跨媒介一致，不丢面板、不裁切文字。
- **P6 能力（重投影/分区直方图）未实现期间不声称**；DEM 垂直基准与单位须明确。

## 4. 输入档案

| 档案 | 格式 | 必需字段 | 说明 |
|---|---|---|---|
| DEM | raster | 高程有效、垂直单位 | CRS 含垂直基准 |
| 研究区边界 | polygon | NAME | — |
| （可选）流域/水系 | raster/vector | — | 水文分析 |

**预检**（M02）：DEM 有效无空洞、CRS/垂直基准、格网、坡度坡向可计算、面板范围一致。**[VERIFY]** 重投影/分区直方图随 P6。
