## 1. 版面结构

```
┌─────────────────────────────────────────────────┐
│  标题区（主标题＋副标题：分类器/验证方案＋日期）    │
├─────────────────────────────────────────────────┤
│                                                 │
│        分类结果主图（类别设色＋研究区边界）         │
│                                                 │
├─────────────────────────────────────────────────┤
│ 混淆矩阵表（参考类×预测类，计数/归一化）           │
├─────────────────────────────────────────────────┤
│ 精度指标：OA/Kappa/各类 PA(召回)/UA(精度)/F1      │
├─────────────────────────────────────────────────┤
│ 图例｜比例尺｜指北针｜验证样本/抽样/来源脚注        │
└─────────────────────────────────────────────────┘
```

- **分类主图**：类别设色。
- **混淆矩阵**：参考（真值）类×预测类计数，可附归一化。
- **精度指标**：总体精度 OA、Kappa、各类生产者精度 PA/用户精度 UA/F1。
- **整饰件**：图例、比例尺、指北针、脚注（验证样本来源/抽样设计/样本量/是否独立）。

## 2. 语义槽位

| 槽位 ID | 语义 | 数据类型 | 必填 | 来源 |
|---|---|---|---|---|
| `title.main` | 主标题（如「XX 分类结果与精度评估」） | string | 是 | TaskBrief |

| `fact.accuracy` | 精度 FactTable | FactTable | 是 | FactTable（M07） |
| `coord.ref` | 坐标系标注 | string | 是 | DatasetContract.CRS |
| `source.note` | 分类/验证来源 | string | 是 | DatasetContract.来源 |

## 3. 字号与约束

| 元素 | 字号（pt，论文/A3） | 字重 | 约束 |
|---|---|---|---|
| 主标题 | 20–34 | Bold | 超长缩至档下限 |
| 分类图注记 | 7–10 | Regular | ≥7pt |
| 混淆矩阵 | 7–10 | Regular | 行列合计自洽 |
| 精度指标 | 8–12 | Bold/Regular | 由矩阵现算 |
| 图例条目 | 7–10 | Regular | 类别色与图一致 |
| 脚注 | 7–8 | Regular | 验证独立性/抽样可查（TXT-001） |

**硬约束**：
- 论文版最小字号 ≥7pt（待 rules-v2 冻结）。
- **独立精度评估**：验证样本须独立于训练样本；抽样设计/样本量/参考数据来源在脚注可查；不得用训练精度冒充泛化精度（SCI-001）。
- **混淆矩阵算术自洽**：行/列合计＝各类参考/预测计数；OA/Kappa/PA/UA/F1 由矩阵现算（NUM-001），与矩阵一致。
- 数据对比（CMP-001）正确；数字同源（SRC-001）。
