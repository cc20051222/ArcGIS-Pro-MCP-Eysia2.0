# TS10 · 不确定性与误差表达 — 资产规格书

> 模板族：科研类（Scientific）｜M2 十六模板之一｜版本：v0.1（D-095 初版）
> 对应场景：S52 量测误差传播｜M2 支柱：复杂内容保护（complex-content-protection）
> 输入政策：**qualified-frozen-input**——分析侧能力「量测误差传播（measurement error propagation，X5 领域批）」属后续批次，**当前未实现**；本规格只定设计面。
> 判据引用（rules-v2，阈值不自定义）：LNG-001、NUM-001、OUT-001、RFL-001、SCI-001、SRC-001

---

## 1. 版面结构

```
┌─────────────────────────────────────────────────┐
│  标题区（主标题＋副标题：误差来源/置信水平＋日期）  │
├──────────────────────────┬──────────────────────┤
│                          │                      │
│  不确定性表达主图          │ 误差/区间统计         │
│ (估计值面＋误差/置信区间   │ 均值误差/置信区间     │
│  叠加，或双图：值＋不确定) │ 表＋误差分布         │
│                          │                      │
├──────────────────────────┴──────────────────────┤
│ 图例｜比例尺｜指北针｜误差模型/假设/来源脚注        │
└─────────────────────────────────────────────────┘
```

- **主图区**：估计值与其不确定性（误差棒/置信区间面/双图值＋不确定）同时表达。
- **误差统计**：误差/区间统计与分布，与主图同源。
- **整饰件**：比例尺、指北针、图例（值＋不确定性）、脚注（误差模型/分布假设/置信水平/传播方法）。

## 2. 语义槽位

| 槽位 ID | 语义 | 数据类型 | 必填 | 来源 |
|---|---|---|---|---|
| `title.main` | 主标题（如「XX 估计值不确定性与误差表达」） | string | 是 | TaskBrief |
| `study_area.geom` | 研究区面 | polygon | 是 | boundary |
| `estimate.values` | 估计值（主结果） | raster/layer | 是 | 输入/计算 |
| `uncertainty.measure` | 不确定性度量（标准差/方差/置信区间） | raster/layer | 是 | X5 计算（挂账） |
| `error.model` | 误差模型/分布假设 | string | 是 | AnalysisPlan |
| `confidence.level` | 置信水平（如 95%） | number | 是 | TaskBrief |
| `propagation.method` | 误差传播方法（解析/蒙特卡洛） | enum | 是 | X5（挂账） |
| `fact.uncertainty` | 误差/区间统计 FactTable | FactTable | 是 | FactTable（M07） |
| `coord.ref` | 坐标系标注 | string | 是 | DatasetContract.CRS |
| `source.note` | 数据/误差来源 | string | 是 | DatasetContract.来源 |

## 3. 字号与约束

| 元素 | 字号（pt，论文/A3） | 字重 | 约束 |
|---|---|---|---|
| 主标题 | 20–34 | Bold | 超长缩至档下限 |
| 图内注记 | 7–10 | Regular | ≥7pt |
| 误差/区间表 | 7–10 | Regular | 与图同源 |
| 图例条目 | 7–10 | Regular | 值与不确定性可区分 |
| 脚注 | 7–8 | Regular | 误差模型/假设可查 |

**硬约束**：
- 论文版最小字号 ≥7pt（待 rules-v2 冻结）。
- **误差与区间含义必须分别说明、不可互换「可信度」**（能力目录 §7：TS10/11/14/16/17 对应误差、区间和集合含义分别说明）。
- 误差模型/分布假设/置信水平/传播方法须显式标注（脚注）；不确定性由误差传播现算（NUM-001），不得用估计值视觉范围冒充误差（SCI-001）。
- 数字同源（SRC-001）、溯源（LNG-001）；媒介重排不改事实（RFL-001）。
- **X5 误差传播能力未实现期间不声称结果**。
