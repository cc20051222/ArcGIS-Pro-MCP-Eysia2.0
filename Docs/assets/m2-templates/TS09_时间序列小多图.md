> 模板族：科研类（Scientific）｜M2 十六模板之一｜版本：v0.1（D-095 初版）
> 对应场景：S27 科研插图自动成稿｜M2 支柱：批量页与项目风格（batch-and-style）
> 输入政策：current-tool-surface

## 1. 版面结构

```
┌─────────────────────────────────────────────────┐
│  标题区（主标题＋副标题：变量/时间范围＋日期）      │
├─────────────────────────────────────────────────┤
│  小多图网格（small multiples）：                  │
│  ┌────┐┌────┐┌────┐┌────┐                       │
│  │t1  ││t2  ││t3  ││t4  │  每格同一时间点/单元，  │
│  └────┘└────┘└────┘└────┘  同比例尺/同符号体系   │
│  ┌────┐┌────┐┌────┐┌────┐                       │
│  │t5  ││t6  ││ ...││tn  │                       │
│  └────┘└────┘└────┘└────┘                       │
├─────────────────────────────────────────────────┤
│ 共用色标/图例｜时间轴标注｜来源/方法脚注           │
└─────────────────────────────────────────────────┘
```

- **小多图（small multiples）**：网格内每格一个时间点（或单元），全部同范围、同比例尺、同符号体系，仅时间切片不同。
- **共用色标**：统一连续/分级色标，格间可比。
- **整饰件**：共用图例/色标、每格时间标签、脚注（时间分辨率/缺测处理/来源）。

## 2. 语义槽位

| 槽位 ID | 语义 | 数据类型 | 必填 | 来源 |
|---|---|---|---|---|
| `title.main` | 主标题（如「XX 变量时间序列小多图」） | string | 是 | TaskBrief |
| `study_area.geom` | 研究区面（各格共用） | polygon | 是 | boundary |
| `timeseries.data` | 时间序列数据（多时间切片） | raster[]/layer[] | 是 | 输入 |
| `time.labels` | 各时间点标签（等间隔/实际日期） | datetime[] | 是 | 元数据 |
| `grid.layout` | 小多图行列网格 | layout | 是 | AnalysisPlan |
| `variable.field` | 显示变量/色标字段 | number | 是 | 数据 |
| `symbology.common` | 共用符号/色标 | style | 是 | STY-001 |
| `missing.policy` | 缺测/无数据处理策略 | string | 是 | AnalysisPlan |
| `fact.timeseries` | 各时间点统计 FactTable | FactTable | 是 | FactTable（M07） |
| `coord.ref` | 坐标系（各切片一致） | string | 是 | DatasetContract.CRS |
| `source.note` | 数据来源/时间分辨率 | string | 是 | DatasetContract.来源 |

## 3. 字号与约束

| 元素 | 字号（pt，论文/A3） | 字重 | 约束 |
|---|---|---|---|
| 主标题 | 20–34 | Bold | 超长缩至档下限 |
| 每格时间标签 | 7–10 | Bold | 各格位置一致 |
| 格内注记 | 7–9 | Regular | 格小则抽稀 |
| 共用色标 | 7–10 | Regular | 全格统一值域 |
| 脚注 | 7–8 | Regular | 缺测策略可查 |

**硬约束**：
- 论文版最小字号 ≥7pt（待 rules-v2 冻结）。
- **小多图三同**（BAT-001）：各格同范围、同比例尺、同符号/色标值域；格序按时间，时间标签完整。
- **缺测如实处理**：无数据时间片以约定方式标注（空位/灰格），不得插值伪造（SCI-001）；时间分辨率与历法明确（TXT-001）。
- 风格令牌来自带 hash 风格件（STY-001）；各时间点统计现算（NUM-001）。

## 4. 输入档案

| 档案 | 格式 | 必需字段 | 说明 |
|---|---|---|---|
| 时间序列切片 | raster[]/layer[] | 时间戳 | 同格网、同 CRS |
| 研究区边界 | polygon | NAME | — |

**预检**（M02）：时间戳完整等间隔、各切片格网/CRS 一致、缺测识别、色标值域可统一。
