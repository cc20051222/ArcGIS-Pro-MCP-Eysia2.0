# TS05 · 空间自相关结果 — 资产规格书

> 模板族：科研类（Scientific）｜M2 十六模板之一｜版本：v0.1（D-095 初版）
> 对应场景：S11 邻接与格网统计｜M2 支柱：质量与溯源（quality-provenance）
> 输入政策：**qualified-frozen-input**——分析侧能力 `spatial_autocorrelation`（Global Moran's I，P5）属后续领域批，**当前未实现**；本规格只定设计面。
> 判据引用（rules-v2，阈值不自定义）：LNG-001、NUM-001、OUT-001、SCI-001、SRC-001

---

## 1. 版面结构

```
┌─────────────────────────────────────────────────┐
│  标题区（主标题＋副标题：变量/方法＋日期）         │
├──────────────────────────┬──────────────────────┤
│                          │                      │
│  空间自相关结果主图        │ 统计结果              │
│ (分析单元＋空间权重示意)   │ Moran's I 值         │
│                          │ 期望值/z-score/      │
│                          │ p-value＋判定        │
├──────────────────────────┴──────────────────────┤
│ 图例｜比例尺｜指北针｜方法/权重/显著性脚注          │
└─────────────────────────────────────────────────┘
```

- **主图区**：分析单元（可含空间权重连接示意）；结果以统计量＋显著性判定呈现。
- **统计结果块**：Moran's I、期望 E[I]、z-score、p-value、聚集/离散/随机判定。
- **整饰件**：比例尺、指北针、图例、脚注（空间权重定义/置换次数/显著性水平）。

## 2. 语义槽位

| 槽位 ID | 语义 | 数据类型 | 必填 | 来源 |
|---|---|---|---|---|
| `title.main` | 主标题（如「XX 变量空间自相关分析」） | string | 是 | TaskBrief |
| `study_area.geom` | 研究区面 | polygon | 是 | boundary |
| `units.geom` | 分析单元 | polygon/point | 是 | 输入 |
| `variable.field` | 分析变量字段 | number | 是 | 单元属性 |
| `weights.type` | 空间权重（邻接 Rook/Queen / 距离 KNN/距离阈值） | enum | 是 | AnalysisPlan |
| `moran.i` | Global Moran's I 值 | number | 是 | P5 计算（挂账） |
| `moran.expected` | 期望 E[I]、z-score、p-value | number | 是 | P5 计算（挂账） |
| `permutations` | 置换检验次数 | integer | 是 | AnalysisPlan |
| `fact.autocorr` | 统计结果 FactTable | FactTable | 是 | FactTable（M07） |
| `coord.ref` | 坐标系标注 | string | 是 | DatasetContract.CRS |
| `source.note` | 单元/变量来源 | string | 是 | DatasetContract.来源 |

## 3. 字号与约束

| 元素 | 字号（pt，论文/A3） | 字重 | 约束 |
|---|---|---|---|
| 主标题 | 20–34 | Bold | 超长缩至档下限 |
| 图内注记 | 7–10 | Regular | ≥7pt |
| 统计结果 | 8–12 | Regular | I/z/p 数值完整 |
| 图例条目 | 7–10 | Regular | — |
| 脚注 | 7–8 | Regular | 权重/置换/显著性可查 |

**硬约束**：
- 论文版最小字号 ≥7pt（待 rules-v2 冻结）。
- **空间权重必须显式定义**（类型/阶数/标准化）；显著性水平与置换次数在脚注可查；判定（聚集/离散/随机）须与 p-value 对应，不得由视觉聚类下结论（SCI-001）。
- Moran's I/E[I]/z/p 由分析现算（NUM-001）；数字同源（SRC-001）；溯源完整（LNG-001）。
- **P5 能力未实现期间，不声称自相关结果**；相关请求标待领域批。
