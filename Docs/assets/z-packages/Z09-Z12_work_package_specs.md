## Z09 · 风格与批量

| 维度 | 内容 |
|---|---|
| **所有者职责**（M10 模板与布局 ＋ M15 版本与更新） | 将"显式项目风格"（字体/色板/图框/标题栏/页脚/图例样式的命名集合）规范化进 DesignSpec，支持命名保存与跨作业复用；批量（多页/十页图册）按页数/像素**事先计算整作业总预算并持久化**，保证跨页分类与整饰一致 |
| **完成证据** | ① 项目风格可命名保存、复用到新作业（风格 revision 可查）；② 十页图册的分类/配色/标题栏/页脚/页码逐页一致；③ 批量整作业总预算持久化（不逐页重置）；④ 风格继承下事实数字仍由 FactTable 决定（改风格不改数据） |
| **输入** | TaskBrief、显式项目风格（或参考成品）、模板规格、批量页数/像素 |
| **输出** | 命名 `ProjectStyle`（revision/字体/色板/图框/整饰）＋ 批量整作业预算 ＋ 批量 `RenderPlan` |
| **判据** | 跨页整饰一致率 100%；批量预算不超限（F04 待校准，**以 L2 冻结面为准**）；风格不改事实；风格复用结果与逐页独立求解视觉等价 |
| **依赖模块** | **M10**（布局/风格规范化）→ **M15**（风格 Patch 继承/revision）；上游 Z01/Z02，与 Z03 并行；下游 → Z10/Z11 |

## Z10 · 多用途重排

| 维度 | 内容 |
|---|---|
| **所有者职责**（M10 ＋ M14 自动设计与修正 ＋ M16 检查与交付） | 同一 FactTable/DesignSpec 面向多媒介（横/竖屏、打印、论文、PPT、长图）重排：按各媒介尺寸/分辨率/安全边距/最小字号重新求解布局，逐媒介生成并检查（一源多成果） |
| **完成证据** | ① 每种媒介有可验证规格（尺寸/DPI/安全边距/字号）；② 多成果共享同一事实，地图/图册/汇报页/PPTX/长图数字一致；③ 横竖切换/附页重排自动完成且硬约束全过；④ 逐媒介真实渲染＋检查（非简单等比缩放） |
| **输入** | DesignSpec、FactTable、目标媒介集合及规格 |
| **输出** | 逐媒介 `RenderPlan`/成果 ＋ 媒介规格矩阵 ＋ 同源校验报告 |
| **判据** | 各媒介硬约束 100% 通过；同源数字一致率 100%；最小字号按媒介下限（**以 L2 冻结面为准**）；非等比缩放/裁剪导致的科学变形 0 |
| **依赖模块** | **M10**（尺寸/横竖/附页重排）→ **M14**（逐媒介求解/评分）→ **M16**（逐媒介检查）；上游 Z09；下游 → Z11 |

## Z11 · 复杂内容保护

| 维度 | 内容 |
|---|---|
| **所有者职责**（M13 UXP 执行 ＋ M15 ＋ M16） | 处理密集文字/复杂图册（10 页）/外部修改过的母版：密集内容自动求解（不删真实类别、不无限缩字，必要时附页/分列）；外部修改保留原件并生成新版；细粒度合并仅限经等价性验证的范围 |
| **完成证据** | ① 密集文字/图例不溢出（附页/分列，真实类别 0 删除）；② 10 页图册全页自动完成；③ 外部改过的 PSD/母版：原件保留、生成新版、差异可追溯；④ 细粒度合并仅在验证范围内（不盲受外部改动）；⑤ 复杂内容科学保护复验通过 |
| **输入** | 复杂/密集任务、外部修改母版（若有）、DesignSpec、FactTable |
| **输出** | 复杂内容成果 ＋ 外部修改处理记录（原件/新版/差异）＋ 合并范围验证报告 |
| **判据** | 真实类别 0 删除；密集内容硬约束 100%；外部原件保留率 100%；合并仅在验证范围；严重科学错误 0（检查项**以 L2 冻结面为准**） |
| **依赖模块** | **M13**（复杂文档/保存重开）→ **M15**（外部修改/新版/强指纹）→ **M16**（复杂内容检查）；上游 Z10；下游 → Z05/Z12 |

## Z12 · 持续设计验收

| 维度 | 内容 |
|---|---|
| **所有者职责**（M19 评测与观测 ＋ 独立专业人员/指挥席） | 为每模板建立标准例（黄金图）/坏例库，持续对自动设计成果做**独立**验收；开发期人工修图不计入自动成功；执行/开发方不得自批 PASS |
| **完成证据** | ① 每模板有标准例与已知坏例；② 自动成功率基于无人工干预的真实运行（人工修图留痕且排除）；③ 独立专业人员/指挥席零采信复算（不采信执行方申报）；④ trace/介入次数/失败可查、日志脱敏 |
| **输入** | 各模板标准/坏例、自动运行 trace、独立验收脚本 |
| **输出** | 持续验收报告（自动/人工分界）、坏例库、独立复算结果 |
| **判据** | 人工修图不计自动成功；自批 PASS 无效；验收以独立复算为准；标准/坏例覆盖每模板（具体通过线**以 L2 冻结面为准**） |
| **依赖模块** | **M19**（trace/指标/分层验收）＋ 独立专业人员（指挥席）；**贯穿各阶段，无上下游** |
