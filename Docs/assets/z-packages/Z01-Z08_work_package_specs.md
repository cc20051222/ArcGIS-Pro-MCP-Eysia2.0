## Z01 · Brief 与数据画像

| 维度 | 内容 |
|---|---|
| **所有者职责**（M02 数据理解 ＋ M04 任务编译） | 接收用户输入（文件夹/GDB/表格/影像/项目图层＋用途/受众/尺寸/约束），生成结构化 TaskBrief；对数据做轻扫＋深读分层画像（CRS/字段/单位/时间/角色/质量），集中呈现歧义；表单路径与 AI 自然语言路径输出同一 TaskBrief 结构 |
| **完成证据** | ① 表单/AI 两条入口生成的 TaskBrief 结构逐字段一致（schema 对齐）；② 歧义清单集中呈现（非逐工具弹窗），含方法条件与许可提示；③ 数据画像含 CRS/字段统计/单位识别/质量 issue，置信度可查；④ 百万要素级数据不默认全量送模型（有深读/轻扫分层证据） |
| **输入** | 用户原始资料引用（路径/图层名）、用途选择（规划汇报/科研论文/…）、受众、输出尺寸/媒介、风格偏好、预算约束 |
| **输出** | `TaskBrief`（schemaVersion/taskId/用途/输入引用/输出根/方法约束/尺寸媒介/风格/预算/必需交付项）＋ `DatasetContract[]`（数据身份/指纹/字段/CRS/时间/质量/许可）＋ 歧义清单 |
| **判据** | TaskBrief 必填字段无缺；歧义项 ≤N 个且均有可行动选项（N 待 D-089 冻结）；数据画像 CRS/字段非空率 100%；AI 路径不凭空创造工具/字段/事实 |
| **依赖模块** | **M01** 能力目录（检索可用工具/许可）→ **M02** 数据理解（画像）→ **M04** 任务编译（Brief 生成）；上游无；下游 → Z02/Z03 |

## Z02 · 模板约束求解

| 维度 | 内容 |
|---|---|
| **所有者职责**（M10 模板与布局 ＋ M14 自动设计与修正） | 将 TaskBrief＋数据画像＋模板规格（TP/TS 五要素）转为 DesignSpec；用约束求解产生候选布局，先淘汰硬错误（图框/必需图例/最小字号/量化颜色），再按内容密度与用途选候选；可行/无解均如实返回 |
| **完成证据** | ① 可行解：候选布局 ≤12 个，硬约束全过，含语义槽位填充结果与最小字号校验；② 无解：明确返回无解原因（如标题超长且不可缩、图例数超限），不静默降质；③ 语义槽位与模板规格一一对应（无缺槽）；④ WPF 测量早筛＋目标 PS 实际测量定稿（双阶段证据） |
| **输入** | TaskBrief、DatasetContract[]、选定模板规格（TPxx/TSxx）、项目风格、字体/ICC 配置 |
| **输出** | `DesignSpec`（不可变 revision/模板版本/字体/ICC/页面尺寸/图框范围/语义 ID/factRef/保护项/布局约束）＋ 候选布局列表（≤12）＋ 求解日志（淘汰原因） |
| **判据** | 硬约束通过率 100%（图框/图例/最小字号/量化色）；最小字号 ≥ 模板规格下限（待 D-089 冻结精确值）；无解时原因可追溯；布局候选数 ≤12 |
| **依赖模块** | **M09** 符号与标注（分类/色阶/标签绑定事实）→ **M10** 模板与布局（槽位/约束/求解）→ **M14** 自动设计（候选筛选/评分）；上游 Z01；下游 → Z03 |

## Z03 · 真实预览推荐

| 维度 | 内容 |
|---|---|
| **所有者职责**（M11 GIS 素材包 ＋ M12 PS 连接 ＋ M13 UXP 执行 ＋ M17 用户工作台） | 将 DesignSpec 转为 RenderPlan，导出 GIS 语义素材包（透明分层＋manifest＋配准锚点），经 PS 通道导入并应用配方，真实渲染预览；推荐 1 个主稿＋≤2 个备选，revision 与预算一致 |
| **完成证据** | ① GIS 素材包：共同画布/原点/图框范围/导出 DPI 固定，逐层 hash＋配准锚点可查；② PS 导入：语义分层保留，配准误差 ≤阈值（待 D-089 冻结）；③ 预览：主稿 1＋备选 ≤2，均为真实 PS 渲染（非 WPF 模拟）；④ revision 与 DesignSpec 一致，预算消耗可查；⑤ [VERIFY] PS 通道可用性（P-05/F04-A 门未闭合前标注 NOT VERIFIED） |
| **输入** | DesignSpec、候选布局（≤3 进入预览）、GIS 项目数据、PS 宿主状态 |
| **输出** | 预览图（低清，≤3 张）＋ `RenderPlan`（受限宿主动作/输入 hash/期望输出/幂等键/预算）＋ 素材包 manifest＋ revision 号 |
| **判据** | 主稿 1＋备选 ≤2；预览为真实渲染；素材包逐层 hash 非空；配准误差 ≤阈值（待 D-089 冻结）；预算不超限 |
| **依赖模块** | **M11** GIS 素材包（导出/分层/配准）→ **M12** PS 连接（配对/心跳/断线）→ **M13** UXP 执行（导入/配方/渲染）→ **M17** 工作台（展示预览）；上游 Z02；下游 → Z04 |

## Z04 · 检查与修正

| 维度 | 内容 |
|---|---|
| **所有者职责**（M14 自动设计与修正 ＋ M16 检查与交付） | 对真实渲染结果做机器检查（溢出/碰撞/裁剪/事实/保护项），白名单内有限修正（容器/换行/图例列数/留白/字体方案/附页）；重复失败/评分无改进/预算耗尽即停止；全局保护复验 |
| **完成证据** | ① 检查报告：每项 pass/fail/unknown＋严重度＋数值容差＋证据引用；② 已知坏例自动修好（修正后重检通过）；③ 重复失败签名停止（不无限循环）；④ 科学保护复验：定量色阶/几何位置/比例尺/分类/事实数字未被美化覆盖；⑤ 修正 ≤2 轮，预算共享 |
| **输入** | 渲染预览、DesignSpec、CheckReport（初检）、修正白名单 |
| **输出** | `CheckReport`（终检）＋ `DesignPatch[]`（若有修正，baseRevision 匹配）＋ 修正后渲染＋ 停止原因（若停止） |
| **判据** | 严重科学错误 0；修正轮次 ≤2；白名单外不修正；停止时原因明确；保护项复验全过（待 D-089 冻结检查项清单与阈值） |
| **依赖模块** | **M14** 自动设计与修正（issue 映射/repair/Patch 生成）→ **M16** 检查与交付（地理/数值/结构/渲染/文件重开）；上游 Z03；下游 → Z05 |

## Z05 · 成果输出

| 维度 | 内容 |
|---|---|
| **所有者职责**（M13 UXP 执行 ＋ M16 检查与交付 ＋ M17 工作台） | 按 TaskBrief 的必需交付项导出最终成果（地图/图册/报告/PPTX/长图），逐件真实校验（文件存在/可重开/内容对应/数字同源），成果可直接取用 |
| **完成证据** | ① 必需交付项逐件存在且非空；② 文件重开校验通过（PSD/PNG/PDF/PPTX 各自真实打开）；③ 地图/报告/PPTX 数字一致（同源 FactTable 校验）；④ DeliveryManifest 含逐件 hash/大小/来源/依赖/方法/设计 revision；⑤ 缺项/限制明确标注 |
| **输入** | 终检通过的渲染、DesignSpec（终 revision）、TaskBrief 交付项列表、FactTable |
| **输出** | 最终成果文件（按 Brief 指定格式）＋ `DeliveryManifest`（必需/可选文件/逐件校验/完整性/追溯）＋ 成果列表（工作台展示） |
| **判据** | 必需交付项 100% 存在且校验通过；文件可重开；数字同源一致；manifest 无待填；[VERIFY] PPTX/报告生成依赖 X8 内部服务（M2 完成，M1 标注 NOT VERIFIED 或降级为 GIS 原生导出） |
| **依赖模块** | **M13** UXP 执行（最终导出）→ **M16** 检查与交付（逐件校验/manifest）→ **M17** 工作台（成果列表）；上游 Z04；下游 → Z06/Z07 |

## Z06 · 改稿与撤销

| 维度 | 内容 |
|---|---|
| **所有者职责**（M04 任务编译 ＋ M14 自动设计与修正） | 接收用户改稿意图（20 类），区分语义改稿（换数据/方法/分类）与视觉改稿（标题/配色/布局）；视觉改稿生成 DesignPatch 并重渲染；语义改稿触发 AnalysisPlan 重算；过期 Patch 拒绝；撤销回退到指定 revision |
| **完成证据** | ① 20 类改稿意图全覆盖（每类有处理路径）；② 语义/视觉区分正确（单位换算触发重算，标题修改不触发）；③ DesignPatch baseRevision 匹配当前 revision，过期 Patch 拒绝并提示；④ 撤销可回退到任意历史 revision（M15 版本链）；⑤ 改稿后重新走 Z04 检查 |
| **输入** | 用户改稿指令（自然语言或快捷操作）、当前 DesignSpec revision、改稿意图分类器 |
| **输出** | `DesignPatch`（视觉改稿）或 新 AnalysisPlan（语义改稿）＋ 改稿后渲染＋ 撤销历史 |
| **判据** | 20 类意图覆盖；语义改稿触发重算率 100%（不误判为纯样式）；Patch baseRevision 校验；撤销后内容与目标 revision 一致 |
| **依赖模块** | **M04** 任务编译（意图解析/语义判断）→ **M14** 自动设计（Patch 生成/重渲染）→ **M15** 版本与更新（revision 链/撤销）；上游 Z05；下游 → Z04（重检）/Z07 |

## Z07 · 数据更新

| 维度 | 内容 |
|---|---|
| **所有者职责**（M06 作业与恢复 ＋ M15 版本与更新） | 新一期数据进入后，沿依赖图重算受影响分析与全部相关事实；已接受的视觉意图（DesignPatch）继承；外部修改的 PSD/母版保留原件，生成新版；默认完整重渲染，局部更新仅作等价检查通过后的优化 |
| **完成证据** | ① 依赖 DAG 重算：受影响 FactTable 全部更新，未受影响的保留原 revision；② 事实同步：地图/图例/说明/报告/PPTX 数字同步更新；③ 外部母版原件保护：外部改过的 PSD 不覆盖，生成新版；④ 强缓存键含输入内容/结构/工具版本/参数/CRS/环境/样式（非仅路径/mtime）；⑤ 旧 revision 拒绝覆盖 |
| **输入** | 新数据引用、当前 DesignSpec＋Patch 链、依赖 DAG、FactTable（旧 revision） |
| **输出** | 更新后的 FactTable＋新 DesignSpec（继承 Patch）＋新版渲染＋ 更新日志（受影响项/未受影响项） |
| **判据** | 受影响事实 100% 重算；数字同步无遗漏；外部原件零覆盖；缓存键不含仅路径/mtime；更新后通过 Z04 重检 |
| **依赖模块** | **M06** 作业与恢复（持久化/对账/取消）→ **M15** 版本与更新（强指纹/依赖 DAG/不可变 revision/Patch 继承）；上游 Z05/Z06；下游 → Z04 |

## Z08 · 新手流程

| 维度 | 内容 |
|---|---|
| **所有者职责**（M17 用户工作台 ＋ M19 评测与观测） | 普通用户（无 PS 技能、无图层知识）通过 Pro 工作台完成：选资料→确认任务卡→看成稿→说修改→取成果；首次设置与日常操作分开测量；配置/设计介入次数分开计数 |
| **完成证据** | ① 任务卡：识别结果/歧义/方法/输出目录/预计成本时间/交付物，一次批准范围内自动执行；② 0 次 PS 手工设计（正常路径）；③ 首次设置步骤可计数且 ≤N 步（N 待 D-089 冻结）；④ 改稿通过自然语言或快捷操作，不需进入 PS；⑤ 配置介入（如连接引导/目录选择）与设计介入（如风格选择）分开计数；⑥ [VERIFY] 新手试用证据（G-FUNCTIONAL 前 8–12 名，G-FUNCTIONAL 后 ≥24 名） |
| **输入** | 用户资料、用途选择、TaskBrief、预览与成果 |
| **输出** | 工作台交互日志（步骤/耗时/介入点/成功率）＋ 新手试用报告（待 M19 评测） |
| **判据** | 正常路径 PS 手工设计 0 次；任务卡必填信息完整；改稿可在工作台完成（不跳转 PS）；首次设置与日常操作指标分开（待 D-089 冻结阈值） |
| **依赖模块** | **M17** 用户工作台（任务卡/歧义/预览/快捷修改/成果/恢复）→ **M19** 评测与观测（trace/指标/新手试用）；上游 Z01–Z07 全部；下游 → M19 评测反馈 |
