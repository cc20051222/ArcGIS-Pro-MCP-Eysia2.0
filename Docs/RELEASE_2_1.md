# ArcGIS Pro MCP 2.1 更新说明

2.1 将已完成本机验收的工作流 Skill 0.7.7、山海任务面板和真实 GP 进度支持整合为新的发布版本。发布标记为 `v2.1`，产品文件版本为 `2.1.0`，Skill 保持自身版本 `0.7.7`。工具数量仍是239，GP白名单53；本版重点是流程可见、检查可信和安装交付完善。

## 本版变化

- 面板重新设计为山海工作台：随本机时间自动切换景观和动态装饰，信息区保持清晰，移除手动背景和特效开关；支持紧凑布局、键盘操作、搜索、筛选及跟随当前步骤。
- 完整展示业务处理链、依赖分支和检查重点。真实执行中的步骤高亮；查看其它行不改变正在执行步骤。没有观测到执行时明确显示空闲，不编造执行百分比。
- Skill先确认目标、数据位置、成果目录和数据缺口，结合实际可用工具、许可和具体标准条款制定计划。缺能力先评估等效替代，确需新增开发时征得用户同意。
- 对话阶段卡与面板使用同一成功发布的任务记录。支持预检、过程检查、问题修复、新证据复检、最终检查及有权验收方裁定；观察窗口不代替Agent发送聊天。
- GP真实SDK回调通过请求ID与步骤绑定。内部阶段计数与整体任务状态分开，跨任务切换不会错误沿用旧进度；异常记录、暂时锁定和恢复均有明确提示。
- 检查状态更严格：未执行、阻断、覆盖不足、陈旧依据和必需项缺失均列为待处理；质量要求改动必须升版，旧检查失效；空范围默认不能充当全量检查通过。
- 安装包含插件、项目Skill、独立面板、完整教程和逐文件SHA256清单。支持D盘运行根、只读预检、备份事务与按已知文件回滚。不会上传用户工程、考试数据或账号密钥。

## 安装与升级

下载 `ArcGIS-Pro-MCP-2.1-Windows-x64.zip` 及同名 `.sha256`，核对SHA256后完整解压到D盘新目录。保存并正常关闭Pro，双击 `安装2.1.cmd`，先查看计划，再按提示确认安装。已有2.0用户同样使用此入口，安装前备份旧文件，不需要先降级或重装r29。

项目Skill安装到用户选定工作区 `.agents/skills/arcgis-pro-2-workflows`。在客户端打开同一工作区并重新加载Skill；插件从Pro的MCP页签启动服务，客户端接入 `http://127.0.0.1:6520/mcp`。面板和Pro须用配套启动脚本以继承同一D盘任务与事件路径。[完整安装教程](SKILL_INSTALL_GUIDE.md) · [使用教程](SKILL_WORKFLOW_GUIDE.md)。

## 验证及适用范围

本机实际环境为Windows x64、ArcGIS Pro 3.5.0.57366、.NET8。0.7.7功能验收已完成48项面板交互、8项自动景观、13项待处理检查控件测试、120项Skill辅助测试、8项离线包检查、18项进度协议检查和68项Server测试。6条道路20米缓冲通过首检、新证据复检及独立DBF/SHP核对；另用10000条固定测试夹具取得真实GP运行中截图，输出10000条非空面。固定压力夹具不计为新增业务能力。

2.1重新构建产品版本并对新载体另做版本、包完整性、安装恢复和运行核验，结果汇总于[2.1发布验证摘要](RELEASE_2_1_VALIDATION.json)。旧0.7.7原始记录保留本地；公开摘要使用匿名统计，不含用户工程、原始试题、私有路径和账户凭据。

本版安装器仅启用Pro3.5/net8。net6构建不等于旧版本Pro实机通过，旧r29仍在历史Release中。全部239工具逐项业务验收、完整DEM水文链、全部PS/UXP、其他客户端、Windows10和干净机安装未由本次证明。90个设计模型行为用例未作为90次真实模型评测执行。本机验收由用户明确指定同一会话完成，不冒称第三方独立验收。
