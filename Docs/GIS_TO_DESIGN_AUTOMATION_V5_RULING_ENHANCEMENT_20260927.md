## 2. 强化措施一：效果最好（视觉上限工程）

1. **标杆样张前置（golden sample）**：每个布局家族在 F04-B 阶段先由专业评阅者产出 1 张标杆成品，后续模板与自动检查以标杆为锚——专业评阅从 Q 期**提前到 F 期**，评阅者同时参与设计 token 定标。
2. **PS 效果分级目录（effects tiers）**：F03 契约冻结时建立两级效果清单——
   - **表现层效果（presentation）**：渐变底、柔光斑、投影、描边、质感纹理、装饰等高线/点阵等，允许自动作用于非科学图层；
   - **科学保护层（protected）**：定量着色、统计符号、栅格像元、比例/北向绑定——禁止任何全局 PS 调整层触碰（V5 A06 原则落实为可枚举目录）。
3. **中文排印一次做透**：F04-B 的字体测量覆盖中文字重层级、混排行高、标点挤压规则；中文排印质量是"效果最好"的最大变量，不许到 M1 才补。
4. **印刷级管线**：PSB 大画布、300 DPI、ICC 色彩配置与校样范围在 F04-B 就用真实样张验证（A09 验证清单前置）。
5. **视觉度量**：视觉表现层检查用真实图像规则评分＋可选视觉模型辅助（非唯一判官原则不变），让"效果"可测量、可回归。

## 3. 强化措施二：实现范围最广（输入/场景/输出三面铺开）

1. **输入面**：F03 的 DatasetContract 覆盖面一次列全——gdb / shapefile / csv / excel / geojson / 栅格 / 在线图层；现有 `scan_data_folder → load_folder_data` 工作流作为文件夹级数据入口承接，不另起炉灶。
2. **场景面**：30 场景在两大类（规划汇报/科研制图）下按域包组织：设施分析、土地、生态、市政、应急、商业选址等；F05 冻结清单时每场景标注依赖（许可/数据/模板），不许"看起来适合"的伪覆盖。
3. **输出面**：PNG / TIFF / PDF / PSD / PSB ＋ GIS 矢量 PDF/SVG 分链交付照旧；**PPTX 拼版与长图拼接列为 M2 候选新增**（汇报场景高频，是否纳入属裁定项，默认纳入规划）。
4. **版面覆盖**：横/竖、A3/A4、多尺寸重排与长图按 V5 M2 计划执行，不缩水。
