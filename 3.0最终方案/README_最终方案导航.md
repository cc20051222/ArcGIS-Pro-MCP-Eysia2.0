## 完整范围和状态

完整范围保留20公共模块、12产品包、10业务深度包、8领域、285核心语义候选底册、20项PS业务、36模板、108标准图、60场景、21来源族/105候选动作格，以及原隐藏、新手、压力、兼容和恢复等全部门。另有30WI、12创新、8可行性原型及其新增合同成本。数量候选、合同可编译、真实可运行和独立接受分账，不互相替代。

GP目标是同口径竞品真实数量上浮10%后的向上取整与2100中的较大值；核心语义目标是同口径真实数量上浮50%后的向上取整与3000中的较大值。竞品精确分母和合法足量来源尚需冻结，不能把“1900+”填为精确1900或说本项目已经具备3000项。

完整60日是有条件的开发目标，启动日与真实完整容量尚未知。D7、D14校准，D28要求两个完整资格周和全部剩余工作资源排程都成立；D49全功能验收，D50至56功能通过后制作并验收真实一键安装包，D57至60为应急。未满足条件时调整资源和预计日期，保留全部范围及质量门。

五线是C0负责指挥、派单和独立验收，E1至E5分别承担平台集成、GP兼容、数据方法、设计办公、业务工作台。现行单ACTIVE批次不变，五线为同一批次中的工作包并行；本资料模板不是实际派单。当前会话四个并发槽不等于正式六席已配置。

插件形式和统一一键安装入口保留。最终安装器及真实包制作放在全部功能门之后，不能以先做安装包替代业务完成；Adobe宿主确认、软件许可和模型凭据按真实支持条件处理。
