# ArcGIS Pro MCP 3.0 项目最终总方案

日期：2026年10月2日；本轮修订：2026年10月3日。定位：完整范围产品设计与开发合同。本稿将已有十五份创新规划收敛成可直接阅读的最终总方案；详细合同和原始范围由同一资料包的技术附件保留。本次形成文档，不代表新功能已经开发、安装、真机运行或独立验收。两个月是完整范围的条件开发目标，所有原功能、质量门和困难样本保持。

## 1 产品定位与最终成果

建设一个运行在 ArcGIS Pro 工作环境中的全链路 GIS 成果平台。用户用自然语言、业务表单或已验技能提出任务，提供当前资料和可选参考成图，系统自动完成资料理解、数据充分性检查、方法选择、GIS 分析、专业制图、真实 Photoshop 自动美化、Office 编制、质量核验、整套交付及后续更新。普通用户不需要掌握 GP 工具名字，不需要在 Photoshop 中手工摆放图层或修图。

产品的核心价值是把“调用工具完成一步”发展为“完成一个可复核、可编辑、可更新的业务成果”。例如，用户提出“比较两个养老设施方案并按这套参考风格生成汇报”，最终得到的不只是服务区图，还包括口径明确的覆盖人口、未覆盖与未知对象、方案差异、同源图表、可编辑报告与演示、拥有的 PSD 母版和 GIS 数据、来源方法说明、可重新计算的交接资料。更新人口或设施数据后，所有受影响图表和文字共同形成新版本。

最终交付仍以插件形态为主：ArcGIS Pro 插件提供工作台与 GIS 宿主接入；Photoshop UXP 插件提供受限设计动作；受控本地组件承担任务、资料、资格、Office 和版本服务。统一一键安装包在完整功能验收后制作，包内明确组件身份、支持条件、升级与恢复路径。安装器不附带未经许可的 ArcGIS Pro、Photoshop、商业字体、模型权重或行业数据，也不以“能安装”代替“整链能完成”。

## 4 十二个产品包与入口组织

U01工作台统一任务、步骤、预览和成果身份；U02模型提供固定适配、实际能力评测、流式提案与费用；U03上下文保存持久会话、输入快照与项目偏好来源；U04指代支持@标签、点选、框选和稳定空间对象，不凭同名图层猜测；U05可视流程展示类型化计划、预检、合法修订与控制；U06数据接入处理多sheet、扫描表格、坐标和关键抽取歧义。

U07知识将本地检索、方法卡、引用、适用谓词和规则连到任务；U08成果编制同源ReportSpec、WorkbookSpec、PresentationSpec并形成完整交付版本；U09记录保存系统实际操作及未记录缺口；U10技能保存声明式业务流程、依赖锁、跨数据适配和回放；U11规范把真实资料定位、候选条款、专业采用、有效规则和QC覆盖串起来；U12行业组合方法、资料、规范、样式、样例、负例和更新。

公共模块是技术能力，U包是用户组织方式，BP是专业业务深度，X是领域扩展。四个视图引用同一操作与合同，不能把一个缓冲操作在四个视图中计成四个能力，也不能把行业入口文案当作该行业全部专业方法已经实现。

## 5 全链路技术思想

固定主链为：任务目的 → 当前输入快照 → 数据充分性 → 方法资格 → 类型化计划 → 范围与预算采用 → 唯一Invoker/Jobs执行 → 已验事实 → DesignSpec → 真实GIS/PS/Office产出 → 独立检查 → 完整DeliveryRevision。

设计坚持五个核心分离。第一，模型提案与执行权分离：模型负责意图、候选、解释与排序，确定性层检查类型、方法、许可、预算、批准和状态。第二，事实与设计分离：面积、人口、分类、单位和分母来自同一FactTable，标题位置与配色只是合法StylePatch。第三，资料候选与当前真值分离：参考图OCR、他人数据结构和网上资料可以帮助发现，但不能替换本项目事实。第四，纯产物复用与当前副作用分离：已验缓存可减少准备，新的复制、导入、保存、数据库修改仍需当次记录与观测。第五，文档声明、源码实现、真机、整链和独立验收分离。

架构沿用既有分层：AI Client → MCP Transport → MCP Protocol → MCP Server → Tool Router → Tool Registry → GIS Tool → IArcGISHost → ArcGIS Services → ArcGIS Pro SDK。Composition.BuildRegistry保持唯一注册；Shared不引用ArcGIS SDK；SDK对象访问经QueuedTask.Run；端口、超时、路径、预算和开关归集中配置。MCP保留本机受控端点127.0.0.1:6520/mcp，既有6511桥仅支持已审查固定类型化操作；不能把自动适配做成任意Python、JS、Shell、SQL或公开网络执行通道。

## 7 自主更新如何长期增加核心能力

能力更新采用可信来源与声明式参数合同驱动。系统枚举当前合法Esri目录；在有实际来源、许可、固定adapter和科学证据时，可加入其他计算提供者。目录大小不等于可用数量，AI包装不能使同一Esri全集凭空变大。未知工具箱加载可能执行代码，不能因为“只读元数据”就扫描任意用户脚本或动态工具箱。

能力状态依次为发现、生成、隔离资格、独立接受、分阶段采用、canary通过、活动、退役或撤销。新增可选参数必须检查默认、依赖、条件副作用和旧域兼容；新类型需要开发codec；相同签名但后端二进制变化仍可能使科学资格失效。运行中的旧任务锁定原方法与版本，恢复时再核当前许可、准入和输入，不能静默漂移到新操作。

六本账分别记录Inventory发现、Contract参数、Qualification真实资格、Semantic去重语义、Recipe完整流程、Resource模板规则格式技能。核心数量保留两个独立门：GP实际资格目标K_GP=max(2100,ceil(1.10×N_GP))；核心独立语义目标K_sem=max(3000,ceil(1.5×N_sem))。N_GP与N_sem要在相同对照条件下冻结实测，当前未知保持null；竞品“1900+”宣传不能被填成精确1900或1900种不同科学算法。

Semantic仅计核心GIS计算、转换与治理。同方法多后端、旧新名字、别名、参数取值、行业皮肤、模板、PS/Office/UI和学习管理不加入核心语义数。每个计入项必须有规范身份、输入输出域、方法/effects/许可、真实正例、必要负例、内容oracle和独立接受。自动化可以批量准备与收证，不能用一个族代表例替掉剩余工具的首次真实资格。

来源验真、版本水位、成员完整、科学资格和允许采用分别记录。SourceVerificationWitness核精确声明、已审信任依据、实际provider/Host与合法用途；SourceUpdateWatermark只由已验的来源版本证据推进，不能让未验高版本锁死后续更新；BundleClosureWitness锁catalog、codec、policy、资格和资源的全部真实成员，不逐项读取latest。当前采用仍用原ActivationCommitted唯一权威头；合法回退形成新commit，引用仍有效已验旧包，不降低来源水位或复活撤销。损坏共同控制历史按可证明影响域停止相关新写，更新缺证不一律封停完整合法旧链。

## 8 参考学习与用户习惯的完整体系

参考资产先区分角色：样式参考、资料结构参考、当前分析数据、方法线索、指定素材、规范依据。文件身份和允许用途分别管理，同字节不等于同权利。读取、OCR、索引、长期学习、外发模型、复制素材、科学计算分别核允许范围。批量参考按角色选用A的版式、B的色彩关系、C的文字层级时保留来源和合并决定，冲突不能由上传先后自动解决。

StyleDNA迁移的是区域、视觉角色和相对关系。参考上的人口、面积、坐标、比例尺、分类阈值、地图形状和科学结论不迁移成当前事实；像素图不能保证恢复原GIS工程和所有可编辑图层。DatasetDNA学习字段结构和语义，当前数据仍完整采集、核单位/日期/CRS/实体/选择与分母。关键未知集中确认，不能为了少提问猜填。

## 9 资料发现与稳健决策的创新细节

资料发现根据当前任务Need确定变量、范围、时间、实际空间支持、分辨率、单位、许可和质量门；再检索STAC/OGC/ArcGIS或已授权资料。目录bbox与日期匹配只说明候选，整景云量不能证明AOI有效，Item与asset实际投影/格网可能不同，无几何或时间不能盲判不匹配。分页完整性、来源限制、动态域、资产可读性和权限逐项记录；只查一页或请求失败不能宣布“没有可用数据”。

补缺提案绑定当前Need、计划基础版本、ReadSet、费用、来源、方法和支持条件，采用后沿原Invoker下载/转换/绑定/读回，逐项重评原缺口。能下载和能打开不代表满足所需时相、人口口径、完整覆盖或科学质量；补充资料带来的新缺口与改变的分母必须保留，不能换一个更弱Need宣告原问题关闭。

方案比较分为固定方法下的业务ScenarioStudy与独立MethodDiagnosticStudy。方法诊断可列不同方法的假设、适用条件、输出与失败，但可比较不等于可相互替代，数值相近也不证明科学等价。统一评价域必须包括冻结完整对象、时相、单位、指标方向与已验转换；不能只取两个方案都成功的交集来删掉难对象。

敏感性分析锁固定模型、指标方向、归一化锚点、允许权重范围、必需数据和方法。每个场景不得重新拟合归一化、截断越界值或补未知为零；某指标权重变零不取消其原必需资料要求。有限网格结果只能说明已评估点，不能声称连续范围稳定或现实获胜概率。只有经过独立资格的解析域才能给连续结论。例如固定两指标仿射模型S=w×x1+(1−w)×x2，A=(80,20)、B=(60,60)的差值为60w−40，阈值为2/3；这只证明固定线性模型中该区间的排序，不证明现实因果。

## 10 自动设计与高可用成果

自动设计先冻结用途、物理尺寸、字号、DPI、色彩、必要图例、说明、输出和编辑性；再选择模板或合法参考。真实字体度量、当前图例数量和保护区域决定布局，不用字符串长度猜宽度。布局允许增加列、调整非科学间距、预验字体替代、许可字号区间等有限修复，不能删除类别、缩到不可读或遮挡科学信息。

原根任务限制保留：候选不超过12，首轮预览不超过3，总预览不超过5，获准修复不超过2，最终渲染不超过2；多页、重启、换模板不重置。没有可行设计时明确未满足条件，不能无限生成直至偶然出现好图。Photoshop按宿主全局单写队列执行精确文档/图层身份的固定命令，保存关闭重开检查；不同PSD也不能默认同时modal写入。

每个数值展示词元绑定FactCell、quantityKind、合法单位转换、显示精度和术语版本。比例0.12、百分数12、百分比12%与变化12个百分点分别处理；绝对温度和温差使用不同转换；小数点、负号、中文英文字形与近零舍入必须核实际载体。非零值被显示成裸“0”而误导用户时，要采用明确精度或阈值说明，不改底层值。

可访问性覆盖必要语义节点完整、唯一ID、阅读顺序、语言、字形、文本、非颜色编码、编辑性和实际辅助阅读。GIS绘制顺序与PDF标签顺序可能冲突，不能为标签强改科学叠置。每Host版本、每成员单独探测；只有原输出合同允许多成员时才可拆科学PDF与阅读版。要求同一个文件满足两种能力时不能悄悄拆分后宣告完成。

## 15 长期自动运行的有效性与留存保障

自动更新、学习和离线复用增加两项底座合同，承接原模块与工作项。TimeValidityWitness 将相对TTL、绝对到期、撤销、内容一致性和宿主租约分别判定：可靠计时上下文内计算耗时；跨重启不比较旧ticks，绝对到期使用有界可信当前时间证据。回拨不能使已知过期资格复活，休眠不能刷新TTL，租约过期不证明宿主已停止。资格不明只限制依赖它的新执行或复用，合法历史查看及不需要该时间证明的已验离线路径保留。用户看到具体依赖与恢复动作，不需自行管理时钟或学习缓存。
