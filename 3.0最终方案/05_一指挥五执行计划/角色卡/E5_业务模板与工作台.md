# E5 业务模板与工作台

唯一主责：WI24、WI25、WI26、WI28。创新主责J12演进工作台；公开回归、行业模板/规则和用户验证资料与其对应WI一起登记，不独立虚增工具数。

## 1. 三条链与用户流程

WI24规划覆盖/方案链：方法前提、网络条件、去重人口和方案可比；WI25科研专题：同格网/掩膜/转移、时间/尺度与科学解释；WI26资料定位→规则采用→拥有副本建库→QC/覆盖：来源适用、授权、复制与质量闭环；WI28工作台显示真实任务/出处/影响/更新，可访问及离线流程。

消费E2合法语义、E3数据/事实/方法/技能和E4完整DeliveryRevision。8行业、12产品包、21输入族及格式动作、全部60任务/压力/原创新试验保留。模块缺项不能由UI按钮占位表示已支持。

## 2. 公开评测与用户资料

准备拥有fixture、公开黄金/不同来源checker、行业方法依据、108图任务描述、对照用户脚本、用户招募与同条件计时。公开oracle由C0/独立专业侧审核。最终隐藏答案由C0/独立专业侧封存，E5不持有或自己签产品最终PASS。

24名新手至少48任务，用户不做PS手工设计。独立完成、需协助、失败和UNKNOWN都记录；不能只统计成功用户或用人工改稿补出成功。公开对比固定10任务×3输入×3轮，每产品90尝试及额外4任务，版本/模型/硬件/许可/准备/费用/人工相同口径。

## 3. 工作台真实状态

一张任务卡解释需要什么、资料缺口、方法依据、步骤、当前结果、学习/采用/复用/等待/失败和下一动作。状态消费原JobStore及typed合同，不另建后端或靠模型总结生成绿卡。可用、候选、已资格、当前不可用分开；不把自动下载、schema生成和学习候选当业务完成。

离线/降级说明真实可用域，已有成果可查看不代表可重算。参考上传、偏好纠正/遗忘、任务改稿和学习说明使用普通语言，技术设置只在影响用户决策时显示。

## 4. 交付与节奏

交PASS CANDIDATE，含三链实际原始结果、各域/格式矩阵、公开oracle来源、工作台状态与底层一致、可访问/离线、用户原始计时和全部分母、竞争同条件记录及未知。

D1–14准备行业/模板/公开检查和首链接力；D15–42逐域、格式、全链和用户开发试用；D43–49最终新手、隐藏实际任务执行及压力/竞争证据。WI24–26依赖WI14/WI16/WI22，WI28依赖WI09/WI22/WI23；准备可前置，真实完成不可绕过。功能门后的实际包阶段协助无安装经验用户验证首装和首图，真实安装需相应授权。

## 本轮细化的用户状态责任

任务卡区分“正在下载、续传校验、资料待核、可用于本任务”和实际已验事实；200/206等协议细节放诊断页，普通用户只看原因与继续方式。D14演示只显示已接受切片范围；完整业务支持来自全量WI和对应业务门，不因一条演示成功把全部行业入口变绿。

## 本轮生命周期深化职责

在原WI28投影逐依赖时间资格、离线可用范围、保留理由、预计/实际空间和清理待对账，不把未知填0或把干运行显示为清理完成。真实普通用户流程不暴露pin/fence实现术语；提供合法恢复操作而不要求用户懂PS或文件锁。

WI28分开呈现来源已核、候选、已采用、暂停/合法回退及未采用原因；检查失败不显示最新，资料自称PASS不成为成功状态。当前合法范围自动完成，不追加逐项确认；用户看到必要问题与已验默认替代，不需PS人工补救。
