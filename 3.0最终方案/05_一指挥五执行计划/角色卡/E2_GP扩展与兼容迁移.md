# E2 GP扩展与兼容迁移

唯一主责：WI11、WI12、WI13、WI14、WI15、WI30。创新主责J01可信更新、J02逐项资格工厂、J03语义能力图谱。所有候选在拥有D盘域，产品改动交E1集成。

## 1. 实现责任

WI11采可信真实目录、canonical ID、版本/许可及完整diff；WI12实现标量/单位/多值/值表/复合/FieldMap族codec；WI13逐操作动态effects、env、许可与准入；WI14把旧、compact/granular入口映射到同一PreparedInvocation与唯一Invoker；WI15逐操作fixture/oracle/evidence及升级影响；WI30支持/兼容矩阵、资源锁、历史迁移和交接。

目录GENERATED、schema通过和可发现不代表QUALIFIED。对新增/删除/改名/参数/许可变化，生成候选→真实正例/关键负例→独立oracle→影子/canary→批准激活；不在线任意改DLL或扩大Bridge任意脚本。未知参数类型隔离而非猜参数。

## 2. 数量与资格

同时实现K_GP=max(2100,ceil1.10N_GP)和K_sem=max(3000,ceil1.50N_sem)。N尚未知；同provider别名、参数组合和PS/UI不充核心语义数。真实交集需同一个已选资格工作单元，动态域/Host/许可/正负例全部一致；每语义组选实际代表。

当前集合包括接受、撤销、失效与恢复，不重复累计。目录来源/许可及独立语义是否足量D7先证；D14 30–50困难试点≥3工具箱、6参数族；D15–42连续4周资格，D28两整周净率与余期一起算。失败、未知、长运行和困难项保留分母。

## 3. 接口与验收

消费E1底座/预算，消费E3 typed DAG和方法依据；向E3/E5交当前可用语义、effects、输入输出域、错误与支持状态。E3方法/语义协作不改变J03的E2主责。E5公开checker和C0独立oracle可协作，不能由E2自签PASS。

交付逐项ProofCapsule、支持域、目录快照和diff、条件参数、effects、实际原始产物/副产物、失败轨迹、checker及oracle身份、当前有效集合。通用受控Host必须经已授权执行，工厂不能以抽检代替逐操作首次实证。

## 4. 晚到迁移不免费

WI30依赖WI15、WI22和WI27；D43–49仍有真实兼容/历史任务/学习资源迁移与撤销回退实现。接口可以前置准备，残余时长、Host、专业和E1/C0成本必须登记，不能放到功能门后或应急而称原功能已完。发行阶段只提供已验组件和真实兼容证据。

## 本轮细化的资格计量责任

为每个当前未接受资格单元赋唯一primaryStratumId，复杂参数、长运行、effects、许可与oracle风险可多标签但不重复加件数。冻结完整剩余集合并与主分组并集一致；D14测各资源净项成本，未测困难组保持UNKNOWN。D28据剩余组分钟重排，不用早期简单组均值填长尾，也不以切片接受关闭完整WI。

## 本轮生命周期深化职责

在原WI13/15/30验证当前GP、Host/许可及证据时效；源代码或表内expires字段不证明可信当前时间。公开负例覆盖休眠、重启、撤销未到期和旧fence，离线无相关时间依赖的正例保留。历史迁移与回滚保持原保护。

WI11/12/13/15/30承接SourceVerificationWitness、水位、BundleClosureWitness和采用恢复；真实可信本机固定Host来源与远端信封按各自已审机制验，不自行信任候选key、不凭digest认证。新codec/代码仍正式变更；合法产品回退不倒来源水位或撤销。
