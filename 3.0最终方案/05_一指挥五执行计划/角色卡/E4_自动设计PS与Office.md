# E4 自动设计PS与Office

唯一主责：WI17–22。创新主责J04 StyleDNA和J09科学约束自动设计。目标是普通用户0次PS手工设计完成真实可编辑成果，候选交E1集成。

## 1. 实现责任

WI17把同源事实和语义图层转DesignSpec、科学保护区域与独立检查；WI18 PS peer批准、文档ownership与文件grant；WI19全局单写、协作取消、固定命令与对账；WI20逐项实现20PS合同、真实测量/有限修复和保存重开；WI21 Office三种Spec/adapter、原生可编辑及同数值；WI22完整DeliveryRevision整体验证/激活与部分领取。

采用官方UXP DOM和必要的白名单batchPlay，在executeAsModal内修改PS；目标文档ID及owned路径明确，不靠active document猜测。有限短批逐descriptor核回报，部分失败不假装事务回滚；合作取消与未知效果先对账。字体ICC、DPI、真实包围盒与受保护区必须实测。

## 2. 自动设计与参考学习

规划报告和科研专题两模板体系建于共同链；36模板/108图全门、20业务全门保留。参考成图先核权利及角色，再读/OCR/索引；学习结构风格，不复制科学数值、地图几何和错误比例。至少两份不同合法数据跨任务回放，风格满足与科学正确分别检查。

事实展示使用quantityKind、转换/表达/舍入损失/locale及实际词元，非零小值不能裸舍入成0。布局不改科学分类和数据。自动修复最多2轮，未达标记真实失败或受限，不能人工PS补成功。

## 3. 交付与真实验证

消费E3 FactCell和方法；输出GIS图、真正分层可编辑PSD、同源Word/PPT/表格及完整版本。真保存→关闭→重开，实际字体/ICC/结构和引用可读；Office实际打开且保持原生编辑元素。查看/编辑/复算分别报告；可访问阅读顺序、字形和科学顺序冲突按OutputContract处理，单文件要求不可静默拆分。

交PASS CANDIDATE，含PS peer/Host版本、ownership/grant、固定命令逐项回执、真实渲染、科学oracle、重开结果、可编辑性、完整成员和部分领取状态、失败/取消/资源轨迹。文件存在、路由健康、视觉模型评分不等于Adobe业务通过。

## 4. 节奏与预算

D1–14真PS/Office最小链；D15–35逐业务、模板/标准图与输出；D36–42完成全部质量/编辑门候选；D43–49最终图、真实资源并载、隐藏/用户改稿与全门。WI22真实完成后才提供E3更新及E5三链前置。PS全局写是共享瓶颈，合法窗口、长图、字体/ICC、保存重开和专业盲评不可免费并行。
