# 派单模板

状态：TEMPLATE_ONLY。此文件没有填入实际批次、编号、授权或接受结论，不构成当前工单。只有现行指挥授权、唯一ACTIVE批次和权威inbox中的有效工单才能授权执行。

## 1. 身份与控制

| 字段 | 待填内容 |
|---|---|
| 当前唯一ACTIVE项目批次 | 待C0按权威状态填写 |
| 派单方及验收方 | 必须为同一指挥侧；防撞编号依现行宪章 |
| 工作包ID、唯一owner、WI/J/PF | 不新建并列ACTIVE；协作不转移主责 |
| 起始时间与有效期 | 保持真实T0日历，不因底座门重置 |
| 权威来源与用户中继 | 当前inbox/宪章/适用工单；用户仍唯一实际会话中继 |
| 状态 | WAITING / AUTHORIZED；模板不能自写AUTHORIZED |

## 2. 冻结问题与成果

| 字段 | 待填内容 |
|---|---|
| 具体问题及用户结果 | 触发、输入、预期行为和为什么需要 |
| 范围及明确支持域 | 参数、方法、Host、许可、格式、行业与用途 |
| 当前基线/payload | 实际绝对路径、SHA256、长度、版本；来源与读取时间 |
| 公共合同版本与diff | schema、typed意义、动态依赖/effects、兼容和消费者 |
| 前置及消费者 | 完整WI原dependencies状态；当前子切片的producerMilestoneRefs及真实消费case |
| 范围级别与未完成域 | CONTRACT / VERTICAL_SLICE / FULL_WI；明确acceptedScope、remainingFullScope及当前完整前置是否成立 |
| 输出路径和拥有资产 | 执行前声明，绝对D盘；fixture母本/副本区分 |
| 候选写域 | E2–E5拥有候选域；产品树只有E1 |
| 不可触碰资产 | 受保护工程、旧仓库、未知锁、封存件、回滚链 |

## 3. 授权与资源

分别记录产品写入、真实Host/GIS写、PS资源、安装、配置、软件/依赖、签名发布的现有具体授权；不在模板中一揽子推定获得。无授权的动作只做准备/只读或报阻断。

资源预约需包含人员、CPU/RAM/VRAM、磁盘、Pro/MCT、PS全局modal、GDB、许可、专业oracle、E1、C0及占用段；全部联合准入。Host尚未结束时保留执行占用；Host结束有证据后可归还计算lane。目标、文件空间和预算按各自结算策略处理，未知效果相关占用继续隔离，不把lane归还当效果已清。D盘写探针、TEMP/TMP D盘、禁止dotnet clean等环境约束照现行规则。

## 4. 逐项验收要求

待填每项真实合法正例、按参数/effects确定的全部关键负例、独立科学oracle、原始内容与状态、故障/恢复/保存重开、支持域、性能测量及证据索引。明确原全部门和新增门中本工作包覆盖哪些，哪些还未覆盖；模块接受不升格为全功能。

成果只交PASS CANDIDATE。文件存在、生成/注册、构建、mock或正确拒绝各标自己的证据级别，不称实际能力通过。失败、UNKNOWN、需人工、等待与返工保留完整分母。资源成本/剩余估时未知填null。

## 5. 退出与变更

前置不成立、基线变动、未知效果、科学前提不满足或需要越权时，停止扩大执行、保留现场并回执；不绕门。公共变更先请求合同处理，E1唯一集成。取消/超时先对账，新的ResumeDecision及完整准入后才能续发。C0独立裁定，分歧用户终裁；交叉抽检不覆盖原派单方结论。

## 生命周期专项字段（适用时必填）

如涉及时间/缓存，固定依赖时间适用域、TTL/绝对期限及可信证据；固定拥有Droot、可再生候选、保护排除、完整引用水位、pin/claim与防替换能力。列原WI costKey和待测成本；本模板不授予删除或LIVE权限。

涉及更新/学习时列来源核验方式、精确声明/成员闭包、已验水位、采用基头及恢复依据；列真实接入角色/用途/parent、候选字段流向及当前Intent/OutputContract。许可、原批准与当前deny独立核，合法自动采用范围明确，新增成本按原WI记。
