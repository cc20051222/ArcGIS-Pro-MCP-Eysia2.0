## 1. SP05：每个格式、动作和支持域独立记账

主键为`formatId + formatVersion + action + adapterId/version + supportedDomainDigest`。action独立为READ、WRITE_NEW、QUERY、EDIT_OWNED、ROUND_TRIP；扩展名DISCOVERY不进入五类成功计数。科学数据不能因能识别文件名就获得全部读写能力。

每条包含真实输入/输出与版本、几何/栅格/字段/编码/NoData/CRS域、容器成员、规模、Host/许可/依赖、参数/effects、损失策略、oracle、恢复、成熟度/可用性、实际证据、限制和替代路径。原21×5=105仅是候选记录；每格确定有意义的范围，正式承诺后不能为删失败临时标NOT_IN_SCOPE。

| 动作 | 成功的最小事实 | 常见错误推定 |
|---|---|---|
| READ | 完整目标范围解析，类型/单位/内容正确 | 扩展名识别或首行可读就是成功 |
| WRITE_NEW | 新拥有文件/容器和全部成员符合真实标准，内容核验 | File.Exists或转换exit0就是正确格式 |
| QUERY | 范围、分页、空值、过滤语义与完整集合正确 | 返回第一页或部分点就是全集 |
| EDIT_OWNED | 准确批准对象/字段/动作修改，读回和未知effects对账 | 读Excel写GDB就是编辑Excel |
| ROUND_TRIP | 固定A→B→A链的结构/属性/几何/CRS/声明损失对照 | 两次转换成功就是无损 |

READ资格不继承为WRITE或EDIT；普通Parquet不冒充GeoParquet，普通TIFF不冒充COG，LAZ支持不推出COPC。未知版本不写“全版本”，某string参数无枚举也不证明无限制。每个承诺子版本、尺度与参数域仍有真实正例、关键负例、内容oracle和必要恢复。

## 2. ConversionPlan和LossReport

转换前冻结目的、允许损失、比较oracle与容差；原件保留，输出限拥有副本。LossReport按字段/对象/波段/时间维列原语义、转换后语义、丢失/截断/精度/编码/CRS/NoData变化、可逆性、依据与未知项。用户选“导出SHP”不等于同意全部字段和精度损失。

科学分析输入默认不接受改变事实口径的隐式损失。确需简化/受限格式时，以明确ConversionPlan和采用记录限定；不能为了快用宽容差掩盖错误。未知损失显示未知，不显示无损；得到损失采用后仍验证实际结果符合约定。

必须覆盖名称截断、字段类型/精度、日期/时区、空字符串/null、Z/M、曲线/环向、CRS/轴序、格网/位深、类别/NoData、点属性、历法/维序、压缩和分页。输出带ConversionReceipt、ID/字段映射、被拒记录、损失清单、版本和内容证据。SHP侧车、GDB成员、分区数据、科学立方、项目引用都检查集合，不只主文件。

## 4. 原始资料理解与J05 DatasetDNA

DatasetDNA的落地合同为DatasetProfile，加SourceDocumentProfile、ExtractedCell、SchemaCandidate、MappingDecision、ProvenanceRecord。记录sheet/单元格/页/原字符串、抽取方法、候选值/单位/类型、字段别名、置信、歧义、来源/许可和采用决定。

识别多行表头、合并格、编码、小数/日期、度分秒、分组和缺失值。OCR可建议不能直接生成事实，缺CRS不能凭坐标大小define projection。正确发现表格不推定新规范全部条款识别；无法定性的关键条款集中提示并保留页定位。

用户上传他人数据可以学习结构、字段映射与可用任务，是否可将该数据作为当前分析输入、复制素材、外发模型、长期学习和训练分别控制。来源声明不等于真实授权；未知许可的素材不进入正式交付复用。原事实、推断候选、采用值和本项目计算结果分别保存。

参考数据画像可用于“你的资料还缺哪个字段”和“这个已验映射可否复用”，但不把参考统计值或他人分析结论替换本项目真值。跨项目复用映射重新核实际schema/单位/CRS/时间；同字段名不同单位或同名不同含义形成反例。

## 5. J04 ReferenceStyleDNA：学成图，而非复制事实

ReferenceStyleDNA记录参考文件身份/许可/允许用途、地图/标题/图例/说明/装饰区域、布局关系、颜色关系、文字层级、质感、留白、提取模型/规则版本、置信与证据。StyleRoleMap将“标题位于上方”“图例分组”转为可编译约束，避免把整张位图当可编辑模板。

步骤为：安全导入→角色候选→科学保护/许可过滤→受限StyleDNA→与本项目FactTable/DesignSpec绑定→最多三首轮预览→显式采用反馈→新不可变DesignSpec→PS/Office/视觉与事实检查。真实源数据与图形图层若合法可用，另建语义图层映射；单张像素图不能保证恢复真实GIS几何、地理配准、字体和可编辑原图层。

参考模仿分别评估布局/色彩/文字层级相似、科学完整、事实不变和来源合规。允许用户选参考A的排版、B的颜色关系、C的文字层级，冲突须StyleMergeDecision。系统不默认复制Logo、背景摄影、受限制底图或未知字体；具体素材采用需要许可和用户指定。

科学保护区包括图框几何/比例、真北/坐标、分类阈值/定量色彩语义、图例绑定、统计数值、分母、单位、来源/不确定性。装饰无法覆盖保护区；参考图缺比例尺不能导致本项目省略必要比例尺。学习成功不是只看图片像，还需本项目每项内容和编辑性成立。

白名单内容是声明式配方、受限AST、Design/Office规格、合法静态素材/符号、方法卡/引用、合成样例和证据元数据。固定解释器只调用既有准入操作；表达式无任意文件/网络/代码权限。禁止任意Python/JS、DLL、Shell、安装命令、宏、未知动态依赖、凭据/token/批准和用户绝对工程路径。

adapter二进制是独立受评审的发行组件，不伪装成资源内容。hash仅证明摘要一致，不证明来源可信或科学正确；作者自填trusted/qualified/adopted不授信。来源与必要签名按已配置采用政策核查，签名也不替代oracle。

## 7. 导入与资格是两个作业

1. 导入仅在上限内读取manifest和成员：路径逃逸、重复成员、链接/别名、大小/数量、压缩展开与schema检查。
2. 对照白名单类型、摘要、来源/许可、有效期、依赖循环和冲突，固定解析，不加载任意代码。
3. 核当前Host/许可/格式/模型/字体/ICC、方法前提、准入和离线条件。
4. 核现有资格证据与包/依赖版本归属；缺合成已知答案、关键反例、至少两份不同合格新资料回放，就保持WAITING_QUALIFICATION。
5. 实际回放另建资格作业，有当前输入/批准/拥有fixture/预算/Invoker，不因导入自动运行GP/PS。
6. C0或正式有权验收方根据独立证据采用不可变版本。执行端只交PASS CANDIDATE；包作者与系统不能自批。
7. 新任务可选新已采用版本，旧任务仍锁原版；撤销/停用保留历史、在途和回滚依赖，不删除用户成果。

状态包括IMPORTED_CANDIDATE、WAITING_REQUIRED_CAPABILITY、WAITING_QUALIFICATION、WAITING_ADOPTION、ADOPTED、HELD、REVOKED、REJECTED。导入ID、资格ID、裁定ID和采用ID分开；UI不能因为导入成功显示“功能已升级”。

## 8. J01/J02自主更新和逐项资格工厂

“自主适配”是自动发现、生成候选、执行合法测试、定位差异和申请采用的流水线，不是无限运行陌生代码。受控来源包含已批准官方工具元数据、已信任版本资料、固定provider目录、内部采用案例和合法资源；网页内容、上传文件或模型建议只有资料身份，没有授权。

完整流程为：`SourceObservation → CatalogDiff → CanonicalMapping → TypedContractCandidate → Effect/License/DomainCheck → Fixture/OracleSelection → QualificationJob → EvidenceBundle → IndependentDecision → AdoptedCapabilityPack → Canary/Drift → Renew/Revoke`。

静态生成器将参数家族转换为codec和条件合同，逐操作仍保留动态依赖、环境、effects、许可、输出语义、恢复与oracle。GP版本新增参数/默认/effects有影响闭包，不能仅更新schema后继续执行。固定adapter版本和Host符合才可派发；新增算法来源有真实方法和合法依赖，再计入独立能力。

资格工厂将共同准备与fixture复用、自动调度、内容oracle、原始日志归集和独立审查摘要自动化，减少人工做重复setup；不会删困难操作或只测“可调用”。难操作仍可人工专业制定oracle，其持续有效性保留专业审查。隐藏答案由C0/独立专业方在候选冻结后制作，E5不能提前获得。

每个真实canonicalOperationId至少绑定源版本、输入域、参数域、effects、许可、oracle、恢复、成功与关键负例、当前可复用资格。失败、Blocked、域外和陈旧项留在分母；发现数、注册数、准入数、运行正例数、独立资格数分别列。全目录结构必要合同覆盖≥95%目标和最终数量门不替代逐操作内容验证。

## 9. J03数量领先与持续增长的可核验口径

旧目标`K=max(2100,ceil(1.10×N))`完整保留，N按冻结版本和合法前提去重可执行GP计算，1900+不能直接当1900。新增跨provider真实算法来源挑战3000项，但未知来源、许可、oracle或语义独立性不得写已达标；无法达到挑战不允许把旧2100门降低。

去重图谱建canonicalOperationId、问题/方法、输入输出语义、来源/版本、alias/equivalence/specialization边与独立裁定。专用入口、通用GP、同工具旧新名、别名、配方、参数实例、行业皮肤、模板风格共享操作身份，不重复计数。真的新算法需同冻结域证明语义独立与业务效果，不仅名字不同。

同一Esri全集有限，目录全发现只是该来源覆盖。要“断档”需更多真实合法算法来源、深度任务链与质量/恢复/易用优势；不能保证永久领先。增长指标为净新增独立合格操作、版本适配延迟、覆盖问题域、全链成功和误调用/漂移恢复，撤销后数量应真实减少。

若D15–42作为28天资格窗口且Q=0，旧2100需每周525项净独立接受，挑战3000需每周750项；这含失败重做、Host/许可等待和独立审查。原180/300每周不足以证明八周全量。只有当前域有效资格Q才可扣除，剩余数量率为`(K−Q)/4周`；若N上升使K更高，同步重算。流水线自动化和加机器/许可/审阅容量必须通过实际难度校准，不能由代码生成条数证明。

旧GP和新语义挑战是不同门：`K_GP=max(2100,ceil(11×N_GP/10))`、`K_sem=max(3000,ceil(3×N_sem/2))`，完整去重资格池`K_union=K_GP+K_sem−K_overlap`。交集K_overlap由语义图谱与证据逐项裁定，不能按名称猜；当前可复用Q_union也在同一并集下核证。四周需求为`ceil((K_union−Q_union)/4)`，在2100/3000且Q_union=0示例中，750/周只对应交集2100、并集3000的下限；零交集并集5100需1275/周。正式格式动作、模型/学习、模板和用户门仍单独计算资源，不能为了降低该池重复计数或删其他门。

## 14. V5借鉴开放格式：结构验证和资产语义分开

GeoParquet1.1.0明确geometry列、encoding、crs和其他空间元数据；其中crs省略有格式规定默认，显式null表示未定义/未知，两者不能混同。[GeoParquet1.1.0](https://geoparquet.org/releases/v1.1.0/)。这是固定规范语义，不是按坐标范围猜CRS；其他来源的缺CRS仍遵守原关键未知门。实际adapter必须在该版本域正确解释列/轴序/编码/边界/空值和声明的几何类型。

任务准备、资源包采用、交付激活和迁移在实际消费/发布依赖前先耐久pin，固定回收claim与新pin在同一控制排序裁定。干运行之后有新合法引用，本项取消候选；claim先提交时，新消费者同步等待或重建，不拿旧bytes开工再补pin。claim期间固定adapter再核真实resolved Droot/文件身份、完整成员、当前policy/授权和保护排除，逐件intent→处理→读回→receipt→核销；没有真实排他/身份见证就保持干运行。目录级递归删除未知子项、触碰reparse/路径逃逸、未知锁/外部writer以及DB/journal与文件删除的原子事务承诺均不属于首版。

工作台默认展示“可管理缓存”“本轮预计释放”“已确认空间”“保留及原因”“待对账”，可以展开资产/用途/任务与再生代价。预计量不能显示为已释放，索引解除不能显示为物理空间归还，移到隔离目录不算释放；文件缺失、handle仍占用或实际释放无法归因时显示待核原因。合法缓存命中消失仅影响下次复用与重建，不能把已领取的完整成果改成已删除/已失效。

用户无需懂pin/GC脚本或人工在PS中整理中间件。系统在既有明确缓存管理范围内按已验政策自动控制可再生资产；超出范围仍按原权限要求处理，不靠“自动化”取得原件/成果/证据/回滚删除权。自动运行有扫描/成员/字节/时间预算，优先停止低收益后台学习/更新/预览；控制记录与原必需输入/质量/格式/DPI/可编辑成果优先，不通过降低精度、漏成员或删完整范围腾空间。取消后的半清理按原持久清单恢复，不能整批重删或向用户报全部恢复/全部清空。
