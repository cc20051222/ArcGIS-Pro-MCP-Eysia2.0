## 1. 模型职责：提出候选，不拥有执行权

模型可以理解自然语言、提出数据映射、选择方法候选、建议计划和设计、解释真实事实、提取参考风格、整理偏好或把成功业务编译成候选技能。模型不能修改批准范围、改变科学方法前提、自行运行脚本或领取许可，也不能把自己的“完成”文本写成作业事实。

路线统一为`ModelRequest → ProposalEnvelope → 类型/语义/事实/上下文检查 → IntentFrame / PlanPatch / DesignPatch / LearningCandidate → 共同准备与采用`。Host效果继续经过批准、预算、唯一Invoker、持久intent、结果检查与receipt。自然语言、表单、技能、上传参考和模型function-call都不能形成第二执行入口。

`IModelProvider`只负责Profile、固定任务类型、规范事件/结果、取消语言请求和usage；提供者SDK不得自动执行另一套工具。工具提案转换为`ToolProposal`并走现有准入。结构化输出限制格式不能证明方法正确、数据完整或计划可执行；拒绝、截断和语义错误仍需显式处理。[OpenAI Function calling](https://developers.openai.com/api/docs/guides/function-calling)、[Structured outputs](https://developers.openai.com/api/docs/guides/structured-outputs)

## 4. 分层自评测和路由实现

不要按“便宜模型处理简单任务、贵模型处理复杂任务”的固定品牌表路由。先确定当前业务步骤需要的能力和不可缺约束，再从当前可用且在该域已合格的Profile中选择。路由目标是在原质量门约束下优化全任务延迟、费用和资源；不以模型响应秒数代替整链成功。

分层评测至少覆盖：结构化意图/字段映射、方法适用与科学拒绝、计划和effects识别、参考风格提取、可绑定事实的解释、技能泛化与恶意资料指令隔离。每层有正确、反例、歧义、拒绝、长输入和当前任务不适用样例。独立隐藏答案由C0/独立专业方在候选冻结后制作；E3/E5不能看到验收答案后再把同题优化当泛化证明。

实现步骤：

1. E3定义统一ModelTaskSpec和能力需求，由E1实现受限adapter接口与事件归属。
2. 在合法测试数据上建立公开开发样例和冻结隐藏评测，后者不暴露给执行端。
3. 运行无effects的资格作业，记录结构、语义、事实、拒绝和曝光结果，再以必要标准链验证实际任务。
4. 独立裁定后将资格绑定具体Profile和支持域；不同量化/权重/上下文/SDK/工具schema变化不是原资格自动继承。
5. 路由过滤不合格或不可用模型，明确选择依据；已批准固定计划不因换模型重复执行。
6. 更新先canary与影子提案，对比业务错误和拒绝；达到非劣条件再扩大。失败撤销新Profile，保留旧版或进入标准表单。

自评测自动化只能加快收集证据和发现漂移，不能由模型自己给自己升级INDEPENDENTLY_ACCEPTED。在线任务反馈不等于所有用户同意将资料用于训练；没有合法测试域的新能力保持候选。

## 5. 提案流式、有界重试与晚到回复

先定义完整领域schema，再编译为提供者支持的子集；提供者不支持某schema关键字时，本地仍执行完整条件约束。流式增量只显示草稿，按`requestGeneration + outputItemId/callId`分桶，不混合交错调用。完整项且响应终态有效才形成typed payload；bytes/events/depth有硬上限，截断、拒绝、取消、缺结束事件都不执行。

事实数值来自FactTable及其引用，解释由ClaimBinding绑定。模型算出的另一个面积、概率或分母不是新真值。重要字段低可信时形成少量合并问题，不能由偏好自动猜补。标准方法说明可以在模型解释失败后确定性生成，但回执应如实说明使用了哪条路径。

重试只由一个责任层控制，SDK内部尝试同样计入。初始建议每个logicalLanguageRequest最多3次总尝试，含schema修复；这是待实测应用配置。429/503等临时问题在合法Retry-After、deadline与根预算内退避，账户/额度/配置错误不反复发。语言重试、模型切换、计划修订和重启均不重置根任务预算。

采用时原子核对task/plan/input/catalog/schema revision、当前requestGeneration/activeAttempt、未取消、未超deadline、槽位未采用。采用决定与关闭槽位同一持久事务。取消/切模型使旧generation失效，即使计划版本相同也拒绝迟到回复。不同requestId或proposalId的重复返回也只能在该逻辑槽位采用一次。

语言解释丢失只能从已验事实补生成，不能重跑GIS/PS。providerRequestId收到后绑定，不用空ID加attempt合并并发请求。请求发出前持久化本地logicalLanguageRequestId/attempt；这是usage对账的不可变主键。

## 6. 费用、资源与曝光预算

UsageReceipt记录原始usage、adapter解释、实际已知/未知计费、所有尝试与根预算。未返回usage不是0费用；发出后超时或取消仍可能计费，保留保守预约和待对账。新尝试另预约允许的最坏费用，预算容纳不了就等待；迟到usage可核验归属后一次去重回填，未知归属不猜。

模型路由与学习后台共用资源调度。正在运行GIS/PS、用户取消和状态查询优先于偏好挖掘、能力canary与候选探索。参考图提取、OCR与大上下文都有内存和输入大小预算；资源不足可以减少可选预览或排队，不降低正式图分辨率、科学精度与必需输出。

ExposurePolicy将原数据、地名、统计摘要、参考像素、个人习惯、客户工程、检索向量分别分类。默认学习资产在本地项目/用户范围，不跨用户、跨团队、跨租户训练或向远端上传。向量同样可能泄露资料语义，不能因为它不是原文件就免除范围控制。已允许发送摘要不自动允许发送整表或原图。

## 7. J06 PreferenceProfile：学用户习惯但保留显式控制

PreferenceProfile至少包含profileId/version、owner/projectScope、createdFromEventRefs、explicitChoices、inferredCandidates、confidence/recency、applicability、conflictRules、retention、export/forget记录。偏好内容可包括常用用途、尺寸/DPI、文字层级、布局密度、合法色板、解释详略、数据字段别名、输出目录偏好和常用交付组合。

学习来源分别计：用户明确“记住这个”、采用的稳定改稿、反复的同条件成功选择、团队标准包。只聊天提及、草稿、取消结果、一次错误或没采用的候选不能自动变成稳定习惯。重复次数增加置信并不授予新的数据发送/写入权。

优先级固定为：法律/来源许可与科学约束 → 当次明确OutputContract与用户决定 → 项目/团队正式规范 → 用户显式长期偏好 → 推测候选 → 已验默认。团队偏好和用户个人偏好冲突时不静默覆盖，说明影响并形成决定。被标记不适用的项目偏好不传播到其他行业任务。

```json
{
  "profileId": "pref-userA-projectP",
  "version": 3,
  "scope": "PROJECT_PRIVATE",
  "explicit": [{"key":"reportTextDensity","value":"concise","eventRef":"feedback-42"}],
  "inferredCandidates": [{"key":"legendPlacement","value":"right","confidence":0.78,"status":"SUGGESTED"}],
  "immutableConstraints": ["classification-boundaries", "facts", "approved-effects"],
  "remoteExposureAllowed": false,
  "forgettableLearningRefs": ["case-12"]
}
```

忘记偏好时生成新版本、删除允许遗忘的学习索引并使相关建议缓存失效；已交付事实、原任务回执及必须保留的审计依据不伪称消失，按具体保留政策说明。导出不含密钥、机器token、历史批准或别的用户私有资产。用户暂停学习后普通任务继续可用。

## 8. J04/J05参考学习：风格与资料语义分离

ReferenceStyleDNA包含布局拓扑、图框/图例/标题/说明角色、颜色关系、文字层级、纹理/留白和置信及提取证据。DatasetProfile作为J05的数据语义合同，包含源身份、字段/单位/CRS/时间/选择/质量、来源/许可与采用映射；主方案称DatasetDNA时映射同一对象，不另建重复真值。

参考像素中识别的比例尺、经纬度或图例文字只能是候选描述，不能确认为用户资料的地理配准、真实分类或可编辑GIS几何。只有合法带空间参考的源数据和已验映射才进入分析。图片学习默认提取抽象样式，不复制受限制的底图、Logo、摄影或字库；复用具体素材需有相应许可与用户指定。

将参考样式编译为受限DesignPatch前，检查是否改变分类颜色语义、分母、图框比例、真北/坐标、统计值、版权或必要内容。冲突时保留科学内容并展示可采用的视觉部分。例如可以学对齐与留白，不能把某图的红色风险阈值直接套入另一个风险模型。

多参考可以按用户指定角色组合：A布局、B字体层级、C色彩关系。冲突记录到StyleMergeDecision，不交由模型随意融合。输出最多三张首轮比较预览，采用和不采用反馈分别留证；正式成果仍按全部图形、科学和编辑性门验。

## 9. J07经验回放和J11业务技能编译

LearningCase不是整段聊天转成“记忆”。它包含问题域、输入快照/允许引用、MethodCard、固定计划、环境/许可、实际执行receipt、检查覆盖、用户反馈、适用条件与失效依赖。失败案例记录失败原因、已知/未知effects、正确恢复和负例，而不是将失败步骤照搬。

案例检索先按领域、方法前提、输入语义、许可、effects与版本过滤，再进行相关度排序；相似图像不能使不适用方法变适用。每次复用输出CaseReuseDecision，说明哪些已验组件可用、哪些参数需重新绑定、哪些授权不可继承。证据陈旧或输入域外则保留解释参考而不执行。

技能编译提取业务输入角色、条件、typed DAG、输出合同、oracle和恢复策略，不复制用户绝对路径、ID、凭据和批准。候选技能先做合成已知答案、反例和至少两份不同合格新资料回放，经过独立验收再可复用。成功案例一键“保存为流程”是提交候选而不是永久拥有执行权限。

知识可迁移和权限不可迁移同时成立。团队导入某人技能仍需当前输入、Host、许可、预算与scope准备；不因技能来源“曾通过”自动写用户原件。固定解释器只能调用已有准入操作，技能文本不能携带Python/JS或新的6511旁路。

## 10. J08主动补缺与多方案探索

主动补缺根据OutputContract反查必要资料，再以已知事实和MethodCard确定候选，不靠大模型自由设想数据。缺CRS、时间口径、测量方法或许可时集中呈现；可使用合法已有资料引用但不能自动下载、购买或上传未批准资源。

多方案探索明确目标、硬约束、允许参数域、候选上限、费用/时间和选择依据。默认最多三张首轮方案预览；有实际分析effects的探索需独立作业预算和拥有输出，未知结果先对账。探索候选数量不能计作独立GP工具或已验模板数。

科学比较使用同一冻结输入、分母和合法方法；不同方案改变何种条件必须说明。视觉候选检查可读性、内容完整与事实保护后才比较审美。模型可建议但不能自动为赢得评分删复杂要素、缩小失败分母或消除不确定性说明。

## 11. 切换、无模型与降级合同

| 故障/变化 | 可以继续 | 必须等待或重审 |
|---|---|---|
| 草案模型不可用 | 已确定用途/对象、确定性表单 | 新的未知语义/方法选择需已验替代或等待 |
| 已批准固定计划 | 仍有效的确定性步骤、状态与取消 | methods/effects/费用/曝光变化按影响重审 |
| GP/PS运行时模型断线 | 固定执行、对账、真实检查 | 不因模型超时再次派发Host效果 |
| 新模型缺视觉能力 | 确定性布局/字体/内容检查 | 必需且无已验替代的视觉检查不能伪报通过 |
| 学习索引坏/过期 | 普通标准任务与明确当次条件 | 不采用未经重验案例或偏好候选 |
| 本地转远端 | 既有允许摘要范围 | 原表/图/偏好未获范围授权不能自动外发 |
| 模型升级 | 旧Profile已验任务路径 | 新Profile先资格与canary，模型名相同不继承资格 |

SP07表单仍生成同一IntentFrame/PlanCompiler/Invoker。三条标准链在无模型且必要Host/方法/PS/资料齐全时满足原全部输出；若缺PS或科学方法，不把“无需模型”冒充整链完成。

## 12. 八周落地任务与验收

W1由E3定义ModelTaskSpec、五adapter映射、ProposalEnvelope与学习合同，E1落实持久归属和预算；W2交真实路线、表单、偏好和参考第一闭环；W3–4在通用链、规划/科研模板验证模型切换/故障与科学保护；W5–6完成原路线与全学习对象、技能泛化、forget/export、canary；W7做隐藏、新手与竞争冻结评测；W8在完整门后为安装包检查依赖/首次配置。新增能力不算已实现，必须对应原始实测。

两个月资源校准采用总去重资格池，而非只选两个数量门中较大者：`K_GP=max(2100,ceil(11×N_GP/10))`、`K_sem=max(3000,ceil(3×N_sem/2))`，`K_union=K_GP+K_sem−K_overlap`。交集K_overlap与可复用Q_union均逐项核证；D15–42四周所需净率为`ceil((K_union−Q_union)/4)`。2100和3000、Q_union=0时，750/周只是交集2100、并集3000的下限；零交集5100需1275/周。模型/学习/格式/模板门仍有另外的实际验收资源，不计作GP或语义数量以减少并集。

验收至少覆盖结构成功、坏schema、语义错误、拒绝、截断、交错流、重复/晚到、usage未知、账户不可用、预算耗尽、取消、远端越范围；提案/GP派发/receipt/解释四阶段注入故障并核副作用次数。学习另测误记偏好、跨项目污染、显式覆盖、忘记后复现、参考提示注入、事实污染、素材无许可、技能新资料、失效案例和模型升级漂移。

自评测与路由采用前，旧完整任务成功、事实/方法与科学门不得下降；比较全链p50/p95、失败/拒绝分母、token/费用和资源，而非只测一句话速度。原60场景、压力集、24名新手至少48任务和独立隐藏门由[主验收](<../01_主方案（6份）/VERIFICATION_AND_TRACEABILITY.md>)统一保留，执行端不自批。

持续学习的增长应统计“新增独立接受案例/技能、覆盖的新合法任务域、减少必要人工判断、错误与漂移恢复”，不能用记忆条数、调用次数或模型自评分证明永久领先。两个月完成目标需要全域工作量和资源证明；未证实的速度改进保持计划假设，不将训练、参考模仿或关键功能移出最终范围来换日期。

## 13. 用实际业务检验学习是否有效

**规划汇报例。** 用户连续三次选择同一报告密度和图例分组，系统先提出可记住的项目偏好；第四次用新行政区资料时只复用布局建议与已验字段映射，仍核新的单位、时间、边界和用途。用户这次要求“文字更详细”，当次要求覆盖长期简洁偏好。验收比较减少了哪些重复选择、是否仍问真实缺项、报告数字是否来自新资料；不能仅凭第四次对话更短判成功。

**科研图例。** 用户上传一张颜色漂亮的论文图，系统可学习留白、标题层级和面板组织；图上原分类阈值、显著性符号、比例和统计值不迁移。若用户资料是另一变量或时期，方法卡与事实绑定决定科学表达。用户要求“跟参考一样红”但与定量颜色语义冲突时说明原因、保留合法替代并记录冲突；学习效果以事实正确、必要内容和可读性同时通过为前提。

**格式映射例。** 他人表格的“面积”列单位为公顷，用户新表同名列为平方米。案例检索可以建议字段角色，但单位检查应发现不等价；正确行为是使用当前元数据或集中询问，而不是把历史单位默默套入。字段名相同却语义不同、编码不同、合并表头变化和公式缓存过期都要列为负例。已验映射有适用域，不是永久通用。

**失败回放例。** 某次PS保存回复丢失，系统已有文档身份和写入意图。经验库记录如何读回、查产物与关闭重开，不能记录“超时就再保存”作为复用技能。另一次遇到不同权限或文档归属时需当前预检，不能因为历史恢复过就重新执行未知效果。验收统计实际副作用、恢复时间、未解决未知项及是否破坏用户外部编辑。

**模型升级例。** 新版本提案更快但在日期、单位或拒绝样例上变差，系统保留旧合格Profile并拒绝在该域升级；其他确实不受影响且已验的域可单独采用。不能以平均得分提高抵消科学错误，也不能在少数简单题上赢了就覆盖所有任务。模型费用未知、流式漏终态、截断和同名权重变更都作为升级门的真实失败。

**团队习惯例。** 一位成员偏好浓色、团队科研规范要求可区分的灰度。工作台说明正式规范优先，把个人偏好保留为其他适用项目候选；团队接手者不继承原成员的数据发送和写入批准。忘记某成员学习后，其个人检索资产不能继续影响别人的自动建议；必要历史回执按保留政策单独显示，不假报已删除全部事实。

每个案例都采用不同新资料、冻结的真实结果判据、用户可感知的减少重复操作与对照路径；失败分母保留。案例检索、偏好规则和风格提取只是机制，只有任务完成率、实际人工时间、科学正确、恢复和满意度改善才构成学习收益。若自动建议造成反复纠错、隐私越界或科学误用，则撤销该规则/案例的当前资格并保留诊断证据，不让系统因“学习次数更多”继续强化错误。

## 14. V5结构化经验：借鉴追踪机制，不部署训练平台

MLflow以run组织参数、指标和产物；DVC用内容资产和依赖/参数记录辅助复现。[MLflow Tracking](https://mlflow.org/docs/latest/ml/tracking/)、[DVC项目流水线文件](https://doc.dvc.org/user-guide/project-structure/dvcyaml-files)。本项目借鉴这两个分离思路，在原JobStore和EvidenceLedger中加入`ProbeRun`与`LearningIndexProjection`，不要求安装MLflow/DVC、运行其CLI、开放新服务或下载权重。

ProbeRun绑定runId/parentTask、purpose、Profile/模型/adapter版本、输入域与允许摘要、方法/规则/schema锁、公开或隐藏测试归属、实际终态、usage、所有预算、产物引用、检查结果、独立裁定和失效原因。LanguageRun、HostQualificationRun、DesignReplayRun与UserFeedbackEvent分别存身份，不能把语言结构正确当Host成功，也不把学习反馈计为独立资格。

LearningIndexProjection只投影已提交事件，公开字段检索可以采用现有固定过滤和文本索引；向量检索是可选排序增强，不成为八周必须新增外部数据库。候选库与已验库分开，索引损坏可以从合法事件重建；重建失败明确待修，不静默让空索引伪装成用户没有习惯。私有embedding、摘要和源文件具有相同用途/范围约束，不能默认传云端。

### 14.1 过滤、召回、排序、解释的实现顺序

先以用户/项目/用途和来源许可过滤，再按当前数据语义、MethodEligibility、Host/Profile/版本、effects和完整OutputContract筛资格；之后才做相似度或用户偏好排序。旧案例支持点数据不能因为关键词相似就匹配面统计，科研图的风格邻近不改变分类方法。被撤销、过期、忘记或域外案例既不能派发，也不应继续出现在自动建议中。

检索回执至少列候选来源、适用/不适用理由、采用到哪个参数/风格角色、未解决关键项和是否需要新决定。解释来自这些记录，而不是由模型事后补造“我理解了你的喜好”。排序失败或模型不支持embedding时，已验结构化过滤/表单/模板仍提供同必要业务能力，不丢功能。

## 15. 风格不确定度与模型角色的真实资格

参考图的区域、OCR、字体层级、颜色角色和地图/装饰判断分别记录observed/inferred/unknown及证据，不能把一个模型overallScore当所有局部都正确。不同模型score不能直接比较，未校准概率标为模型原始置信或启发式分，不显示“99%可靠”。几何/比例、科学分类、统计值、版权和用途绝不由置信自动批准。

| 提取角色 | 可以自动成为候选 | 必须独立核查 | 不成立时的完整路径 |
|---|---|---|---|
| 布局/留白/元素关系 | 边界框、相对对齐、空间层级 | 当前画布/图例容量/必需内容可放置 | 同合同已验布局模板，列明与参考差异 |
| 字体/文字层级 | 标题/副标题/注记角色及相对字号 | 当前合法字体、真实字形/度量、OCR关键文字来源 | 预验合法字体重新测量，不复制OCR错字 |
| 颜色/纹理 | 背景与装饰关系 | 定量色彩/类别、印刷ICC、素材许可 | 保留科学色带，只迁移合法非科学色彩 |
| 数据结构 | 字段角色/编码/单位候选 | 当前schema/单位/CRS/时相/实体与来源 | 冻结已知映射，关键未知集中确认 |

视觉模型只是其中一种观察器；固定区域/布局规则与已验模板也可完成角色化学习。替换模型后先用相同公开/隐藏域验证提取错误、科学冲突、完整任务和实际资源；图像看起来更像不抵消错误事实。不能承诺任意模糊、复杂或无合法源文件的成图100%复制；产品承诺可解释抽象风格迁移和当前任务的正确可编辑成果。

## 16. ModelCapabilityProbe必须绑定环境和故障

模型“支持JSON/图片”声明不是本项目资格。每路径的ProbePlan绑定真实endpoint、账户或本地权重身份、adapter版本、允许数据范围、请求大小/上下文/资源预算和冻结用例。无effects探针优先，不外发用户原表或参考图；实际业务外发仍按ExposurePolicy。模拟provider响应仅验证本地处理，真实路径资格另存。

最低探针覆盖正确typed提案、schema/语义错误、拒绝、截断、流交错/中断、取消晚到、重复、usage缺失/延迟、未知计费、账户/配额、能力缺失和本地离线。当前模型名不变但权重/量化/tokenizer/后端/adapter或上下文政策改变，使相关Profile资格待重验。故障时标准表单与已批准固定步骤可继续的前提仍是必要Host/方法/PS/输出依赖成立。

模板回退或小模型路由只能在原OutputContract和原科学、设计、编辑性门内采用。降低可选预览数是资源策略；删除必要分析、字段、PSD、Office结构或科学说明是功能变化，不可叫降级保持全功能。实际没有等价完整路径就等待，保留已验部分并说明缺项。路由计费未知的保守预约、languageRequest持久主键、根预算和一次采用继续不可省。

## 17. 可撤销学习的成本、隔离与验收

实现归属：WI03负责ProbeRun/事件投影，WI05/07负责当前资料/方法过滤，WI15负责版本资格，WI23负责失效闭包，WI27负责LearningCase/技能，WI28负责解释/遗忘界面；J04–J07/J10–J12的新增检索、局部不确定度、版本比较与源权限另记边际。现有五提供者路径与55条支持规格继续有独立任务，不因复用通用字段少算adapter测试。

训练、微调和新的索引服务若未来采用，要分别证明资源、来源、质量与回退，并作为正式受验依赖，不成为首版学习必要条件。后台自评测和案例挖掘受资源/费用额度与用户前台优先级约束；无资料、未知许可或未具备Host的任务保持阻断，不靠自产模型答案提高净吞吐。

验收新增：同样例不同score量纲不混用；参考局部置信高却科学冲突仍拦截；重复用户点击不形成未明确采用的稳定偏好；跨租户/忘记/撤销资产不召回；索引损坏重建不造新事实；模型升级后usage未知不释放保守预算；无向量服务/无视觉模型仍在已验等价域完成全部必要成果。隐藏答案由C0/独立专业方候选冻结后保管，实现者不可提前看到。

最终比较实际必要问题数、任务成功、用户主动分钟、误推荐/纠正、全链p50/p95、成本和科学门，不能用检索速度、模型自评或记忆条数代替学习效益。60日剩余工作和资格并集容量仍未知，采用条件未满足就保范围质量并重排，而非取消原模型路线、格式动作或学习功能。

## 18. V6模型职责缩小，系统智能完整保留

模型负责有限问题的表达、字段角色候选、情景候选说明与带引用差异解释；PredicateGraph四态、事实差值、方法/许可、预算、fence、停止与激活由确定性组件核定。所有模型输出先过原schema/类型/引用及科学约束，出现未知可用规则模板完成表达，不凭流畅语句造事实。

QuestionSet先确定哪些真实事实需答，再让模型润色，重试不生成不同CRS/分母默认值；有界情景枚举来自已验方法/参数域，模型不能自行创建新算法填数量。FactDelta每句解释绑定old/new fact与provenance，缺因果实验则写“关联变化/处理依赖”，不伪称贡献比例。

路由失败保持同一ExecutionLock/根budget/来源授权，结构化缓存必须绑定输入、模型/规则、作用域与学习授权。远端/本地替换回归原能力门；用户关闭学习后不能读取已撤销参考/偏好，摘要、索引及派生经验一起按原遗忘合同处理。用不带个人历史的默认模式仍完成全部核心链，不以持续训练作为首版依赖。

## 19. V7学习证据与模型路由

显式保存偏好在合法硬条件内直接采用，来自隐式点击/一次修改的内容只提候选；记录展现顺序和未展现候选，避免排名位置自证。自动学习优化必须项目隔离留出、trainCutoff、同方法事实/输出、固定cold/warm及试验顺序，失败/超时计入原分母；最低相关case数/指标规则在原型前冻结，当前待测，不随成绩调整。

配对回放只能证明该冻结case集的表现，不能直接宣称全用户因果收益；样本/效应不充分BENEFIT_UNKNOWN。正式独立隐藏任务不进入训练、prompt例子或调参。切模型和换参考时核相同完整任务门，不以新score直接比旧概率；首版仍结构化事件/检索/有限排序，无每用户必需微调服务。

deny-use generation在检索前、model context构造及候选采用前检查，不能把已撤销参考的摘要/embedding留在context中继续用。索引异步清理不阻止即时拒用；必须保留的审计与已领成果、外部权重未知分别说明，不提供虚假的“彻底忘记所有副本”。

## 20. V8模型上下文与降级不得制造复用资格

模型输入按角色投影精确stage/domain/来源事实/待证字段，允许解释变化和候选映射；摘要丢失单位、角色、批准、用途或依赖时必须回取原记录，不由模型补齐。模型输出与结构验证都不能生成完整读集、来源快照保证、当前资格或科学PASS。

规划/分析结果缓存包含实际影响方法的模型/权重/参数/随机性合同与完整输入；解释文字缓存另按事实与语言模型依赖。切换模型若只影响文案仍重核ClaimBinding，若改变字段理解/方法/分类/设计则沿真实闭包重算/重排，不能说所有模型替换都不影响结果。当前价格/费用/网络与发送用途仍按原规则和实际提供者验证。

可以少发无关上下文，完整必需合同/失败信息及可追溯原引用必须在；不把token节省推成代码正确率或60日容量。原提供者故障/能力/预算/接入门不降，模型忙时允许已有合法固定配方或明确等待，不静默改变科学方法。

## 21. V9模型准入与学习更新绑定同一根任务

ResourceDemand把本地模型常驻allocationId及每请求KV/图像/上下文峰值分开；共享权重不重复扣，而并发请求增量不得漏。任务还与Pro/PS/Office整机负载共同判RAM/VRAM；没有实测profile不以权重文件大小证明能装下或速度合格。远程模型请求记录provider/requestId、maxTokens/价格版本/根与周期预算；费用未知不填0。

provider超时可能已产生请求费用或效果，切换模型不能退款或清attempt/rootBudget；任务取消仅拒新请求，未核账保留已批准最坏成本。模型降级必须保持原结构合同/科学事实/完整质量；不合格时等待而非少步骤交差。候选模型版本、模板、方法或习惯参数影响结果时进入资格依赖闭包，不能用schema一样维持旧资格。

ContextCapsule只保留当轮精确权威ref/范围、接口摘要、变更/已知缺口、必要文件定位和已读身份；权威过期按需重新读，必须全文自读不省略。用户私有资料、密钥及C0隐藏答案不得传播到执行工作包或外部模型；原来源/许可/保留期门保持，摘要不是最新事实的替身。

主动学习只提出候选改善，由固定目标、独立oracle及完整当前门评估；模型不得改验收阈值或给自己签资格。公平队列保留取消/状态通道预算，但SDK诊断仍受真实MCT约束，不能宣称任何长Host任务都即时中止。

## 22. V10模型作为候选提取者，确定性合同控制采用

模型可从资料提字段/粒度/role/偏好/失败原因候选，确定性typed规则核当前上下文、科学前提、完整来源与合法域；置信度不把未知基数、CRS、分母、版权或必需规则补TRUE。失败因果未证只记hypothesis，多个模型或provider同结论不产生独立科学真值。

ContextPreferenceResolution读取原E3 Profile和完整当前任务，区分NO_MATCH/UNKNOWN/ERROR/REVOKED；可选学习条件未知可回原完整默认，必要规范未知保持等待。同层不同值不靠模型最新记忆或时间戳决定，任务override不落全局长期档。科学方法/批准/effects从不成为可自由学习偏好。

批量图片按当前role证据有界选择，原始图/特征/摘要进入外部视觉模型之前核每次外发授权和根预算；合法READ不等云端发送许可。已有固定观察器/模板可产生候选，未知role不伪称支持；不以大模型微调成为两个月前置。来源撤销仍V7派生闭包/deny-use，旧历史事实保留。

学习/模型收益对照按已知来源组隔离开发与独立留出，[GroupShuffleSplit官方说明](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.GroupShuffleSplit.html)启发按组核而非按文件随机分；仅借方法，不安装sklearn。组身份未知不能宣称无泄漏；同bytes/同作品的100副本也不提供100独立泛化证据。所有新增预览/解析/反例均同rootBudget，降级/重启/模型切换不重置费用。

## 23. V11模型提案与确定性科学/表达分工
