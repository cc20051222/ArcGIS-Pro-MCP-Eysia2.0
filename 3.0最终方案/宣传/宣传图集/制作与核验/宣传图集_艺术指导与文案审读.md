# ArcGIS Pro MCP 3.0 宣传图集艺术指导

版本：2026-10-02。用途：新一轮宣传图集制作建议，不修改旧宣传成果。

## 本轮采用原生矢量实施版

用户已经选择保持 C 盘禁写，使用 D 盘原生矢量图集。本轮不调用 image_gen，以下原先摄影类描述仅保留为质感参考；实际交付明确为原创矢量插画，不宣称摄影或真实项目成图。执行数据以同目录的 `宣传图集_原生矢量实施文案.json` 为准。

8 张改为主视觉、自然语言、PS 自动成图、参考风格、GP 持续适配、成果同步、多业务、完整交付。每张拥有不同的重心、镜头、空间关系和主物件：河湾城市全景、展开的地图卷轴、大幅纸面地图、原创图册组合、扇形图层模型、版本地图叠放、连续地理长卷、完整成果静物。不能把同一组矩形卡片换标题后复用成 8 张。

矢量实施应包含立体建筑的顶面与侧面、连续道路、水岸、自然河道、山体层片、成组等高线、精细的纸边与材质细线，并用克制的光影和透明度建立空间层次。矩形仅用于真实物件中的纸张与册页，不承担功能模块和流程框。优先看整幅画面的构图与地理细节，再添加品牌和文案。

每张品牌、8–12 字标题、20 字以内副标题、预告状态与固定脚注已经写入 JSON，供根代理直接排版。所有制作与核验文件留在本图集 D 盘目录。

本轮应从“说明功能的海报”转成“令人愿意停留的产品广告图集”。每张只讲一个价值，用真实材质感、城市与地形的空间美感、成图的编辑质感建立产品印象。画面为原创概念视觉，不充当软件截图、真实分析成果或已上线功能证据。

## 一 统一视觉语言

- **视觉方向**：建筑摄影与地理专题刊物的结合。自然纸张、模型地形、实物图册和克制的空间图形为主体；避免平铺卡片、工具流程框、科幻控制台、霓虹光轨。
- **色彩**：暖白纸色 `#F4F1E8`、深墨绿 `#18382F`、天然橄榄绿 `#61745A`、少量暖橙 `#D07845`。每张最多一个主要强调色，保留明暗层次；避免全套变成相同的青绿色渐变。
- **光线与材质**：柔和侧光、真实短阴影、细致地形起伏、哑光纸与木石材质。纸面图件保持清楚，不能用金属反光或装饰覆盖地图。
- **镜头**：封面采用低角度斜俯视；科学成图采用正俯视；成果册采用近景；更新与行业应用采用适度广角。保持系列一致，也让翻阅产生变化。
- **画幅**：建议 8 张统一竖幅 4:5，单张 3000 × 3750 像素；方便社交发布、图集分页与印刷转版。画面上部留出约 18% 自然留白供标题排版，下部留出约 10% 供必要说明。关键主体不跨安全裁切边界。
- **文字**：画面生成阶段不生成中文字、商标、界面或数字。中文标题和品牌由后期真实字体排版，以保证字形、准确性和系列一致。每张一个标题、一句副标题，最多三条短词；不再放整段功能清单。
- **品牌位置**：顶部小字号统一写 `ArcGIS Pro MCP 3.0`；旁边可放 `3.0 方案预告`。主标题使用清楚的黑色或深墨绿字形，不使用花字或发光效果。
- **固定说明**：每张底部保留“概念视觉 · 3.0 方案预告；规划功能及支持条件以实际验收为准”。说明必须在手机全屏查看时可读。

## 四 文案审读与保留边界

1. 所有标题必须与“3.0 方案预告”同画面出现；省略状态会令未来体验被读为现役能力。
2. 不写“已实现数千工具”“全部领先”“永久领先”“保证两个月上线”“零错误”，不做无证据竞争贬损。
3. “不会 PS，也能出好图”描述规划体验；副标题保留科学含义，避免把精美画面包装为实际 PS 验收证据。
4. 参考学习仅提合法参考与适用偏好；不得暗示单张参考图能恢复原作者所有图层或复制作品。
5. 更新画面不出现虚构项目数据、日期、统计值、完成率或 PASS 徽章；它只说明未来产品机制。
6. 不加不存在的官网、联系方式、预约日期或下载二维码；收束页可写“阅读完整最终方案”。

## 五 图集验收建议

- 8 张放在一起时色彩、字体与边距一致，但每张主体、镜头和空间关系不同。
- 先在无文案情况下检查主视觉是否吸引人；如果只是几张纸或复杂线条，不因加标题就认为完成。
- 单张缩到手机宽度查看，标题立即可读，主体明确，脚注能辨；缩略图查看仍有视觉层次。
- 图件的道路、河流和等高线检查重复纹理、断裂、杂乱与不合理交叉；摄影检查纸边、册页、阴影与物件透视。
- 最后使用真实字体加文字并再次检查，不把生成画面里的错字留在交付版。
- 保留旧版海报，新图集独立存放。原图、排版版、分享版与图集文件分类，说明哪些可编辑、哪些是概念视觉。
