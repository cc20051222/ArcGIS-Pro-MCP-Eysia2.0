# ArcGIS Pro MCP 3.0 宣传图集创意方向与实施选择

最终实施：用户明确选择保持 C 盘禁写，制作 D 盘原生矢量图集。已生成八张 2400×3000 的 PNG 分享图、八张同源 SVG 编辑图和一份八页矢量 PDF，统一为 4∶5 竖版；另有离线浏览页。最终版已经逐张实际复看。以下保留最初创意探索，实际文案、画幅与制作方式以原生矢量实施文案和交付回执为准。

## 整体方向

制作八张独立宣传主视觉，采用统一的广告美术语言。由摄影感的三维地理场景、纸张与地图材质、细腻光影和简洁中文排版组成画面，以大主视觉为核心，减少文字。图集应能单张使用，也能连续翻阅。

视觉基调：深海蓝与暖白交替，青绿作为地理与智能的强调色，少量暖珊瑚色用于重点区域。实际图集采用 4∶5 竖版，重要元素置于安全版心。字体清晰、留白充分、标题与主物件有明显主次。

每张仅包含品牌、一句主题、简短说明和规划标识。保留“3.0 方案预告”和“概念视觉 规划功能以实际验收为准”，不使用尚未证明的工具数量、性能数据、上线日期或比较结论。不要伪造软件截图、现有产品界面或真实业务分析结果，不使用官方合作标识。

## 生成与验收

最终未使用内置 image_gen。画面使用原创参数化地形、透视楼群、地图线条与纸页几何生成 SVG 和 ReportLab 矢量 PDF，再将实际 PDF 栅格化为 PNG。中文使用真实字体排版。逐张检查字形、品牌拼写、构图、遮挡、边距和规划状态，并根据独立审读修正重复构图、图层透明度和投影。

最终成品归档到本图集目录，并记录每张图片的主题、最终提示词与工具模式。保存封面或预览索引，方便查看整套图集。旧版海报作为上一版保留，不覆盖。

内置图像工具的默认生成目录与用户的 C 盘禁写约束不兼容，用户已明确选择原生矢量路径。本轮所有制作、中转和浏览核验文件均在本 D 盘目录，不修改 CODEX_HOME、不在 C 盘建立链接、不安装软件，不使用内置 AI 出图缓存或付费 API。
