# ArcGIS Pro MCP 3.0 宣传图集

本套为 **3.0 方案预告**。八幅图用原生矢量插画呈现城市、山川与成果链的概念画面，面向宣传和方案说明；**不是软件实际截图，也不是实际 GIS 分析成果**。发布功能、支持条件与自动化表现以实际验收为准。

## 浏览与分享

直接双击 [图集浏览.html](./图集浏览.html)，用浏览器离线查看整套图集。页面不使用外链、网络字体、外部脚本或远程数据。

- 点击缩略图打开大图，点击左右按钮或按键盘左右键翻页。
- 按 Esc 或点击关闭按钮退出大图；Home、End 分别跳至首幅、末幅。
- 每幅图均提供 PNG 分享图、SVG 编辑图入口，页面另有整套 PDF 入口。
- 将本文件夹整体复制给他人，保留各子目录及文件名，即可继续离线浏览。

## 编辑和使用说明

图中文字与概念图形由原生矢量方式制作。SVG 是可编辑源文件；PNG 是分享成品，PDF 是整套矢量展示文件。编辑 SVG 时，接收设备的中文字体可能影响排版，请在最终导出前核对换行、字形与位置。不要把概念画面改标为实际软件截图或实测成果。

整套画面统一为 **4∶5 竖版**。PNG 为 **2400×3000 像素**，由实际矢量 PDF 栅格化导出；SVG 采用同源矢量图形与可编辑文字，引用微软雅黑中文字体。PDF 每页为 **240×300 mm** 自定义页面；使用 A4 打印时选择“适合纸张”并保持纵横比即可。

所有新制作文件及中转文件仅放在本 D 盘图集目录内，不使用内置 AI 出图缓存，不在 C 盘或系统 TEMP 存放项目产物。旧版宣传材料保留。
