## 使用说明

1. 介绍项目时使用宣传册；直接展示核心体验时使用海报。
2. 修改海报文字时编辑 SVG，保留版心、预告标识和底部说明；修改 Word 正文后重新检查分页。
3. 外发文件可选择 `Word` 与 `海报` 中所需版本，`制作与核验` 保存文案来源、制作脚本、内部审读记录和排版检查文件。
4. 本资料不设置未确认的联系方式、官网、预约日期或二维码。正式发布文案应按产品实际验收结果更新。

完整技术与开发安排见 [最终方案导航](<D:/ArcGIS-Pro-MCP 2.0/3.0最终方案/README_最终方案导航.md>)。

两份 Word 均通过 Microsoft Word 原生分页检查，并逐页查看实际渲染：宣传册 10 页，海报展示版 2 页。两页打印海报及 PNG 已检查中文、文字位置、标签遮挡、图片比例与规划状态说明。以上是宣传资料质量检查，不代表 3.0 产品功能验收。
