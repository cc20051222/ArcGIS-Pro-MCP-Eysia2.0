# 数据发现、画像与质量

## 从业务问题找到真实数据

地图已有图层时读 `get_current_map` / `get_layers` / `get_layer_info`，检查同名、broken、真实数据源、定义查询与选择；没有活动地图时读 `list_maps` 和明确的数据路径，不默认激活或修改工程。

用户给文件夹时用 `scan_data_folder`，默认深度 2、最多 200 项，当前上限深度 4/1000 项；GDB 成员限深 1、最多 50。读取返回的 `available`、`skipReason`、`countBasis` 和截断信息。容器数不等于成员数，扫描项数不等于要素数。超限分区扫描并去重，不能把首批结果称全部。

按实际类型读取 `get_dataset_info`、`get_schema_info`、`get_field_info`、`get_geometry_info`、`get_raster_info`；Python 不可用时采用已注册 Native 的相应只读检查，但必须明确检查覆盖差异，不能假称两个接口完全等价。

## 数据充分性核查

| 范围 | 必查事实 | 影响执行的缺口 |
|---|---|---|
| 对象与范围 | 路径/地图/图层身份、几何、全量/选择/查询、时间和研究区 | 歧义、断源、关键时间不明先定位 |
| CRS 与单位 | 源 CRS、目标 CRS、XY/Z 单位、所需基准转换 | 未知 CRS 询问可信依据，禁止猜测或当作 WGS84 |
| 表结构 | ID、字段类型、编码、前导零、空值、域、子类型 | 缺主键或一对多连接会改变统计分母 |
| 内容质量 | 重复、无效几何、空几何、异常值、空间覆盖、NoData | 发现问题并报告；检测不自动授权修复 |
| 统计依据 | 原始 N、已读 N、样本 N、过滤、缺失、失败和去重规则 | 抽样/截断不能当全量，零值与空值不同 |

`query_attributes`、`get_field_statistics`、`summarize_features` 只使用当前 schema 支持的筛选和聚合。字段名先读回，SQL 方言按实际数据源，不假设通用 SQL。大量记录优先受支持的服务端统计/分段读取；披露取样/上限，不自行启用任意 SQL 执行或脚本旁路。

## 检查工具与修复边界

可按问题选择 `find_identical`、`compare_schemas`、`compare_datasets`、`validate_geometries`、`check_topology_rules`、`validate_field_constraints`、`validate_relationship_class`、`get_dataset_lineage`、`trace_dataset_dependencies`、`generate_quality_report`。调用前读它们的 schema、支持的数据载体和结果口径；不从工具名推断完整 ISO/行业合规能力。

输出问题对象/字段、判据、数量、范围和未检查部分。修复一般先生成 D 盘拥有副本；`repair_geometry`、`calculate_field`、删除重复、删字段、域/子类型和关系类修改都可能改变原始数据，另核当前授权。只读检查不得调用修复，也不自动 `save_edits` / `discard_edits` 清掉用户未保存内容。

交付前用相同口径重查关键数量、CRS、字段、几何和统计，合理的数量变化用方法解释，不能为了“通过”删除异常或改分母。

## 从试题、技术书和参考成图提取要求

文本抽取用于检索，不代替原页核对。涉及根号、上下标、分式、矩阵、颜色选区或图示范围时查看原始页面；遇缺字、替换字符、孤立代理字符或单位不闭合，停止相应计算并核原图。记录页码、正确公式、变量含义/单位、适用范围与舍入规则。现有 2026 试题自测中，文本抽取丢失了根号和 H；实际公式是 r = k × √S × H / h。这是具体资料的模型，不能升级成通用噪声声学规范。

“图中高亮道路”必须映射到真实源对象并保留依据，不能当作全部道路。线起点按源方向；25 米布点等任务还需明确多部件、闭合线、恰好整除、短线、零长度、共享端点及余段末端的去重口径。没有受控算法入口或可靠选区时保留阻断，不用未核路线凑成果。

附带报告可能已填写答案或包含姓名、电话。先识别其用途，不能把旧答案当独立真值、把他人身份写入新成果，或因文档包含提交链接就自动上传。原件及工作副本保真，派生报告另存；缺失身份不阻塞不需要身份的本机试验。

## 几何、字段与精度交叉检查

面积/长度属性可能是旧值，尤其 Shapefile 不保证随几何实时维护。计算前核实际几何、CRS、XY/Z 单位及字段来源；发现不一致就报告差异和采用依据，不静默覆盖原字段。本次商超属性面积为 19932.7047095 m²，实际二维几何为 19933.50867354 m²；原周长字段也不同。Z 几何不等于可用的三维建筑实体，建筑高度字段也不自动建立日照模型。

先采用足够精度计算，再按任务规则显示/落值，明确各阈值从未舍入还是已舍入量导出；需要十进制四舍五入时不能无说明采用偶数舍入。空值、负值和分母为零先处理；比例与百分比、原面积与相交面积分开保存，避免重叠累计超过原面积。

缓冲环需检查成对相交面积、总覆盖及外边界，而不只是三份文件存在。空相交结果在“不重叠”检查中是预期结果，GP 的空输出警告不自动等于失败。GDB 内部数据集不能仅用文件系统 exists 或通用 stateProof 判不存在，应通过数据集/几何工具实际读回；stateProof 为 unprovable 时保留限制。几何校验工具若返回未实现，几何有效性仍是未验证，数量/面积检查不能冒充完整拓扑校验。
