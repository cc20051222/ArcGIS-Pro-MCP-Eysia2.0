# 水文场景：由数据与目标决定流程、质量重点和能力缺口

本参考用于计划和检查设计，不授予GIS写入权限，不增加工具。先核DEM类型/时相/分辨率/XY与Z单位/水平与垂直基准、研究区与上游覆盖、河湖与真实洼地、出口点、用途、已有许可、当前工具与GP白名单。Fill是填洼，不是土方填挖方计算。没有真实资料时展示计划或待资料，不表演正在执行水文。

## 方法分支

- 要指定出口的汇水区：先定出口标识和吸附距离依据，再用兼容的D8流向衔接Watershed；若采用MFD或DINF用于汇流研究，不能直接当Watershed的兼容输入。
- 要全区分水岭：选择Basin等适用方法，不能凭空造一个出口。要河网时才需要阈值、分级与矢量化；已有可信水文整饰DEM时先验证已有处理，避免重复填洼。
- 传统Fill→Flow Direction→Flow Accumulation是候选链，Fill的深度限制与保留真实洼地须论证。新式连续流或直接河网算法可作为备选，但仅在本机版本、许可和受控接口实际支持且方法适用时采用。
- 河网阈值须说明单元数、汇水面积或加权累积的口径；投影米制方形格网可按单元面积换算，不能把加权累积当像元数。阈值用参照河网/资料及敏感性比较选定，不捏造一个通用最佳值。

## 完整计划候选与检查重点

| 步骤 | 必须说明的方法与条件 | 过程检查/成果重点 |
|---|---|---|
| 资料、目标与质量预检 | 研究用途、输入版本、上游范围、CRS/Z基准、许可、输出根 | 来源/NoData/有效范围/分辨率；无资料与能力缺口明确受阻 |
| DEM预处理 | 按需拼接、投影、格网对齐、保留上游缓冲范围；记录重采样 | 像元大小/原点/范围/单位；重采样不提高真实精度 |
| 洼地诊断与填洼 Fill | 诊断异常与真实洼地，深度限制或保留依据 | 改动像元/高差与体量；填洼后残余异常，不能任意填平湖泊洼地 |
| 流向计算 | 选择D8/MFD/DINF及边界处理并解释 | 方向编码与算法一致，异常/未定义流向、边界出流与洼地 |
| 汇流累计量 | 流向算法衔接、是否加权 | 单元数/面积/权重口径，极值、NoData与边界截断 |
| 河网阈值确定 | 基于资料、面积尺度与敏感性 | 多阈值河网长度/密度变化，目标河道与噪声分支 |
| 河网提取、分段与分级 | 按交付用途选Link/Order与分级法 | 连通、分段/等级值，背景NoData，不把0背景矢量化为河道 |
| 河网矢量化 | 与流向一致的Stream to Feature等受控方法 | 下游方向、栅格/矢量位置、断裂、短伪支；河源/出口悬挂合理豁免 |
| 出口点定位（条件步骤） | 使用用户目标出口/节点与有据吸附距离 | 吸附前后位移、落在目标支流、ID唯一及错支风险 |
| 流域/子流域划分 | 指定出口Watershed或全域Basin分支 | 出口对应ID、上下游嵌套/互斥分区业务区别、边界截断与覆盖 |
| 水文地形指标统计 | 面积/周长/主河长/坡度/河网密度等按目标选择 | 米/平方公里等单位、分母、主河定义、格网/矢量面积差；DEM不推导实测流量 |
| 成果首检 | 逐项质量判据、适用标准/合同、全检/抽样 | 格网/数值/网络/流域/统计/正式制图各自判据和证据 |
| 问题修复与受影响下游重算 | 明确缺陷/原因/操作/版本与授权；无问题时有据跳过 | 不改原DEM；科学参数改动记录方案版本，旧下游标STALE |
| 新证据复检 | 对问题与受影响链重新读取/测量 | 首检失败保留，修复与复检分别留证；未通过继续显式闭环 |
| 最终交付检查 | 数据/报告/地图/工程引用/完整成员与规格 | 每必需成员实际可读、CRS/单位/版本、真实渲染，限制未隐去 |
| 外部验收 | USER/INDEPENDENT_REVIEWER的真实裁定 | 不由制作Agent自签；计划节点required=false，候选与验收分开 |

检查不能一律选“无缝隙/无悬挂”：闭合自然流域边界、嵌套汇水区、流域内湖泊、真实河源/出口具有不同语义。按行业技术设计书的具体条款列criterion/source/阈值与范围；未提供适用条款时采用明确的通用技术检查，不能称已符合某行业标准。

## 2.0的能力与运行边界

更正旧版能力描述：随包工具目录快照已含 `sa.Fill`、`sa.FlowDirection`、`sa.Watershed` 等受控候选，不能再笼统声称白名单没有水文入口。任务开始时重新枚举并读取每个所需GP的实际schema，分别核许可、宿主、算法衔接和真实小样本执行。目录中出现名称只证明被列出，不证明完整水文链已实测；其余汇流、河网、出口吸附等成员同样按现场清单逐项判断。缺失入口的步骤及其下游保持BLOCKED，不用任意ArcPy或6511旁路补跑。本次综合实验没有DEM，不能作为水文场景验收。

本机C盘项目产物仍禁写；Spatial Analyst并行栅格工作还可能使用TempFolders。水文执行前除了workspace/scratch/TEMP/TMP/ARCTEMPDIR，还要核实际继承的TempFolders指向可写D目录；当前进程没有配置时，先解决运行条件，不能仅在新shell中设变量就声称旧Pro已变化。当前面板改进不等于已跑真实DEM水文验收。
